### Phase 52: docs match the code, and the Design panel's controls are tested

- `SCHEMA_REFERENCE.md` §0 is schema v7 (the optional asset, mode, breakpoint and 3D tables, and the v6 to v7 migration).
- `CONVENTIONS.md` and `FOLDER_STRUCTURE_AND_DATA_HIERARCHY.md` are rewritten against the code (v2.0.0); the v1.1 text described files and folders that were never built.
- New end-to-end spec `tests/e2e/design-controls.spec.ts`: padding, margin, grow, fill opacity and reorder, effects, line shadow, cursor, sizing and text modes each change what is drawn.
- New end-to-end spec `tests/e2e/assets-new-editor.spec.ts`: a picture dropped on the new editor's canvas becomes an asset and an image layer, draws from the asset store, and survives a reload.
- Design panel: blend-mode, cursor and overflow options have descriptions; every segmented control shows its label as a tooltip (LA-009, LA-021).
- New end-to-end spec `tests/e2e/design-coverage.spec.ts` (Design track D2): drives every control in the Design panel for a rectangle, a frame, a text and a line, and fails on a control that changes nothing.
- Design track D3 (Style code): a **Style code** box in the Design panel. Write CSS declarations for a layer; known ones (padding, opacity, border-radius, colours, ...) set the matching controls, the rest are kept as written, drawn on the canvas and exported unchanged. Hostile input (`expression()`, `javascript:`, selectors, HTML-bearing `url()`) is refused with a line and a message. New property `style.custom` (additive); `src/core/style/styleCode.ts`.
- Design track D4 (drivers), engine core: `src/core/bindings/` evaluates the signal and operator bindings that the document model already described: the operator catalogue (smooth, spring, remap, deadzone, falloff, noise, delay, velocity, threshold, toggle, and the rest), guards, per-property blending with range clamps, and input tapes with a seeded autopilot pointer. Not wired to the stage or the export yet.
- Design track D4 (drivers): a **Driven by** section in the Design panel. Make Position X or Y, Rotation, Scale or Opacity follow the pointer, the pointer's speed, scroll or time, with a range and smoothing. Drivers are bindings in the document, shown in Motion and Preview (Design shows the design). The kernel takes `inputs.bound` (one optional input); the stage engine gets a `BindingDriver` that costs nothing when no driver is enabled. Not exported yet; scroll is not measured in the editor yet.
- Design track D5 (parenting, links, expressions): a **Parent & links** section in the Design panel reaches the engine Lane B merged. Parent a layer (it keeps its place), link a property to another layer's (a multiplier of -1 turns it the other way), type an expression; cycles and bad expressions are refused with a message.
- Design track D6 (follow, pins, helpers): **Follow the pointer** under Driven by (pick one of nine points of the layer, a lag and an offset; it is two drivers, made and replaced as one undo step). A **Helper layer** toggle (drawn while designing, absent from Preview and the export). A label parented to an image stays on its point through moves, rotations and scales (tested to 0.5 px).
- Design track D8 and D9 (Repeater and Cloner): **Repeat** (a layer N times, each copy stepped in position, turn, scale and fade) and **Clone** (a grid of rows and columns, a ring, or fill the frame the layer sits in) sections in the Design panel. The copies are drawn by the renderer from new `repeat.*` and `clone.*` properties, so the canvas, Preview and the export agree; a 100 x 60 dot grid exports with no script.
- Design track D7 and D10: the link form gains **Range** mapping and a one-click **Opposite**; an **Effector** section varies the copies of a Repeat or Clone by a ramp, seeded noise, or the pointer's distance (dots that grow near the cursor while the page runs, restored in Design).
- Design track D4 (gaps): drivers now read the previewed frame's own **scroll** and **view(section)** (how far a section has scrolled through the screen) in the editor, and the plain HTML export carries drivers and live effectors in one standalone script (tested against the editor's evaluator). Drivers have typed commands (`layer.addDriver`, ...). The Style code box autocompletes. Link form: **Pick on canvas**. The export says when links or expressions are left out.
- Design track D5 and D7 (export): the plain HTML export now carries **links and expressions** (direct and range maps) in the same page script as the drivers. The script embeds the core's own expression evaluator, generated by `npm run build:export-runtime` (a test fails if it is stale); 20 links and expressions are tested equal to the editor's values.
- Design track D4 (more): drivers can read `hover`, `press`, `pointer.inside` and `proximity` of a layer (editor and export); the driver script is also written for the Vite and Next.js targets. D9: a static grid of 50 or more identical plain dots exports as one element with a CSS background (6,000 dots in under 6 KB); the pointer effector's live driver only touches the copies that changed.
- Design track (more): copies of a repeated or cloned layer **follow its animation**, each a **Delay** behind the one before; drivers can set **CSS variables** (editor and export); **Look at the pointer** (a new `lookAt` operator); Follow works on turned and scaled layers.
- Design track D16 and D18: the corner pin is verified (handles within 0.01 px, export within 0.5 px at five sizes). New **Speed** section: a layer stretches along its motion, leans and blurs by how fast it moves, and can leave an echo trail.
- Design track D14: a **Parallax** preset (layers drift at their own depth with the scroll and the cursor) and **smooth scrolling** for the exported page (a standalone script that eases the mouse wheel; keys, find in page, anchors, touch and the scrollbar stay native; off for reduced motion). New page property `scroll.smooth`.
