### Phase 55 (Frame scheduler): unified requestAnimationFrame phase order & one-clock motion model sync

Wires the Phase 55 frame scheduler into the new editor UI (`/editor`), enforcing ordered phase execution (`input` → `evaluate` → `apply` → `render` → `overlay` → `stats`) across playback, motion state updates, canvas rendering, and stage overlays.

#### Added
- **`src/core/time/scheduler.ts`**: Test seam `window.__LL_SCHEDULER__` under the `__LL_TEST__` guard giving Playwright deterministic test access (`setDeterministic`, `step`).
- **`src/editor/motion-model/store.ts`**: Scheduler task registration in the `apply` phase to copy transport time to `useMotionModel` once per frame during playback; scheduler task in the `overlay` phase to publish synchronized `overlayFrame` and `overlayTime`. Paused seeking, scrubbing, and frame stepping apply immediately to maintain responsive direct manipulation.
- **`src/editor/motion-model/index.ts`**: Exported `getOverlayFrame`, `getOverlayTime`, `useOverlayFrame`, and `useOverlayTime`.
- **`src/editor/stage/ValueHud.tsx`**: Value HUD now reads the published `overlayFrame` and `overlayTime` instead of independent 60 Hz throttling, exposing `data-frame` in lockstep with the stage canvas.
- **`src/editor/stage/MotionPathOverlay.tsx`**: Motion path overlay consumes `useOverlayTime` and exposes `data-frame`.
- **`src/editor/stage/OnionSkinOverlay.tsx`**: Onion skin ghost sampling consumes `useOverlayTime` and exposes `data-frame`.
- **`src/editor/panels/timeline/TimelinePlayhead.tsx`**: Playhead layer and knob consume `useOverlayFrame` and expose `data-frame` alongside `data-time`.
- **`src/editor/stage/Artboard.tsx`**: Evaluates active clip properties at current `motionTimeSec` for the engine-rendered page tree (`stage-page`), keeping live elements and canvas DOM in strict agreement.
- **Unit test `src/editor/motion-model/__tests__/schedulerPhases.test.ts`**: Proves deterministic `step(1/60)` advances playhead by 1 frame per step in lockstep with overlay frame, and paused seeking updates immediately without stepping.
- **Playwright test `tests/e2e/wire-55-scheduler.spec.ts`**: End-to-end verification in `/editor` Motion tab under deterministic scheduler mode with headline layer animation, asserting transport frame, Motion playhead, ValueHud `data-frame`, and drawn layer computed opacity match for 10 consecutive frames.

#### Changed
- **`DOCS/UI/WIRING-53-80.md`**: Marked Phase 55 as **Yes** with proof references.
- **`src/editor/motion-model/__tests__/oneClock.test.ts`**: Updated playback test step to drive advance through the deterministic frame scheduler.
