### Phase 56 (Move playback onto clock): React commit throttling and direct DOM updates during playback

Decoupled 60fps playback from React component re-rendering across the timeline panel and the stage canvas. High-frequency updates (timeline needle position via `translateX`, timecode display, and animated stage element properties) are driven directly on the DOM in `frameScheduler`'s `apply` and `overlay` phases. Timeline and stage components throttle React subscriptions to <= 10 Hz during playback while preserving immediate 60fps reactivity when paused. On pause, direct DOM inline overrides are cleared immediately, returning rendering authority to React with zero stale styles.

#### Added
- **`src/editor/diagnostics/commitCounter.ts`**: React `<Profiler>` commit recording utility exposed under `window.__LL_TEST__` test seam as `window.__LL_COMMITS__` (`{ timeline, artboard, reset }`).
- **`src/editor/stage/directDomApply.ts`**: Direct DOM playback engine running in `frameScheduler`'s `apply` phase. Evaluates active composition clips at transport time and applies inline properties (`opacity`, `transform`, `transformOrigin`, `backgroundColor`, `borderRadius`) directly to `[data-testid="stage-page"] [data-archetype][data-element-id]`. Automatically clears all inline overrides when playback transitions from playing to paused.
- **`src/editor/stage/__tests__/playbackOptimization.test.ts`**: Unit test suite verifying commit counters, direct DOM property application, inline override removal on pause, and scheduler apply lifecycle.
- **`tests/e2e/wire-56-playback.spec.ts`**: End-to-end Playwright test verifying timeline commits <= 10/s, Artboard commits <= 10/s, deterministic 1-frame lockstep between needle, transport and canvas opacity, zero stale inline styles on pause, and Design-at-rest persistence.

#### Changed
- **`src/editor/panels/timeline/TimelinePlayhead.tsx`**: Moved needle position updates (`translateX`) to direct DOM updates in `frameScheduler` `overlay` phase. React component renders only when paused (`s.playing ? 0 : s.playhead`), eliminating 60fps React reconciliation during playback.
- **`src/editor/panels/timeline/TimelinePanel.tsx`**: Wrapped in React `<Profiler id="timeline-panel">`; removed redundant 60fps `playhead` subscription.
- **`src/editor/panels/timeline/TimelineRuler.tsx`**: Removed 60fps `playhead` subscription; drag and click handlers read store imperatively.
- **`src/editor/panels/timeline/TimelineLane.tsx`**: Subscribed to `useTransportTime({ maxHz: 10 })` display playhead during playback, eliminating per-frame lane reconciliations.
- **`src/editor/panels/timeline/TimelineTransport.tsx`**: Timecode display text updated directly in DOM via `frameScheduler` `overlay` phase, with React state throttled to 10 Hz via `useTransportTime`.
- **`src/editor/stage/Artboard.tsx`**: Wrapped in React `<Profiler id="artboard">`. `animatedLayers` memoized on `pausedPlayhead`, skipping React canvas tree reconciliations during playback and relying on direct DOM application.

- **`src/editor/motion-model/store.ts`**: Throttled non-deterministic `syncTransportToMotion` and `syncOverlayFromTransport` updates in `apply`/`overlay` scheduler phases to <= 10 Hz, while preserving per-step synchrony in deterministic test mode.
