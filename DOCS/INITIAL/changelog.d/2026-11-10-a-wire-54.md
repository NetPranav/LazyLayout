### Phase 54 (Transport & one clock): Wire one unified clock into the new editor

Unified the motion timeline UI and motion model onto the core canonical `transport` and `transportStore`. Removed the competing local playback loop from `TimelinePanel.tsx`, mirrored `transportStore` directly into `useMotionModel`, routed transport and timeline controls to `transport.*`, registered transport commands on the command bus with timeline focus scopes, and added tests proving clock synchronization and frame-exact stepping.

#### Added
- Unit tests (`src/editor/motion-model/__tests__/oneClock.test.ts`): verified `transportStore` drives motion model time and playing across seek, stepFrame, and play/tick; frame stepping lands on exact frame times at 24, 30, and 60 fps; motionActions route directly to transport.
- E2E Playwright spec (`tests/e2e/wire-54-transport.spec.ts`): verifies step-forward moves transport time by exactly one frame, timecode reflects it, play/pause keeps playhead stationary and in sync with timeline ruler, loop button cycles through three modes, and pressing K pauses playback.
- Test seam `window.__LL_TRANSPORT__ = () => transportStore.getState()` gated behind `window.__LL_TEST__`.

#### Changed
- `src/editor/motion-model/store.ts`: added `time` property to `MotionState`; subscribed `useMotionModel` to `transportStore` so playback, time, speed, direction, loop, work area, and fps are always in lockstep; forwarded `motionActions` methods (`setPlayhead`, `setPlaying`, `setSpeed`, `setLoop`, `toggleLoop`, `stepFrame`, `jumpKey`, `shuttle`, `setWorkArea`, `resetWorkArea`, `setComp`) to `transport.*`.
- `src/editor/panels/timeline/TimelineTransport.tsx`: read playing, loop, speed, and timecode from `transportStore` and `useTransportTime`; wired center transport buttons and menus to `transport.*` (including 3-state loop cycle and speed rate changes).
- `src/editor/panels/timeline/TimelinePanel.tsx`: removed rogue local `frameScheduler.register("evaluate")` playback loop; added `useFocusScope("timeline", panelRef)` to scope command bus shortcuts; updated keydown handlers to call `transport.*`.
- `src/editor/shell/EditorShell.tsx`: mounted `installTransportCommands()` and `installTransportDriver()` at root shell level.
- `src/core/time/transportCommands.ts`: updated `transport.shuttleStop` (K) and `transport.togglePlay` (Space) when-conditions to allow pausing whenever playing or timeline is focused.
- `src/core/time/useTransportTime.ts`: ensured paused time updates emit immediately to prevent UI lag on manual scrub/seek.
- `DOCS/UI/WIRING-53-80.md`: updated Phase 54 row to "Yes".
