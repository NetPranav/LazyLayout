## Phase 57 in the new editor: the engine animates the canvas

- The new canvas now uses the engine's stage adapters (`installStageEngine`: the kernel adapter, with Web Animations while playing), exactly as the old stage did. They write the animated values straight onto the drawn layers in the scheduler's apply phase, only the properties a layer animates, and put back what React drew when they stop.
- The canvas draws the design at rest. The engine runs in Motion and Preview and while playing; in Design (paused) it is off, so the canvas shows the design itself.
- `src/editor/stage/useCanvasEngine.ts` fills the engine's layer registry from the drawn page (a linked view's copies are left out), and gives tests `window.__LL_ENGINE__` (the kernel's value for a layer, seek, play, pause).
- Removed: the canvas's own per-frame evaluation and the hand-made playback writer from the earlier Phase 56 attempt; the engine does both properly.
- `tests/e2e/wire-57-stage-engine.spec.ts`: ten reference animations, each seeked to five times, match the kernel within 0.5 px (opacity within 0.005) on the new canvas; Design at rest versus Motion at the playhead.
