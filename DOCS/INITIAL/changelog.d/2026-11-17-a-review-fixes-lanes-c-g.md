### Fixed

- **AI "Accept all" no longer undoes your work.** It used to replace the whole document with the copy the AI made when it proposed the change, so anything you edited while the proposal waited was lost, and layers you had discarded came back. It now applies only the changes still pending, to the document as it is now.
- **The server's AI keys stay private on public builds.** Turning the lab pages on (`NEXT_PUBLIC_ENABLE_LABS=1`) used to open the server's own Anthropic/Gemini/NVIDIA keys to anyone who could reach the site. Only `LAZYLAYOUT_ENABLE_AI_ROUTE=1` on the server opens them now, and requests on the server's key may only name a listed model. Requests with your own key (BYOK) or offline mode are limited to 20 a minute per visitor, and provider error details stay in the server log.
- **The AI says when a change is a preset, not its own answer.** When the model proposes nothing, the chat may still offer a built-in preset that matches your words; it now says so instead of presenting it as the AI's change. The AI is no longer offered, and can't stage, file, export, test, undo or redo commands.
- **Pointer presets do what their names say (Phase 143).** Magnet pulls toward the cursor on both axes (it used to always push right). Follow leans after the cursor from where the layer is (it used to jump the layer to page coordinates). Inertia only reacts while you drag (it used to drift on every mouse move). Noise and wander move on both axes.
- **The kernel's list of what it can't evaluate is true again.** Phase 143 had removed "behaviours" from it, but `evaluate()` still runs only `loop` behaviours.
- **The 3D Studio tab no longer shows a "227-phase gates" PASS.** Its results were hard-coded. The model checks behind it (`core/3d/roadmap3d`) now report what they can't measure: no Export v2 build or compression, no leak check, no vision model, no video tracking, no ink renderer, no anime export. Gates M4, B and C list those under `unmeasured` and don't pass until they're built. The lab workbench still shows the checks, now with "not measured" where there is no number.
- **The effect "10-minute soak" no longer reports a result it never measured (Phase 200).** It added and removed the same surfaces in a loop, so it always reported zero leaks and zero memory growth. It now checks the effect's declared costs against the tier budget and replays its tape. It reports leaks and memory as not measured, and doesn't count as a pass until a real browser soak exists.
- **Code components get prop updates (Phase 195).** The sandbox only ran the first `init`; `props_update` and `dispose` were ignored. A component can now call `host.onProps(fn)`, `dispose` clears the frame, and the frame only accepts its channel from the parent window. The static sandbox report no longer returns made-up probe results ("unreadable", "SecurityError…"); it lists the risky APIs a bundle names and whether the frame is opaque. The real probe is the browser test.
- **The embed snippet audit only claims what it checks (Phase 198).** CLS 0 now comes from the reserved `aspect-ratio` box. "Strict CSP" is true only when a nonce is given. "Waits for LCP" and "pauses offscreen" are false, because the runtime the snippet loads (`embed-v1.mjs`) isn't built yet.
- **The interactive export bundle checks its own claims (Phase 197).** "No LazyLayout imports" and "cleans up on unmount" are now read from the generated files, not fixed `true` types. The bundle also says plainly that its entry mounts a placeholder and doesn't run the effect yet (`runsEffect: false`).
- **The interactive verification harness can fail (Phase 137).** A checkpoint past the end of the tape used to be skipped, and the run still passed. A run with no checkpoints passed too. Both now fail, and teardown and the leak check run even when a frame throws.
- **Exported Blueprints run (Phase 169).** The compiled React, Vue and plain TypeScript used to hook every graph to one `pointerdown`, order actions by where nodes sat on the canvas, write values into an in-memory map, and call empty physics stubs. Each event node now becomes its own listener: press, hover, focus, key, mount, in view, timer or custom event. The actions wired after it run in wire order and change the element's styles. Node types the export can't run yet (physics, particles, sound, state machines) are listed in `unsupportedNodes` and in a comment at the top of the file.
- **Rig exports draw and play the character (Phase 215).** The Next.js export used to render an empty `<div data-bones>`, and nothing played the animation. Next.js, Vite and HTML exports now draw the bones as SVG and loop the keyframed track; under reduced motion they show the first pose. Parity checks run the exported pose sampling as well as the bone maths. Skinned meshes aren't exported yet, and the bundle says so (`skinsMeshes: false`). The HTML export escapes the rig's name and data, so a name can't break out of the page's script.
- **Event bindings fire once per press (Phase 139).** A binding that targets an event used to fire on every frame its value stayed at or above 0.5, so one press fired dozens of events. It now fires when the value crosses 0.5 going up.
- **Stock photos are ones you may use and edit on a commercial site (Phase 126).** The Openverse search now asks for commercial, modifiable licences only, and drops any NC (non-commercial) or ND (no-derivatives) result that still comes back.
- **Input bus and signal catalogue fixes (Phases 132, 133).** The page's hidden state now updates: `visibilitychange` is heard on the document, not the window. Held keys are released when the window loses focus or the tab hides, instead of staying "held". The bus no longer adds empty scroll and resize listeners. In the catalogue, each device channel has its own label and range (they all showed "Tilt X"), and every cursor position unit has an entry.
- **Drags keep their momentum (Phase 148).** A fling used to stop dead on release, because the release was compared with the last move position and they are the same in a browser. It now carries on, and a quick flick on a slide-to-confirm reaches the end. A rubber-banded overshoot springs back instead of jumping back in one frame.
- **State machines can change their mind (Phase 151).** A transition can now be interrupted. Moving the pointer away halfway through a hover-in reverses from the pose reached so far, instead of finishing the hover-in first. A trigger nothing uses is dropped at the end of the step; before, it waited and fired a transition later. The transition history keeps its last 64 entries.
