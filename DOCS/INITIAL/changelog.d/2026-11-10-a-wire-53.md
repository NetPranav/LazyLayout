### Phase 53 (Animation grammar: close schema gaps): Wire two-way trigger and category into the new editor

Two-way synchronization for clip triggers and categories is now fully wired between the canonical document model and the new editor's Motion workspace (`/editor`).

#### Added
- **Category & Trigger 2-Way Sync:** Extended `src/editor/motion-model/types.ts` with `ClipCategory` (all 10 `CLIP_TYPES`: Entrance, Hover, Tap, Scroll, Loop, Morph, Exit, Focus, Stagger, Layout) and full `Trigger` set (mount, hover, press, focus, inView, scrollProgress, pointerMove, drag, time, unmount, layoutChange).
- **Canonical Projections & Mappings:** Added bijective conversion tables and helper functions in `src/editor/motion-model/sync.ts` (`CANONICAL_TO_UI_TRIGGER`, `UI_TO_CANONICAL_TRIGGER`, `CANONICAL_TO_UI_CLIP_TYPE`, `UI_TO_CANONICAL_CLIP_TYPE`, `CATEGORY_DEFAULT_TRIGGERS`). `syncDocumentToMotion` reads `type` and `trigger` from canonical document clips so reloads, undos, and external edits persist and project accurately.
- **Motion Actions:** Added `motionActions.setClipCategory`, `motionActions.setClipTrigger`, and `motionActions.setClipSettings` to `src/editor/motion-model/store.ts`. Edits update document clips in one undo step (`documentCommands.updateClip` / `documentCommands.addClip`) respecting `ClipSchema` refinements (e.g. default `stagger` for stagger clips, cleaning `event` for non-custom triggers).
- **Inspector UI:** Added Category `<Select>` and updated Trigger `<Select>` in `src/editor/panels/inspectors/LayerInspector.tsx`. Choosing a category sets its matching default trigger (Exit → On leave, Focus → On focus, Layout → When its layout changes, Hover → On hover, Tap → On press, Scroll → While scrolling, Entrance → On load) while allowing subsequent trigger customization. Legacy "On click" UI values are supported and mapped to canonical `press`.
- **Wiring Roadmap:** Documented complete wiring audit for Stage 2 in `DOCS/UI/WIRING-53-80.md`.
- **Unit and E2E Tests:** Added unit tests in `src/editor/motion-model/__tests__/clipSettingsSync.test.ts` (category defaults, sync projection, undo/redo restoration, independent trigger changes, legacy click mapping) and Playwright specification in `tests/e2e/wire-53-motion-grammar.spec.ts` (interactive canvas selection, Category Exit, reload persistence, trigger updates, and clean static HTML site export).
