## 2. Public API Added

### Camera (`src/core/3d/camera/viewCamera.ts`)
- `ViewCamera`: Immutable data structure for target, distance, yaw, pitch, fovY, ortho, orthoSize, near, far.
- `createViewCamera(options)`: Creates a ViewCamera with defaults or overrides.
- `cameraPosition(cam)`: Computes world 3D eye position from target and spherical angles.
- `cameraBasis(cam)`: Computes normalized forward (-Z), right (+X), and up (+Y) vectors.
- `viewMatrix(cam)`: Generates 4x4 column-major look-at matrix.
- `projectionMatrix(cam, aspect)`: Generates 4x4 column-major perspective or orthographic projection matrix.
- `orbit(cam, dx, dy)`: Increments yaw and pitch with strict pitch clamping just short of $\pm 90^\circ$ (`[-PI/2 + 1e-4, PI/2 - 1e-4]`).
- `pan(cam, dx, dy, viewportH)`: Moves target in the view plane so the scene moves synchronously with the cursor.
- `dolly(cam, delta)`: Exponentially scales distance / orthoSize with boundary limits.
- `zoomToPoint(cam, factor, sx, sy, vw, vh)`: Zooms towards a viewport pixel while keeping the target point under the cursor stationary.
- `flyStep(cam, dir, dt, speed)`: Translates camera target along local basis directions in fly mode.
- `setStandardView(cam, view)`: Aligns camera to canonical Blender numpad views ("front", "back", "left", "right", "top", "bottom") converted to glTF conventions.
- `toggleOrtho(cam)`: Toggles orthographic / perspective mode while preserving visible scale at the target.
- `frameBounds(cam, aabb, aspect, margin)`: Re-centers and fits camera distance/orthoSize to an axis-aligned bounding box.
- `frameAll(cam, boxes, aspect, margin)`: Re-centers and fits camera distance/orthoSize to the union of multiple bounding boxes.
- `viewFromObjectCamera(cameraObject, doc)`: Configures ViewCamera from a scene Camera object and its evaluated world matrix.
- `VIEW_COMMANDS`: Canonical view command IDs (`3d.view.front`, `3d.view.toggle_ortho`, etc.).

### Gestures (`src/core/3d/camera/gestures.ts`)
- `navigationFromGesture(event, sensitivity)`: Pure translator from abstract mouse, wheel, trackpad, and touch events to navigation deltas.

### Tape (`src/core/3d/camera/tape.ts`)
- `TapeStep`: Typed step union for navigation macros (orbit, pan, dolly, view, frame, ortho, fly, zoom_to_point).
- `runTape(cam0, tape)`: Deterministic sequential executor returning a new `ViewCamera`.

### Picking & BVH (`src/core/3d/pick/ray.ts` & `src/core/3d/pick/bvh.ts`)
- `Ray3d`: World-space ray record `{ origin: Vec3; dir: Vec3 }`.
- `rayFromScreen(x, y, vw, vh, viewMatrix, projMatrix)`: Normalized world ray generator for both perspective and orthographic cameras.
- `PickResult`: Intersection result `{ objectId, distance, point, faceIndex, normal }`.
- `getOrCreateMeshBVH(meshId, version, positions, indices)`: Spatial index cache for three-mesh-bvh instances.
- `clearMeshBVHCache()`: Clears cached geometries and BVH trees.
- `pickMesh(ray, mesh)`: Raycast against a single mesh transformed by worldMatrix with inverse-transpose normal transformation.
- `pickScene(ray, objects)`: Raycast against multiple scene objects sorted by distance ascending.

### Selection (`src/core/3d/pick/select.ts`)
- `Selection3d`: Selection state `{ active: string | null; selected: string[] }`.
- `createSelection3d(initial)`: Instantiates a Selection3d model.
- `click(sel, hitId, modifiers)`: Blender click reducer with Shift-toggle/activate and Ctrl-deselect.
- `selectAll(sel, allIds)`: Selects all IDs.
- `selectNone(sel)`: Clears selection.
- `invert(sel, allIds)`: Inverts selection against all IDs.
- `boxSelect(objects, rect, viewProj, mode, viewport, sel)`: 2D rectangle selection in screen or NDC space with replace/add/subtract modes.
- `lassoSelect(objects, polygon, viewProj, mode, viewport, sel)`: 2D polygon origin containment selection.
- `selectLinked(sel, doc)`: Selects all objects sharing the same parent hierarchy tree.
- `selectSimilar(sel, doc, by)`: Selects objects sharing type, material slots, or dataId with the active object.
- `selectLinkedFaces(mesh, seedFace)`: Mesh topology flood-fill returning all triangle face indices connected by shared edges.
- `SELECTION_COMMANDS`: Canonical selection command IDs (`3d.select.all`, `3d.select.box`, etc.).

### Outline Silhouettes (`src/core/3d/pick/outline.ts`)
- `SilhouetteEdge`: Record of `{ v0, v1, normal0, normal1 }`.
- `silhouetteEdges(positions, indices)`: Extracts unique mesh edges and their dual adjacent triangle face normals (open boundaries return `normal1 = [0, 0, 0]`).

## 3. Decisions Made
1. **glTF Right-Handed Conventions (+Y Up, -Z Forward, +X Right):**
   - At `yaw = 0, pitch = 0`, the camera is situated at `target + [0, 0, distance]`, looking along `-Z` towards `target`.
   - Blender numpad standard views map cleanly: "front" looks along -Z (from +Z), "back" along +Z (from -Z), "right" along -X (from +X), "left" along +X (from -X), "top" along -Y (from +Y), and "bottom" along +Y (from -Y).
2. **Pitch Clamping & Invertibility:**
   - Clamped pitch to `[-PI/2 + 1e-4, PI/2 - 1e-4]`. This eliminates gimbal lock at poles while guaranteeing that `orbit(+d)` followed by `orbit(-d)` strictly returns to the original state within floating-point epsilon `< 1e-12`.
3. **Unified Perspective/Orthographic Raycasting:**
   - Instead of branching on projection type, `rayFromScreen` unprojects NDC near plane ($z = -1$) and far plane ($z = 1$) via `invert(Proj * View)` with perspective divide. This formulation works identically and accurately for both perspective and orthographic camera views.
4. **Local-to-World Transform & Normal Matrix Inversion:**
   - `pickMesh` transforms the incoming world ray into mesh local space via `invert(worldMatrix)`. After computing local intersection, the hit point is transformed back via `worldMatrix`, and the face normal is transformed via $\text{transpose}(\text{worldMatrix}^{-1})$. World distance is computed as the true Euclidean distance between `ray.origin` and the world hit point, guaranteeing exact distances under non-uniform scaling.
5. **Static Edge Adjacency for GPU Outlines:**
   - View-dependent silhouette determination (`dot(n0, V) * dot(n1, V) <= 0`) is deferred to the GPU shader pass. `silhouetteEdges` performs pure CPU extraction of unique edges and adjacent face normals once per mesh.

## 4. Verification & Testing
- **15-Step Tape Golden Test:** A 15-step navigation tape (orbit, pan, dolly, standard view, ortho toggle, framing) was executed and asserted against an analytical hand-computed 4x4 matrix, matching within `1e-12`.
- **Exact Picks on 30 Views:** 30 generated camera views (front, right, top, and angled off-center rays) were tested against a known unit cube. In all 30 cases, nearest-hit object ID, distance, point, and normal matched analytical ground-truth values within `1e-6`.
- **100,000-Face BVH Picking Benchmark:** A 100,352-face mesh (225x225 grid) was generated and benchmarked over 200 distributed rays. Raycast execution measured `< 0.05 ms/ray`, easily passing the `< 3.0 ms/ray` budget constraint.
- **Reducer & Selection Tests:** Full coverage for click modifiers (Shift toggle/activate, Ctrl deselect), boxSelect (replace/add/subtract), lassoSelect point-in-polygon, hierarchy selectLinked, selectSimilar, selectLinkedFaces connectivity flood-fill, and silhouette edge extraction.
