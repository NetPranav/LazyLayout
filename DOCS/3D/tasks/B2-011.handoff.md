## 2. Public API Added

### Primitives (`src/core/3d/commands/primitives.ts`)
- `cube(options?: number | CubeOptions): PrimitiveMesh`: Generates an 8-vertex, 12-triangle unit cube with outward-facing CCW normals and watertight topology.
- `uvSphere(segments?: number | UvSphereOptions, rings?: number, radius?: number): PrimitiveMesh`: Generates a UV sphere with shared ring vertices, polar closures, and positive signed volume.
- `cylinder(vertices?: number | CylinderOptions, depth?: number, radius?: number): PrimitiveMesh`: Generates a closed cylinder with top/bottom caps and side quads.
- `cone(vertices?: number | ConeOptions, depth?: number, radius?: number): PrimitiveMesh`: Generates a cone with apex fan and flat circular base cap.
- `plane(options?: number | PlaneOptions): PrimitiveMesh`: Generates an XZ plane quad with upward-facing +Y normal.
- `torus(radius?: number | TorusOptions, tube?: number, radialSegments?: number, tubularSegments?: number): PrimitiveMesh`: Generates a closed 2-torus manifold without boundary edges.
- `icosphere(subdivisions?: number | IcosphereOptions, radius?: number): PrimitiveMesh`: Generates a normalized geodesic icosphere from an icosahedron base with edge midpoint sharing.
- `computeSignedVolume(positions, indices): number`: Evaluates signed divergence volume of a triangle mesh (positive confirms outward CCW winding).
- `isWatertightMesh(indices): boolean`: Validates that every undirected edge in a closed triangle mesh is shared by exactly 2 triangles.

### Operations & Schemas (`src/core/3d/commands/ops.ts`)
- `run3dOp(id: string, doc: MotionDocument, args: unknown): OpResult`: Dispatches and executes any canonical 3D operation immutably, returning `{ doc, selection?, created? }`.
- `COMMAND_SCHEMAS: Record<string, z.ZodTypeAny>`: Map of all 29 canonical 3D command IDs to their strict Zod argument schemas.
- `COMMAND_TITLES: Record<string, string>`: Map of all 29 canonical 3D command IDs to human-readable UI titles.
- Schemas for all 29 commands: `AddCubeSchema`, `AddSphereSchema`, `AddCylinderSchema`, `AddConeSchema`, `AddPlaneSchema`, `AddTorusSchema`, `AddIcosphereSchema`, `AddLightPointSchema`, `AddLightSunSchema`, `AddLightSpotSchema`, `AddCameraSchema`, `AddEmptySchema`, `ObjectDeleteSchema`, `ObjectDuplicateSchema`, `ObjectRenameSchema`, `ObjectParentSchema`, `ObjectUnparentSchema`, `ObjectHideSchema`, `ObjectUnhideAllSchema`, `ObjectApplyTransformSchema`, `ObjectSetOriginSchema`, `ObjectSetLocationSchema`, `ObjectSetRotationSchema`, `ObjectSetScaleSchema`, `ObjectJoinSchema`, `MaterialAddSchema`, `MaterialAssignSchema`, `MaterialMakeSingleUserSchema`, `MaterialSetSchema`.

### Adjust Last Operation (`src/core/3d/commands/lastOperation.ts`)
- `recordLastOperation(op: { id, args, docBefore, title? }): void`: Stores the last executed 3D command and snapshot for subsequent adjustment.
- `adjustLastOperation(newArgs: Record<string, unknown>): boolean`: Re-executes the last operation against `docBefore` with merged arguments, replacing the undo transaction in `useHistoryStore` in-place.
- `getLastOperation(): LastOperation | null`: Returns the currently active last operation snapshot, or null.
- `clearLastOperation(): void`: Resets the last operation state and notifies subscribers.
- `subscribe(listener: () => void): () => void`: Subscribes to changes to the last operation state (recorded, adjusted, cleared).
- `describeArgs(id: string): ArgDescriptor[]`: Introspects the Zod schema for a command into strongly-typed parameter descriptors (name, type, default, min, max, step, options, description) for UI controls.

### Registration (`src/core/3d/commands/register.ts`)
- `register3dCommands(): () => void`: Registers all 29 canonical 3D commands on the global command bus with `defineTypedCommand`, wiring execution into `documentCommands.mutate` and `recordLastOperation`.

## 3. Decisions Made

1. **Topology & Watertightness Over Duplicated UV Seams:** Procedural primitives avoid duplicating vertices along UV seams so that all closed primitives (cube, UV sphere, cylinder, cone, torus, icosphere) satisfy the strict 2-shared-triangle-per-edge watertight 2-manifold invariant and have positive signed volume.
2. **In-Place History Step Replacement:** `adjustLastOperation` uses `history.replaceLast` with updated diff patches instead of pushing new transactions or popping/pushing. This guarantees that one gesture/operation = exactly one undo step regardless of how many times the user tweaks parameters in the panel.
3. **Automatic Invalidation:** Subscribed to `subscribeToDocumentChanges` and `useHistoryStore` to automatically clear `currentLastOp` whenever an external edit or undo/redo occurs, replicating Blender's modal operation adjustment lifecycle.
4. **Schema Introspection for Controls:** Built a recursive Zod unwrapper (`describeArgs`) that extracts types, numerical ranges (`min`, `max`), integer steps, defaults, and enum options directly from the schema, ensuring UI panels and agent bridges stay synchronized with schemas without duplicate metadata.
5. **Multi-Object Join Transform Hierarchy:** `3d.object.join` computes `mRel = primaryWorldInv * objWorld` to bake each child object's world transform into the primary object's local mesh space, transforming both vertices and normals before consolidating geometry and cleaning up merged objects.
