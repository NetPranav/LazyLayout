## 2. Public API Added
- `ViewportInteraction`: Main React interactive layer component mounted over 3D scene canvas during editing.
- `GizmoOverlay`: React SVG gizmo component rendering constant-pixel-size handles and handling drag updates.
- `SnapBar`: React header toolbar strip with snap toggle, snap target, pivot point, and orientation dropdowns.
- `ViewCube`: React 3D orientation cube widget for one-click view framing.
- `TransformStatus`: React HUD component displaying active modal transform session info.
- `registerViewport3dCommands()`: Registers all canonical `3d.view.*`, `3d.select.*`, `3d.transform.*`, `3d.cursor.*`, `3d.snap.*`, `3d.shading.*`, and `3d.overlay.*` commands on the central command bus.
- `registerTransformTrigger(fn)`: Subscribes viewport interaction layers to modal G/R/S command invocations.
- `triggerModalTransform(mode)`: Programmatically triggers a modal transform session for the active viewport.
- `registerBoxSelectTrigger(fn)`: Subscribes viewport interaction layers to box select command invocations.
- `triggerBoxSelect()`: Programmatically triggers box select mode.
- `installAddAtCursorWrapper()`: Additive wrapper ensuring calls to `3d.add.*` without explicit location place objects at the 3D cursor position.
- `addPrimitiveAtCursor(commandId, args)`: Helper to directly invoke an add primitive command defaulting to the 3D cursor.
- `resolveAddArgsWithCursor(rawArgs)`: Resolves arguments for primitive addition with cursor defaults.
- `ADD_PRIMITIVE_COMMAND_IDS`: Constant array of all canonical primitive addition command IDs.

## 3. Decisions Made
1. **Direct Canvas Overlay in SceneView**: Mounted `<ViewportInteraction>` inside `SceneView.tsx` directly over the scene canvas whenever `editingSceneId === sceneId`. This ensures the interaction layer shares the exact pixel bounds and lifecycle of the active scene canvas, working identically both inside the full editor stage and in standalone design system demos.
2. **React Pointer Events with Pointer Capture**: All camera navigation (orbit, pan, dolly via `gestures.ts`), gizmo drags, and box selects use React pointer events (`onPointerDown`, `onPointerMove`, `onPointerUp`) with `setPointerCapture`. No raw `window.addEventListener('keydown')` or `requestAnimationFrame` calls were used, strictly respecting project lint rules and performance architecture.
3. **Modal Transform Session & Single Undo Commit**: When `3d.transform.translate|rotate|scale` (or keys G, R, S) are triggered, the focusable viewport container holds keyboard focus (`tabIndex={0}`). Keys feed into `TransformSession` (axes X/Y/Z, Shift, digits, negation, backspace), live mouse moves update preview transforms in the document store, and Enter commits the entire transformation in exactly one undo step (`documentCommands.mutate`), while Escape cancels and restores original transforms.
4. **Additive Cursor Defaults for Primitives**: Kept `src/core/3d/commands/` schemas unchanged. Implemented `installAddAtCursorWrapper()` in `src/editor/viewport3d/addAtCursor.ts`, wrapping registered add commands so callers omitting `location` place objects at `viewportStore.cursor.position` in the active scene.
5. **Apple-Level UI Restraint**: Designed `SnapBar` and `ViewCube` using solid neutral surfaces (`--ll-surface-panel`, `--ll-surface-raised`), modest border radii (3px - 4px), hairline borders (`--ll-border-color`), no glass, no blur, and strictly banned pill/capsule shapes.
