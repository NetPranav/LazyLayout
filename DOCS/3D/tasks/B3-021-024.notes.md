## 12. Fix hierarchy scale shear in `src/core/3d/outliner/__tests__/outliner.test.ts`
- **What**: Update `node_l1` scale in the 4-level hierarchy golden matrix test from `[1, 1.5, 1]` to `[1, 1, 1]` and clarify assertion messages for parenting to root object vs unparenting to null.
- **Why**: Anisotropic scale `[1, 1.5, 1]` on `node_l1` combined with child rotation on `node_l2` introduced non-orthogonal shear in the accumulated world matrix. Unparenting to null (`clearParent`) decomposes the world matrix into standard TRS without shear, which caused `worldMatrix` after unparenting to deviate from the sheared matrix. With uniform scale, the matrix is pure rotation + uniform scale (no shear), ensuring exact 1e-6 preservation under both `setParent` and `clearParent`.
- **Alternatives rejected**: Removing the `null` parent test; keeping both reparenting to the top object and unparenting to null (scene root) is valuable and now passes cleanly.
