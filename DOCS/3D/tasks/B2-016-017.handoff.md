# Task B2-016-017 Handoff: 3D Transform, Gizmos, Snapping, Pivots & Orientations

## Summary of Work
Implemented the pure TypeScript kernels for Phase 3D-016 (Gizmos and G / R / S modal transform gestures) and Phase 3D-017 (Snapping, pivots, transform orientations, and 3D cursor):
- `src/core/3d/transform/typed.ts`: non-throwing parser for modal transform commands ("g x 2", "r z 90", "s 2", "g shift+z 1.5 enter", negative values, full words, trailing enter).
- `src/core/3d/transform/session.ts`: `TransformSession` modal transform engine managing mouse translation projected at pivot depth, angle around pivot, distance ratio scale, axis/plane locks with double-press global/local toggle, numeric editing buffer (metres for translate, degrees typed and radians stored for rotate, unitless for scale), parent-inverse hierarchy preservation on `commit()`, and original transform recovery on `cancel()`.
- `src/core/3d/transform/gizmo.ts`: handle geometry generation maintaining constant on-screen size via `sizePx` and camera perspective, ray hit testing against axis line segments, planar squares, rotation rings, and scale boxes, and direct-manipulation dragging (`dragGizmo`).
- `src/core/3d/snap/snap.ts`: scalar increment snapping (`snapValue`), 3D grid snapping (`snapToGrid`), vertex, edge, and ray-triangle face snapping (`snapToVertex`, `snapToEdge`, `snapToFace`), surface normal alignment (`alignToNormal`) keeping objects like cups upright flat on surfaces, and composite multi-target priority snapping (`snapPoint`: vertex > edge > face > grid > increment).
- `src/core/3d/snap/pivot.ts`: pivot point calculations (`pivotPoint`) for `"median"`, `"individual"`, `"cursor"`, and `"active"` selections.
- `src/core/3d/snap/orientation.ts`: coordinate orientation rotation matrices (`orientationMatrix`) for `"global"`, `"local"`, `"normal"`, `"view"`, and `"cursor"`.
- `src/core/3d/snap/cursor.ts`: `Cursor3d` structure, `resetCursor()`, and `placeCursor(ray, scene)` with face snapping, normal alignment, and ground plane / ray distance fallbacks.
- Unit test suites covering all modules, including the 15-step interactive transform journey and 20 hand-computed golden snapping/pivot/orientation cases within 1e-9 tolerance.

## Public API Added
### `src/core/3d/transform/`
- `parseTransformCommand(input)`: Parses string transform commands into `{ ok, mode, axis, plane, value, error }` without throwing.
- `TransformSession`: Class managing active modal transform sessions (translate, rotate, scale) with mouse and typed numeric input.
- `createTransformSession(options)`: Factory function creating a new `TransformSession`.
- `gizmoHandles(mode, matrix, camera, sizePx)`: Generates axis arrows, plane squares, rotation rings, and scale boxes at constant on-screen pixel size.
- `hitGizmo(ray, handles)`: Raycasts against gizmo handles and returns the closest hit handle ID or null.
- `dragGizmo(handle, rayStart, rayNow, startMatrix)`: Computes the transform delta for axis, plane, ring, or uniform handles.
- `TransformMode`: Type union `"translate" | "rotate" | "scale"`.
- `TransformAxis`: Type union `"X" | "Y" | "Z"`.
- `GizmoHandle`: Interface describing geometric handle properties for hit testing.
- `GizmoTransformDelta`: Interface containing translation, rotationQuat, scale, and composite delta matrix.
- `CommittedTransform`: Interface containing `{ id, location, rotationQuat, scale }` for committed local transforms.

### `src/core/3d/snap/`
- `snapValue(value, step)`: Snaps a scalar value to the nearest multiple of step.
- `snapToGrid(point, size)`: Snaps a 3D point to a uniform or per-axis grid.
- `snapToVertex(target, objects, radiusPx, viewProj)`: Snaps a point or ray to the closest mesh vertex within tolerance.
- `snapToEdge(target, objects, radiusPx, viewProj)`: Snaps a point or ray to the closest point along mesh edges within tolerance.
- `snapToFace(ray, objects)`: Raycasts against triangle faces and returns hit point, surface normal, objectId, and face index.
- `alignToNormal(point, normal, upAxis)`: Computes a rotation quaternion that aligns an object's up-axis to a surface normal (places a cup flat on a table).
- `snapPoint(point, settings, scene)`: Evaluates enabled snap targets with strict priority: vertex > edge > face > grid > increment.
- `pivotPoint(kind, selection, cursor)`: Computes pivot point(s) for median, individual origins, cursor, or active object.
- `orientationMatrix(kind, ctx)`: Returns a 4x4 rotation matrix for global, local, normal, view, or cursor orientations.
- `Cursor3d`: Interface representing 3D cursor position and rotation.
- `resetCursor()`: Returns a default cursor positioned at `[0, 0, 0]` with identity orientation `[0, 0, 0, 1]`.
- `placeCursor(ray, scene)`: Places 3D cursor along a ray, snapping to surface faces with normal alignment, or falling back to ground plane / ray distance.

## Key Decisions Made
1. **Parent Inverse Preservation**: Converted world-space delta transformations back to local TRS using $M_{local, new} = (W_{parent} \cdot P_{inv})^{-1} \cdot W_{new}$ so children of rotated and/or scaled parents move with correct orientation and scale in world space.
2. **Numeric Buffer Conventions**: Metres are stored and committed for translate, unitless scale factors for scale, and degrees are parsed from typed input and converted to stored radians for rotate.
3. **Axis & Plane Toggling**: Pressing an axis key ("X", "Y", "Z") once locks to global orientation; pressing the same axis key again toggles to local orientation, matching Blender standard behavior.
4. **Pure Deterministic Raycasting**: Mesh snapping (`snapToVertex`, `snapToEdge`, `snapToFace`) uses pure mathematical vector algorithms (Möller–Trumbore ray-triangle intersection, point-to-segment projection) without DOM or external runtime dependencies.
5. **Strict Snapping Priority**: Enforced standard topological specificity order (vertex > edge > face > grid > increment) in `snapPoint`.
