# Tasks 3D-016 (gizmos and G/R/S) and 3D-017 (snapping, pivots, orientations): pure parts
Read the "Phase 3D-016" and "Phase 3D-017" entries in DOCS/INITIAL/ROADMAP_3D.md. Pure TS, no DOM. Folders `src/core/3d/transform/` and `src/core/3d/snap/`. Use `src/core/3d/math.ts` and `hierarchy.ts` (world matrices, parent chains).

3D-016 `src/core/3d/transform/`:
- `session.ts`: `TransformSession`: created with {mode:"translate"|"rotate"|"scale", objects: [{id, worldMatrix, parentWorldMatrix, local TRS}], viewCamera info (view matrix, projection, viewport), pivot, orientation}. Methods: `moveMouse(dxPx, dyPx)` (converts pixels to world motion at the pivot depth, in a plane facing the view; rotation uses the angle around the pivot; scale uses the distance ratio), `setAxis("X"|"Y"|"Z", {plane: boolean})` (X locks to X; Shift+X locks to the YZ plane; pressing the same axis again toggles global/local), `typeChar(c)` / `backspace()` / `negate()` building a numeric value like Blender ("2", "-1.5", "90"), `value()`, `commit() => Array<{id, location, rotationQuat, scale}>` (new LOCAL transforms: the world result converted back through the parent so a child of a rotated parent moves correctly), `cancel()` (returns the original transforms). Translate typed values are metres, rotate typed values degrees (store radians), scale unitless.
- `typed.ts`: `parseTransformCommand("g x 2")`, `"r z 90"`, `"s 2"`, `"g shift+z 1.5 enter"` -> {mode, axis, plane, value}; invalid input returns an error value (no throw).
- `gizmo.ts`: handle geometry and hit testing: `gizmoHandles(mode, matrix, camera, sizePx)` (axis arrows, plane squares, rotation rings, scale boxes) and `hitGizmo(ray, handles)` returning the handle id; `dragGizmo(handle, rayStart, rayNow, startMatrix)` returning the transform delta (axis-constrained: closest point between the ray and the axis line; plane: ray-plane; ring: angle). Constant on-screen size via `sizePx`.
Tests: a 15-step journey (G X 2 Enter; R Z 90 Enter; S 2; G with plane lock; cancel; typed negative; child of a rotated, scaled parent, etc.) with transforms checked against values you compute by hand, tolerance 1e-9; commit then cancel returns the originals exactly; typed parser table tests; gizmo hit and drag cases.

3D-017 `src/core/3d/snap/`:
- `snap.ts`: `snapValue(value, step)` (increment), `snapToGrid(point, size)`, `snapToVertex(ray or point, objects, radiusPx, viewProj)`, `snapToEdge`, `snapToFace(ray, objects)` returning {point, normal, objectId}; `alignToNormal(point, normal, upAxis)` returning a rotation quaternion that places an object on the surface upright (a cup dropped on a table sits flat); `snapPoint(point, settings, scene)` combining enabled targets with priority vertex > edge > face > grid > increment.
- `pivot.ts`: `pivotPoint(kind: "median"|"individual"|"cursor"|"active", selection, cursor)`; individual origins returns one pivot per object.
- `orientation.ts`: `orientationMatrix(kind: "global"|"local"|"normal"|"view"|"cursor", ctx)` returning a rotation matrix; `normal` uses the active face normal, `view` the view camera axes.
- `cursor.ts`: `Cursor3d` {position, rotation}; `placeCursor(ray, scene)` snaps to surfaces; `resetCursor`.
Tests: golden tests: each snap target and each pivot and each orientation on 20 hand-computed cases (tolerance 1e-9), including the cup-on-table placement.
