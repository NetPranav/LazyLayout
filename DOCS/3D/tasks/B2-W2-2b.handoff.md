## 2. Public API Added
- `bindKeymap(keymap)`: Sets `command.keybinding` for all registered `3d.*` commands from the given keymap and scopes execution to `!textEditing && editingScene3d`; clears unmapped bindings; returns unbind cleanup.
- `formatKeyBindingShortcut(binding)`: Converts a `KeyBinding` record into a normalized canonical shortcut string (e.g. "G", "Shift+A", "Ctrl+Numpad1"); skips non-keyboard bindings.
- `getKeymapById(id)`: Returns the `blenderKeymap` or `beginnerKeymap` preset object by ID.
- `applyOverlays(threeScene, settings, selection, cursor)`: Applies and updates ground grid, axes lines, object origins, face-orientation diagnostic, normals lines, wireframe on shaded, 3D cursor ring/crosshair, and selection outline meshes on a Three.js scene.
- `getOutlineColor()`: Reads active CSS selection/accent token (`--ll-pen-mark` / `--ll-label-4`) once and returns a normalized RGBA tuple, with fallback to orange.
- `AdjustLastOperationPanel`: React component for Blender-style parameter adjustment; subscribes to `lastOperation.subscribe()`, generates typed controls from `describeArgs`, and calls `adjustLastOperation`.
- `ShadingBar`: React component rendering 4 shading buttons (Wireframe, Solid, Material preview, Rendered) plus X-Ray toggle.
- `registerShadingCommands()`: Registers `3d.shading.wireframe`, `3d.shading.solid`, `3d.shading.material`, `3d.shading.rendered`, and `3d.shading.toggle_xray` on the command bus.
- `OverlaysMenu`: React component providing Blender's overlays popover dropdown for toggles.
- `registerOverlayCommands()`: Registers `3d.overlay.toggle_grid` and `3d.overlay.toggle_stats` on the command bus.
- `ViewportStats`: React component displaying object, vertex, face, triangle, and estimated memory statistics from `sceneStats`.
- `LastOperationHost`: React host component mounting `AdjustLastOperationPanel`, `ShadingBar`, `OverlaysMenu`, and `ViewportStats` with non-blocking pointer events.
- `Viewport3dDemos`: Design system demo component showing all 4 new viewport chrome controls with all interactive states.

## 3. Decisions Made
1. **Dynamic Schema Introspection in Adjust Panel**: Rather than hardcoding forms for individual operations, `AdjustLastOperationPanel` introspects Zod schemas dynamically via `describeArgs(lastOp.id)`. This automatically supports integers, floats, booleans, enums, strings, and 3D vectors across all 30+ canonical 3D commands with zero duplicated UI code.
2. **Single Stage Chrome Host Mount**: In accordance with the requirement for ONE additive mount in the stage/canvas chrome, `LastOperationHost` was created in `src/editor/viewport3d/panels/` and mounted inside `ll-stagewrap` in `CanvasChrome.tsx`. The host has `pointer-events: none` on its outer shell and `pointer-events: auto` on interactive panels, so empty space never blocks canvas interactions.
3. **Live Keymap Command Bus Binding**: Instead of dispatching shortcuts via ad-hoc local `keydown` listeners, `bindKeymap` modifies the `keybinding` property of commands in the central command registry (`defineCommand`). This guarantees that shortcuts appear automatically in View > Show keystrokes (`ScreencastKeys`), participate in command palette search, and follow the single command bus architecture.
4. **Cached Overlays Hierarchy**: Overlay helper geometries and materials (grid, axes, origins, cursor, normals, wireframe, outlines) are cached within a persistent `__ll_overlays__` group on the Three.js scene. Only transforms and visibility flags are updated on each frame pass, eliminating redundant buffer allocations and memory leaks.
5. **UI Rules Compliance**: All new UI components strictly follow LazyLayout UI rules:
   - Tailwind `ll:` prefix on every class.
   - Design tokens only (`--ll-surface-panel`, `--ll-surface-bar`, `--ll-border-color`, `--ll-text-primary`, `--ll-control-active`, etc.).
   - Rectangular containers with modest radii (`rounded-md`, `rounded-sm`), hairline borders, and soft shadows; no glass, blur, or pill/capsule shapes.
   - Interactive demos with all states registered on `/design-system` under `3D Viewport Chrome`.
