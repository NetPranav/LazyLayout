## Public API Added

### Types & Specs (`src/core/3d/primitives/types.ts`, `specs.ts`)
- `PrimitiveKind`: Union of primitive names (`"cube" | "cylinder" | "cone" | "uvSphere" | "icoSphere" | "torus" | "plane" | "circle" | "capsule" | "roundedBox"`).
- `PrimitiveMeshResult`: Geometry format `{ positions: Float32Array; indices: Uint32Array; uvs?: Float32Array }`.
- `HandleDef<P>`: Manipulation handle definition `{ id, label, position: Vec3, axis: Vec3, param: string, apply: (params: P, delta: number) => P }`.
- `PrimitiveSpec<P>`: Complete parametric primitive definition `{ kind, params, generate, handles }`.
- `cubeSpec`: Spec for cube with width, height, depth size handles.
- `cylinderSpec`: Spec for cylinder with top depth handle and side radius handle.
- `coneSpec`: Spec for cone with top depth handle and base radius handle.
- `uvSphereSpec`: Spec for UV sphere with radius handle.
- `icoSphereSpec`: Spec for icosphere with radius handle.
- `torusSpec`: Spec for torus with major and minor radius handles.
- `planeSpec`: Spec for plane on XZ with width and height handles.
- `circleSpec`: Spec for 2D fan disc on XZ with radius handle.
- `capsuleSpec`: Spec for capsule with top depth handle and side radius handle.
- `roundedBoxSpec`: Spec for rounded box with width, height, depth, and bevel handles.
- `PRIMITIVE_SPECS`: Map of all 10 canonical primitive specifications.
- `getPrimitiveSpec(kind)`: Case- and alias-insensitive lookup returning the matching `PrimitiveSpec`.

### Generators (`src/core/3d/primitives/generators.ts`)
- `circle(options)`: Pure procedural generator for fan disc with center vertex and CCW rim facing +Y.
- `capsule(options)`: Pure procedural generator for watertight, positive-volume capsule solid.
- `roundedBox(options)`: Pure procedural generator for watertight, positive-volume beveled box.

### Procedural Document Operators (`src/core/3d/primitives/procedural.ts`)
- `ProceduralSource`: Schema type for `{ kind: string; params: Record<string, unknown> }`.
- `regenerate(doc, meshId, newParams)`: Immutably re-evaluates a mesh's geometry from its spec and parameter overrides.
- `setPrimitiveParam(doc, objectId, param, value)`: Immutably sets a parameter on an object's mesh and recomputes geometry.
- `convertToPlainMesh(doc, meshOrObjectId)`: Bakes a procedural mesh into a static mesh by removing `source`.

### Commands (`src/core/3d/primitives/commands.ts`)
- `register3dPrimitiveCommands()`: Registers `3d.primitive.set_param`, `3d.add.circle`, `3d.add.capsule`, `3d.add.rounded_box`, and wraps canonical `3d.add.*` commands to store `mesh.source` while keeping 1 undo step.
- `PrimitiveSetParamSchema`: Zod schema for `{ objectId: string, param: string, value: unknown }`.
- `AddCircleSchema`: Zod schema for adding circle primitive with transform arguments.
- `AddCapsuleSchema`: Zod schema for adding capsule primitive with transform arguments.
- `AddRoundedBoxSchema`: Zod schema for adding rounded box primitive with transform arguments.

## Decisions Made
1. **Watertight Manifold Topology for Rounded Box**: Designed a projected coordinate system over a subdivided cube surface with shared vertex indexing. Adjacent faces share the exact same boundary vertex indices, ensuring zero T-junctions, exactly 2 triangles per edge (`isWatertightMesh === true`), CCW outward winding, and strictly positive signed volume.
2. **Handle Drag Parameter Isolation**: Configured `apply(params, delta)` across all 10 primitive handle definitions to strictly modify only the targeted parameter (leaving all other parameters unchanged) and clamp values to valid schema bounds.
3. **Single-Step Undo for Wrapped Canonical Add Commands**: Canonical `3d.add.cylinder` etc. are wrapped by intercepting their execution, reading the created object's mesh ID, stamping `mesh.source`, and squashing the history transaction via `useHistoryStore.getState().replaceLast` with diff patches between `docBefore` and `nextDoc`. This guarantees exactly 1 undo step per add gesture.
4. **Non-Destructive Additive Schema**: Added `source` to `Mesh3dSchema` as an optional field, preserving strict schema validation while ensuring all existing v6/v7 document fixtures continue to load unchanged.
5. **No `any` & No Unused Imports**: Replaced heterogeneous map types with `PrimitiveSpec<Record<string, unknown>>`, eliminating all `any` casts to comply with strict ESLint rules.
