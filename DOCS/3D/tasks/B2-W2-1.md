# Tasks 3D-012 (scene layer on the canvas) + 3D-018 (shading modes), plus the shared viewport store
Read the "Phase 3D-012" and "Phase 3D-018" entries in DOCS/INITIAL/ROADMAP_3D.md. Existing, read with grep: `src/core/gpu/compositor.ts` (scene contexts: `registerScene`, `setVisible`, poster on sleep, loss recovery), `src/core/render/definitions.ts` (the `scene3d` archetype currently uses `Placeholder`), `src/core/render/surfaceView.tsx` (how a canvas-backed layer lives among the page's layers), `src/core/render/archetypes/` (component shape: `ArchetypeRenderProps {layer, nodeRef, children, ...}`), `src/core/3d/viewport/settings.ts` and `shaders.ts` (written by a parallel task; read them, do not edit), `src/core/kernel/evaluate3d.ts`, `src/core/document/scene3d.ts`.
1. `src/core/render/scene3d/viewportStore.ts`: a zustand store (see `src/core/store/useCanvasViewStore.ts` for the style) shared by the whole viewport UI: `{ settings: ViewportSettings, camera: ViewCamera (from src/core/3d/camera/viewCamera.ts, written by a parallel task), selection: Selection3d (src/core/3d/pick/select.ts), cursor: Cursor3d (src/core/3d/snap/cursor.ts), snap: {enabled, target, step}, pivot, orientation, keymapId: "blender"|"beginner", editingSceneId: string|null }` with setters and a `reset()`. If a parallel module is not there yet when you start, wait by writing everything else first and re-check with `ls`; if it is still missing at the end, define the missing type locally in a clearly marked TODO and say so in the handoff.
2. `src/core/render/scene3d/buildScene.ts`: converts a document scene into a three.js scene: meshes (from inline positions/indices or decoded binary), `MeshStandardMaterial` from Material3d, lights (point/sun/spot), perspective camera from the scene's active camera, world background colour. `applyEvaluated(threeScene, evaluated3D)` updates ONLY transforms/material/light/camera values from `evaluate3D(doc, time)` (the renderer applies what the kernel evaluated and nothing else). Cache three objects by id, dispose geometry/material on removal.
3. `src/core/render/scene3d/shading.ts`: the four shading modes with three.js: wireframe (WireframeGeometry/`wireframe` material), solid (flat studio lighting: 3 fixed lights, matcap-like, optional cavity via the strings from `viewport/shaders.ts`), material preview (`RoomEnvironment` from `three/examples/jsm/environments/RoomEnvironment.js` through PMREMGenerator as the HDRI), rendered (same as material preview for now, with a clear hook `renderedHook` for the later path tracer), and the X-ray toggle (transparent + depthWrite off).
4. `src/core/render/scene3d/SceneView.tsx` and `src/core/render/archetypes/Scene3dLayer.tsx` (an `ArchetypeRenderProps` component: a div of the layer's box containing a canvas): registers with `compositor.registerScene`, reports visibility with an IntersectionObserver, creates `new THREE.WebGLRenderer({canvas, context: gl})` in `onReady`, disposes in `onRelease`, shows the poster canvas (the callback argument) while asleep, redraws on context restore, renders only when something changed (document version, camera, settings) via the project's frame scheduler (see `src/core/time/scheduler.ts`; no raw requestAnimationFrame: lint forbids it). Lazy-load three through a dynamic `import()` so pages without 3D pay nothing. Wire it into `RENDER_DEFINITIONS.scene3d` in `definitions.ts`. Off screen it must cost nothing (no render loop).
5. Command `3d.scene.insert` (title "Insert 3D scene", category "Insert", args `{width?: 480, height?: 320}`) in `src/core/3d/commands/` (create a new file `sceneInsert.ts`; do NOT edit the other files there, a parallel task writes them): creates a scene with a default cube, a camera and a light, plus a `scene3d` layer in the active frame; one undo step. Register it from the same place `register3dCommands` is called (grep for it) via a small additive call. Add "3D scene" to the Insert menu (`src/editor/components/TopBar.tsx`, grep "Insert"; follow `DOCS/UI/UI_RULES.md`: `ll:` Tailwind prefix, tokens only).
6. Entering/leaving: double-click on a `scene3d` layer sets `viewportStore.editingSceneId`; Escape leaves it (command `3d.scene.exit` with keybinding "Escape" and a `when` context key true only while editing a scene; grep `contextKeys.ts` for how to add one).
