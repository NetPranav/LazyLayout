## Creating src/core/render/scene3d/buildScene.ts
- About to: Create `src/core/render/scene3d/buildScene.ts` converting document scenes into Three.js scenes and applying evaluated kernel state.
- Why: Requirement 2 of Task B2-W2-1. Converts meshes (inline positions/indices), materials (`MeshStandardMaterial`), lights (point/sun/spot), camera (active camera PerspectiveCamera), and world background. Implements `applyEvaluated(threeScene, evaluated3D)` which updates ONLY evaluated values from `evaluate3D` deterministically. Maintains object caching by ID and cleans up GPU/CPU geometry and materials on object removal.
- Alternatives rejected: Re-instantiating the entire Three.js scene graph from scratch on every frame/evaluation tick. Recreating geometries and materials every frame causes memory leaks, frame drops, and shader re-compilations; caching with targeted `applyEvaluated` updates is high-performance and preserves Three.js buffers.

## Creating src/core/render/scene3d/shading.ts
- About to: Create `src/core/render/scene3d/shading.ts` implementing the four viewport shading modes and X-ray mode.
- Why: Requirement 3 of Task B2-W2-1 (and Phase 3D-018).
