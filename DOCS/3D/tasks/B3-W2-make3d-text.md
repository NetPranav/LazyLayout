# Tasks 3D-029 (Make 3D from a 2D layer) and 3D-026 (3D text): pure parts
Read the "Phase 3D-029" and "Phase 3D-026" entries in DOCS/INITIAL/ROADMAP_3D.md. Existing (read exports with grep): `src/core/3d/path/` (flattenPath, offsetRings, booleans, normalizeRings), `src/core/3d/sdf/` (signedDistanceField, sdfToHeight, layerOutlineRings, layerSdf), `src/core/3d/primitives/` (the `source` recipe on a mesh: `ProceduralSource`, `regenerate`), `src/core/3d/modifiers/`, `src/core/3d/commands/ops.ts` (read, do NOT edit), `three` (its `ShapeUtils.triangulateShape` earcut is available and may be used for triangulating polygons with holes), `opentype.js` 2.0.0 (font outlines; a real test font: `node_modules/next/dist/compiled/@vercel/og/Geist-Regular.ttf`).
1. `src/core/3d/make3d/extrude.ts`: `extrudeRings(rings, {depth, bevel: {size, segments, profile: "round"|"chamfer"|"concave"}})` -> MeshData ({positions, indices, uvs}), watertight (every edge shared by exactly two triangles), outward normals, front and back caps triangulated with holes, the bevel built as rings of the offset outline (use `offsetRings` for the inset). `lathe.ts`: `latheRings(profile points, {segments, axis})`. `plane.ts`: a flat card with UVs for the layer's texture. `inflate.ts`: `inflateRings(rings, {depth, resolution})` -> a pillow mesh from the SDF heights (front and back surfaces joined at the outline, watertight).
2. `src/core/3d/make3d/link.ts`: extend the mesh recipe: `Mesh3d.source` may be `{kind: "make3d", params: {layerId, mode: "extrude"|"inflate"|"lathe"|"plane", ...}}` (the field exists from the primitives task: read `src/core/document/scene3d.ts`, keep it additive); `makeFromLayer(doc, layerId, mode, params)` creates the object+mesh+material (layer fill colour becomes the material baseColor) in the scene and returns the new document; `refreshLinked(doc, changedLayerIds)` rebuilds every mesh linked to a changed layer in under 100 ms for a 10-reference-shape test; commands `3d.make3d.from_layer` ({layerId, mode, depth, bevel...}), `3d.make3d.refresh`; `register3dMake3dCommands()` called next to `register3dCommands` (grep; additive). Text on the layer is left for the decal phase: just keep its id in `params.textLayerIds`.
3. `src/core/3d/text/font.ts`: `parseFont(buffer: ArrayBuffer)` with opentype.js; `glyphOutlines(font, text, size)` -> per-glyph contours as BezPath/rings; `src/core/3d/text/layout.ts`: `layoutText(font, text, {size, align: "left"|"center"|"right", tracking, lineHeight, maxWidth?})` -> ring sets positioned with advance widths + kerning, multi-line; `src/core/3d/text/mesh.ts`: `textToMesh(font, text, opts)` = layout + `extrudeRings` (depth, bevel size and resolution); a `Text3d` data block (`texts?: Record<string, {id, text, fontFamily, fontUrl?, size, depth, bevel, bevelSegments, align, tracking, lineHeight}>` additive in `scene3d.ts`, and `Object3d.type` may be "text"); commands `3d.add.text` ({text, ...}), `3d.text.set` (any field; the mesh regenerates), `3d.text.convert_to_mesh`; `register3dTextCommands()` called next to `register3dCommands`. The editor must supply the font: the command takes `fontBuffer` only in tests; production loads through `fontCache.ts` (`loadFontFor(family, weight)`: fetch the family's TTF through the Google Fonts CSS API with an old-browser User-Agent... you cannot do network in tests, so write it behind an injectable `fetchFontBuffer` function and test with the Geist file read from disk).
4. Tests: all four meshes watertight for 10 reference shapes (square, rounded rectangle, circle, L, ring with hole, star, crescent, text glyph 'O', 'B', 'S'); extrude volume equals area*depth for a straight-walled square with no bevel; glyph outlines of 'O' have two rings (outer and hole) and the area matches the font's own path area within 0.1%; layout widths equal the sum of advances; text mesh watertight for 'SALE', 'Bob', '3D'; a linked refresh takes < 100 ms (assert < 300 ms).
