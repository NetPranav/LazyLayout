# Tasks 3D-027 (Path engine for extrusion) and 3D-028 (distance fields & outlines): pure parts
Read the "Phase 3D-027" and "Phase 3D-028" entries in DOCS/INITIAL/ROADMAP_3D.md. Existing 2D path code you REUSE (read the exports with grep): `src/core/paths/pathOps.ts` (booleanPaths, pathRegion with fill rules, regionToPath, simplifyPath), `src/core/paths/vectorNetwork.ts`, `src/core/geometry/bezpath.ts` (BezPath), `src/core/editing/layerOutline.ts` (a layer's outline path) and `outlineStroke.ts`; `polygon-clipping` is installed.
1. `src/core/3d/path/flatten.ts`: `flattenPath(path: BezPath, tolerance: number): Ring[]` (adaptive subdivision of cubic and quadratic segments so the max deviation <= tolerance; closed rings; consistent winding; returns outer rings and holes with their fill rule applied: use even-odd and non-zero as asked), `ringArea`, `ringOrientation`, `normalizeRings(rings, rule)` giving {outer, holes}[] with outers counter-clockwise and holes clockwise.
2. `src/core/3d/path/offset.ts`: `offsetRings(rings, delta, {join: "round"|"mitre"|"bevel", miterLimit, arcTolerance})` (positive grows, negative shrinks; implement by offsetting each edge and resolving with polygon-clipping union, a robust and simple approach), handling holes.
3. `src/core/3d/path/booleans.ts`: thin wrappers over `booleanPaths`/polygon-clipping for rings: union/intersect/difference/xor of ring sets with a fill rule each.
4. `src/core/3d/sdf/sdf.ts`: `signedDistanceField(rings, {width, height, cellSize, origin})` returning a Float32Array (negative inside) computed exactly with a Felzenszwalb-Huttenlocher 2D Euclidean distance transform on a rasterised inside mask plus sub-cell correction from the nearest polygon edge so the error is under 0.5 px; `sampleSdf(field, x, y)` (bilinear); `sdfToHeight(field, {depth, profile})` for inflate (pillow profile: height = depth * sqrt(1 - (1 - d/dmax)^2) style, document the formula).
5. `src/core/3d/sdf/layerSources.ts`: `layerOutlineRings(doc, layerId, tolerance)` (calls the existing outline code, flattens), `layerSdf(doc, layerId, opts)`. A GPU texture of a layer and its ledger entry come in the UI wave: leave a clear `TODO`-free interface `LayerTextureSource {layerId, width, height, pixels?: Uint8Array}` type only.
6. Tests: flatten error <= tolerance on a circle, an S-curve and a text-like glyph path (compare against a dense reference); golden areas for booleans and offsets on 20 shapes (square, L, ring with hole, star, crescent, overlapping circles...: derive areas analytically where possible; offset of a square by d has area (s+2d)^2 minus rounded-corner correction for "round": (s^2 + 4sd + pi d^2)); holes by both fill rules; SDF error under 0.5 px on 10 shapes (compare to an exact point-to-polygon distance at 200 random points), SDF sign correct inside/outside, sdfToHeight monotone from edge to centre.
