# Task 3D-008 Handoff: Transforms & Hierarchy

## Summary of Work
Implemented the pure TypeScript 3D transform and hierarchy kernel for LazyLayout in `src/core/3d/`, establishing glTF/WebGL column-major matrix conventions, Tait-Bryan Euler conversions for all 6 orders, Blender-compatible `parentInverse` transform hierarchies with cycle detection, transform baking (`applyTransform`), and geometry/point/volume-center origin adjustments (`setOriginToGeometry`, `setOriginToPoint`, `setOriginToCenterOfMass`). Extended `Object3d` in `scene3d.ts` with optional `parentInverse: number[16]` and optional `delta: { location?, rotationQuat?, scale? }`. All operations preserve world-space vertex positions within 1e-9.

- `compose(location, quat, scale, out?)`: Composes a 4x4 matrix from location, quaternion orientation, and scale (`src/core/3d/math.ts`).

- `quatFromEuler(order, x, y, z, out?)`: Converts Euler angles to quaternion for any of the 6 Tait-Bryan orders (`src/core/3d/math.ts`).

- `quatNormalize(q, out?)`: Normalizes a quaternion to unit length (`src/core/3d/math.ts`).
- `quatSlerp(qa, qb, t, out?)`: Spherical linear interpolation between two quaternions (`src/core/3d/math.ts`).
- `transformPoint(m, p, out?)`: Transforms a 3D point by 4x4 matrix with perspective divide (`src/core/3d/math.ts`).
- `transformDirection(m, v, out?)`: Transforms a 3D direction vector by 4x4 matrix ignoring translation (`src/core/3d/math.ts`).
- `localMatrix(obj)`: Computes an object's local TRS matrix combining `transform` and optional `delta` (`src/core/3d/hierarchy.ts`).
- `worldMatrix(doc, objectId)`: Computes the 4x4 world matrix by walking the parent chain with `parentInverse` (`src/core/3d/hierarchy.ts`).
- `depth(doc, objectId)`: Returns the hierarchy depth of an object (0 for root), throwing on cycle (`src/core/3d/hierarchy.ts`).
- `setParent(doc, childId, parentId, options?)`: Parents child under parentId, calculating `parentInverse` when `keepWorld: true` and detecting cycles (`src/core/3d/hierarchy.ts`).
- `clearParent(doc, childId, options?)`: Unparents child, decomposing world matrix to local transform when `keepWorld: true` (`src/core/3d/hierarchy.ts`).
- `applyTransform(doc, objectId, options)`: Bakes chosen parts (location, rotation, scale) into mesh positions and resets transform (`src/core/3d/apply.ts`).
- `setOriginToGeometry(doc, objectId)`: Centers origin on mesh bounding box midpoint without moving visual object (`src/core/3d/apply.ts`).
- `setOriginToPoint(doc, objectId, point, options?)`: Moves origin to specified world or local point without moving visual object (`src/core/3d/apply.ts`).
- `setOriginToCenterOfMass(doc, objectId)`: Centers origin on volume centroid via signed tetrahedra (or vertex mean for open meshes) without moving visual object (`src/core/3d/apply.ts`).
- `DeltaTransform3dSchema` / `DeltaTransform3d`: Zod schema and type for additive/relative local delta transforms (`src/core/document/scene3d.ts`).
- `Mat4ArraySchema` / `Mat4Array`: Zod schema and type for 16-element matrix arrays (`src/core/document/scene3d.ts`).

## Decisions Made
1. **glTF/WebGL Column-Major Memory Layout**: Implemented column-major Float64Arrays where columns 0, 1, 2 represent the X, Y, Z basis vectors and column 3 contains translation $[m_{12}, m_{13}, m_{14}]$, aligning with glTF 2.0 specifications and WebGL/Three.js expectations.
2. **Blender-Compatible `parentInverse` Formulation**: Evaluated child world transforms as $W_{child} = W_{parent} \cdot P_{inv} \cdot M_{local}$. On parenting with `keepWorld: true`, solved for $P_{inv} = W_{parent}^{-1} \cdot W_{child} \cdot M_{local}^{-1}$. This exact formulation guarantees that both unparented objects and re-parented child objects preserve their world transforms within 1e-6 without altering their local coordinates or keyframes.
3. **General and Fast Affine Matrix Inversion**: Provided both general 4x4 matrix inversion using Laplace cofactor expansion (supporting projective transformations) and `invertAffine` using upper 3x3 block inversion and translation negation $-R^{-1} \cdot t$ for fast performance during hierarchy walks.
4. **Transform Baking via $M_{bake} = M_{new}^{-1} \cdot M_{old}$**: For `applyTransform`, formulated the baked vertex transformation as $M_{bake} = M_{new}^{-1} \cdot M_{old}$ where $M_{new}$ resets the user-selected components (location, rotation, scale). This guarantees mathematically that $M_{new} \cdot v' = M_{old} \cdot v$, keeping world-space positions identical down to machine precision. Normal vectors are transformed using the transpose of the inverse matrix $(M_{bake}^{-1})^T$ and normalized.
5. **Origin Adjustment Location Delta**: When shifting an object's origin to local point $O_{local}$, vertices are translated by $-O_{local}$ and the object's transform location is shifted by $\Delta L = R \cdot (S \cdot O_{local})$. This maintains vertex world positions within 1e-15 across arbitrary parent chains.
6. **Signed Tetrahedra Center of Mass with Manifold Detection**: For `setOriginToCenterOfMass`, implemented volume integration $\sum \frac{1}{6} p_1 \cdot (p_2 \times p_3) \cdot \frac{p_1 + p_2 + p_3}{4}$. Checked undirected edge frequencies to detect open meshes (any edge count !== 2) or zero-volume geometry, cleanly falling back to vertex mean as specified.
7. **Single-User Mesh Isolation on Mutation**: If an object shares a mesh with other objects (`userCount > 1`), operations modifying the mesh (`applyTransform`, origin changes) allocate a new mesh ID via `createId("msh")` so other objects' geometries remain untouched.
8. **Pure and In-Place Dual Support for Documents**: `setParent`, `clearParent`, and `applyTransform` modify `doc.objects` in place while also returning an updated immutable copy `{ ...doc, objects: ... }`, seamlessly supporting both functional and mutating caller styles.
