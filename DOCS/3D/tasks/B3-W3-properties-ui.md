# Tasks 3D-022 (Properties editor), 3D-023 (Looks), 3D-030 UI (Modifiers section)
Read the entries "3D-022", "3D-023", "3D-030" in DOCS/INITIAL/ROADMAP_3D.md, `DOCS/UI/UI_RULES.md`, `DOCS/UI/WORKER_RULES.md`. Existing: the right panel's 2D | 3D switch (`src/editor/panels/details/inspectorDimension.ts`, `src/editor/shell/RightPanelConnected.tsx`, `src/editor/panels/details/sections/SurfaceSections.tsx` and `surfacePresets.ts`: the 2.5D "Surface" sections, a good model for Simple faces), `src/editor/shell/right-panel/` (section config types), `src/core/document/scene3d.ts` (every data block), `src/core/3d/modifiers/` (registry, `3d.modifier.*` commands), `src/core/3d/primitives/` (`3d.primitive.set_param`), the 3D commands in `src/core/3d/commands/` (`3d.object.set_location/rotation/scale`, `3d.material.set`...), the viewport store (selection), UI components in `src/editor/components`. Other tasks edit `src/editor/panels/layers/*`, `src/editor/viewport3d/*`, the stage: do NOT touch those.
1. With a 3D selection (an object selected in the viewport store while editing a scene), the right panel's 3D side becomes Blender's Properties editor: tabs for **Object** (name, location/rotation (Euler shown, quaternion stored)/scale, parent, visibility), **Modifiers**, **Physics** (a stub tab that says what comes later, with the 2.5D surface physics sections as its Simple face for a 2D layer), **Material** (PBR fields, slots, shared count and Make single user), **Object data** (Mesh: vertices/faces counts and the primitive's parameters from `source`; Light: type, colour, power, size, spot angle; Camera: fov, near/far, ortho; Armature: bone list), **Constraints** (stub), **World** (colour, ambient/HDRI strength), **Render** (a stub with quality tier from `src/core/gpu/tiers.ts`). Build it as new files in `src/editor/panels/details/properties3d/` (`Properties3d.tsx`, one file per tab) and mount it from `RightPanelConnected.tsx` in ONE additive branch.
2. Two faces per tab: **Simple** (looks strip + 4–6 plain-word controls) and **Pro** (every field of the data block, via a generic field renderer driven by the zod schema's `def`, so every data-block field is reachable). A Simple/Pro toggle at the top (persist like the other dimension switch). Every write goes through a typed command, one undo step per gesture (number fields commit on Enter/blur; drags coalesce into one step).
3. **Looks (3D-023)** in `src/core/3d/looks/` (pure) and the UI: a look = `{id, name, section: "material"|"light"|"physics"|"modifier"|"animation"|"interaction", values: Record<path, value>, sizing?: rules}`; `applyLook(doc, targetIds, lookId)` scales sizing rules to the object (depth from its smallest bounding side, light power from scene size); a built-in set (material: matte, glossy plastic, brushed metal, glass, rubber, glow; light rig: studio three-point, soft top light, dramatic rim; modifier: mirrored, arrayed row, shell) plus user looks saved with "Save as look" (stored in the document `looks` table, additive optional on the document root: add to the schema and the references check; keep old documents loading); commands `3d.look.apply`, `3d.look.save`, `3d.look.delete`; a thumbnail strip `LooksStrip.tsx` at the top of each Simple tab with an offline-rendered thumbnail (render once with the shared compositor at 96 px, cache by look id + target shape; a fast flat-colour fallback when no GL).
4. **Modifiers section**: add (menu of the registry), reorder by drag, hide (viewport/render toggles), apply, delete, per-modifier parameters from its zod schema (keyframe diamonds are a later phase; leave the slot).
5. Demos on `/design-system`, decisions appended to `DOCS/UI/DECISIONS.md`, no raw window keydown / requestAnimationFrame / sync setState in effects (eslint enforces).
6. Tests: unit tests for looks (applying a look to 5 objects of different sizes gives proportional results: assert the sizing rule numbers; save then apply round-trips), the generic field renderer picks controls by schema type; an e2e spec `tests/e2e/properties3d.spec.ts`: select the default cube, see the Object tab, set location X to 2 and one undo restores; open Modifiers, add Mirror, hide it with its toggle; Material tab: apply "Glossy plastic" look and the material roughness changes; select the light and see power and colour.
