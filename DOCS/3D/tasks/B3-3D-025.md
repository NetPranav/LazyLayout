# Task 3D-025: Primitives with parameters & handles (pure part)
Read the "Phase 3D-025" entry in DOCS/INITIAL/ROADMAP_3D.md. Existing: `src/core/3d/commands/primitives.ts` (cube, uvSphere, cylinder, cone, plane, torus, icosphere generators returning {positions, indices}) and `ops.ts` (the add commands); read them, do NOT edit them: build the parametric layer in a NEW folder `src/core/3d/primitives/`.
1. `specs.ts`: one `PrimitiveSpec` per kind: cube, cylinder, cone, uvSphere, icoSphere, torus, plane, circle, capsule, roundedBox. Each has: `kind`, a zod `params` schema (with sensible defaults and ranges: sides 3..256, rings, radius, depth, bevel/segments, subdivisions, major/minor radius), `generate(params) => {positions: Float32Array, indices: Uint32Array, uvs?: Float32Array}` (reuse the existing generators where they exist; write circle (a fan disc), capsule (cylinder + hemispheres) and roundedBox (box with rounded edges, `bevel` and `segments`) yourself), and `handles(params): HandleDef[]` where a handle is {id, label, position (local Vec3), axis (local unit Vec3), param: string, apply(params, delta along axis) => new params} (cylinder: a top handle that changes `depth`, a side handle that changes `radius`; sphere: radius; torus: major and minor; box: three size handles).
2. `procedural.ts`: the link between an object's mesh and its recipe: `ProceduralSource = {kind, params}` stored as an optional `source` field on the Mesh3d data block (add `source: z.object({kind: z.string(), params: z.record(z.string(), z.unknown())}).optional()` to `Mesh3dSchema` in `src/core/document/scene3d.ts`, additive; old documents load unchanged); `regenerate(doc, meshId, newParams)` returns a new document with the mesh rebuilt from the spec (immutable); `setPrimitiveParam(doc, objectId, param, value)`; `convertToPlainMesh(doc, meshId)` drops `source`.
3. `commands.ts`: typed commands `3d.primitive.set_param` ({objectId, param, value}, one undo step, adjustable like the other add commands) and `3d.add.circle`, `3d.add.capsule`, `3d.add.rounded_box` (add objects whose mesh carries `source`); register through `defineTypedCommand` (category "3D") with `register3dPrimitiveCommands()`, called next to `register3dCommands` (grep for it; additive). The existing `3d.add.cylinder` etc. should also record `source` when created: do that by wrapping from the new file (do not edit ops.ts): `register3dPrimitiveCommands` re-registers those ids with a wrapper that adds `source` after the original run (look at how `src/editor/viewport3d/addAtCursor.ts` wraps commands for the pattern).
4. Tests: each spec's generated vertex positions match golden values you derive by hand for a small parameter set (cube corners, cylinder with 4 sides, circle with 4 sides, torus 4x4), watertight (every edge shared by exactly two triangles) for the closed ones, indices in range, outward-facing normals (signed volume > 0), a handle drag changes exactly its param, regenerate after `set_param` equals generating with the new params, undo restores.
