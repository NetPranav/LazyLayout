# Tasks 3D-025 UI (Add menu and on-object handles) and 3D-026 UI (3D text)
Read the entries "3D-025" and "3D-026" in DOCS/INITIAL/ROADMAP_3D.md, `DOCS/UI/UI_RULES.md`, `DOCS/UI/WORKER_RULES.md`. Existing: `src/core/3d/primitives/` (specs, `handles(params)`, `3d.primitive.set_param`, `3d.add.circle|capsule|rounded_box`), `src/core/3d/text/` (parseFont, layoutText, textToMesh, `3d.add.text`, `3d.text.set`, `3d.text.convert_to_mesh`, fontCache with injectable fetch), `src/core/3d/keymap/` (Blender keymap has `3d.menu.add` on Shift+A), `src/editor/viewport3d/` (ViewportInteraction.tsx, GizmoOverlay.tsx, SnapBar.tsx: read how overlays are mounted inside the scene's hit box). You MAY add new files in `src/editor/viewport3d/` and make ONE additive mount edit in `ViewportInteraction.tsx`; other tasks edit `src/editor/panels/*` and the stage: do NOT touch those.
1. **Add menu** (`AddMenu3d.tsx`): Shift+A opens (command `3d.menu.add`, register it if missing, `when` only while editing a scene) a Blender-style menu at the pointer: Mesh (Cube, Plane, Circle, Cylinder, Cone, UV Sphere, Ico Sphere, Torus, Capsule, Rounded Box), Text, Light (Point, Sun, Spot), Camera, Empty; plus an "Add" button in the viewport's header strip (next to the SnapBar). Each item runs the matching `3d.add.*` command at the 3D cursor (the cursor wrapper exists in `addAtCursor.ts`). Menu navigable by arrows and typing to search; Escape closes.
2. **Handles on the object** (`PrimitiveHandles.tsx`): for the selected object whose mesh has a `source`, draw each handle from `handles(params)` as a small diamond in the SVG overlay (constant pixel size; project with the viewport camera; scale pointer positions by the stage zoom: see common.md), drag along its axis (ray-to-axis closest point, like the gizmo's `dragGizmo`) updating the param live through `3d.primitive.set_param` coalesced into ONE undo step per drag (use the adjust-last-operation / transaction pattern in `src/core/3d/commands/lastOperation.ts` and `src/core/store/useDocumentStore.ts` `documentCommands.transaction`), with the value shown next to the handle while dragging; Escape cancels.
3. **3D text** (`TextEditOverlay3d.tsx` and a "Text" add item): adding Text creates a text object (default "Text") and opens it for typing in place: a small floating input over the object (as the 2D text tool's editor does: `src/editor/stage/textEditRequest.ts`) whose edits run `3d.text.set`; Enter/blur ends, Escape cancels; the font comes from the project fonts: use `fontCache.loadFontFor` and, in tests, a seam `window.__LL_TEST_FONT__` (an ArrayBuffer-compatible base64 of Geist) set by the spec before load, which `fontCache` must honour when present (add that seam in a NEW file `src/editor/viewport3d/textFontSeam.ts` that installs `fetchFontBuffer`). Properties (size, depth, bevel depth and resolution, alignment, spacing) show in a small panel `TextPanel3d.tsx` next to the Adjust Last Operation panel (follow how `LastOperationHost.tsx` mounts) while a text object is selected; "Convert to mesh" button.
4. Demos on `/design-system`, decisions appended to `DOCS/UI/DECISIONS.md`.
5. Tests: unit tests for pure helpers; an e2e spec `tests/e2e/add3d.spec.ts`: enter a scene, press Shift+A (use the real keyboard through the command dispatcher), choose Cylinder from the menu: an object exists at the cursor; drag its height handle and the `depth` param increases and one undo restores it; add Text, type "SALE" through the overlay (with the test font seam) and the text block's string and mesh vertex count > 0, Convert to mesh removes `texts` link.
