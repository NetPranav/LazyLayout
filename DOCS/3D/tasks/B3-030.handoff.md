## Public API Added

### Schema (`src/core/document/scene3d.ts`, `schema.ts`)
- `Modifier3dSchema`: Zod schema validating modifier definitions `{ id, type, name?, enabled?, renderEnabled?, params }`.
- `type Modifier3d`: Inferred TypeScript type for a modifier instance.

### Types & Registry (`src/core/3d/modifiers/types.ts`, `registry.ts`)
- `MeshData`: Geometry container `{ positions: Float32Array, indices: Uint32Array, uvs?: Float32Array, normals?: Float32Array }`.
- `ModifierDefinition<TParams>`: Contract for modifier registration `{ type, label, schema, params?, evaluate }`.
- `computeVertexNormals(positions, indices)`: Computes normalized vertex normals from triangle cross products.
- `cloneMeshData(mesh)`: Allocates fresh typed array copies of a MeshData instance.
- `evaluateMirror(mesh, params)`: Evaluates mirror modifier across x/y/z axis with merge distance and bisect support.
- `evaluateArray(mesh, params)`: Evaluates array modifier with relative/constant offsets and vertex welding.
- `evaluateSolidify(mesh, params)`: Evaluates solidify modifier creating a closed watertight shell with flipped inner wall.
- `evaluateTransform(mesh, params)`: Evaluates transform modifier with vertex scaling, Euler XYZ rotation, and translation.
- `evaluateDisplace(mesh, params)`: Evaluates displace modifier along normals using deterministic procedural 3D value noise.
- `MODIFIER_DEFINITIONS` / `MODIFIER_REGISTRY`: Record map of all registered modifier definitions.
- `getModifierDefinition(type)` / `getModifierDef(type)`: Resolves a modifier definition by type string.
- `registerModifierDefinition(def)` / `registerModifier(def)`: Adds a new modifier definition to runtime registry.

### Stack & Document Helpers (`src/core/3d/modifiers/stack.ts`)
- `mesh3dToMeshData(mesh)`: Converts a document `Mesh3d` to `MeshData` typed arrays.
- `stackKey(meshHash, modifiers, options)`: Computes deterministic LRU cache key for a mesh and modifier stack.
- `clearModifierCache()`: Empties the modifier evaluation LRU cache.
- `evaluateStack(mesh, modifiers, options)`: Evaluates an ordered modifier stack with LRU caching and viewport/render filtering.
- `evaluateModifiersWorker(mesh, modifiers, viewport)`: Pure core function executed by worker or directly in tests.
- `evaluateStackAsync(mesh, modifiers, options)`: Evaluates stack in background worker pool when vertexCount >= 50,000, otherwise runs inline.
- `addModifier(doc, objectId, modifier, index?)`: Immutably adds a modifier to an object's stack.
- `removeModifier(doc, objectId, modifierId)`: Immutably removes a modifier from an object's stack.
- `reorderModifier(doc, objectId, modifierId, newIndex)`: Immutably reorders a modifier within the stack.
- `setModifierParam(doc, objectId, modifierId, param, value)`: Immutably updates a modifier parameter.
- `setModifierVisibility(doc, objectId, modifierId, toggles)`: Immutably updates viewport/render visibility flags.
- `applyModifier(doc, objectId, modifierId)`: Bakes the first modifier in the stack into the object's mesh block; throws if not first.
- `applyAll(doc, objectId)`: Evaluates all enabled modifiers in the stack, bakes result into mesh block, and empties stack.

### Commands (`src/core/3d/modifiers/commands.ts`)
- `register3dModifierCommands()`: Registers `3d.modifier.add`, `3d.modifier.remove`, `3d.modifier.reorder`, `3d.modifier.set_param`, `3d.modifier.set_visibility`, `3d.modifier.apply`, `3d.modifier.apply_all` on the command bus.

## Decisions Made
1. **Array Stack Model**: Stored `modifiers?: Modifier3d[]` as an array on `Object3d` so evaluation follows array order directly (index 0 first), matching Blender modifier stack semantics.
2. **First-Only Modifier Apply**: Followed Blender's rule that individual modifier apply (`applyModifier`) is only permitted on the first modifier in the stack (index 0). Attempting to apply a modifier lower in the stack throws an explicit error, guiding the user to reorder first or use `applyAll`.
3. **Solidify Shell Closure**: Built automatic boundary-edge detection for solidify: closed watertight surfaces (like cubes or spheres) produce double-walled hollow solids, while open surfaces (like planes or sheets) bridge outer and inner boundary edges with side rim quads, producing watertight volumes.
4. **Pure Deterministic Noise**: Implemented 3D value noise using a 32-bit integer hash and quintic smoothing with zero external dependencies to guarantee identical vertex displacement across scrubbing and platforms.
5. **Path Resolution Dual Compatibility**: `apply3DProperty` and `get3DProperty` check if `target.modifiers` is an array or object map. When array, it locates by `m.id === modId` and sets/gets `m.params[param]` (or top-level properties like `enabled`), while preserving compatibility with any legacy object-map structures.
6. **Worker Offloading Threshold**: `evaluateStackAsync` offloads to `jobPool().run("modifiers.eval", ...)` when `vertexCount >= 50000` and `jobPool()` is available. When `jobPool()` is null (Node.js/testing environments) or vertexCount < 50,000, it evaluates synchronously inline.
