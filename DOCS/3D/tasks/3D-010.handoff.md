## Public API Added
- `is3DPath(path: string): boolean`: Checks whether a path string starts with the canonical `"3d:"` prefix.
- `parse3DPath(path: string): Parse3DPathResult`: Parses a path into `{ table, id, rest }` or returns a descriptive validation error.
- `format3DPath(table: Valid3DTable, id: string, rest: string): string`: Formats table, entity id, and rest into a canonical 3D path string.
- `get3DInterpolationMethod(path: string, val0?: PropValue, val1?: PropValue): InterpolationMethod`: Infers interpolation method (`slerp`, `vector`, `color`, `numeric`, `discrete`) for 3D properties.
- `apply3DProperty(target: Record<string, unknown>, rest: string, value: unknown): void`: Mutates a 3D data-block target with a resolved property value.
- `get3DProperty(target: Record<string, unknown>, rest: string): unknown`: Reads a nested property from a 3D data block according to its path.
- `describe3DDiff(a: Evaluated3DState, b: Evaluated3DState, tolerance?: number): string[]`: Compares two evaluated 3D states with tolerance (default 1e-9) and returns an array of differing paths.
- `evaluate3D(doc: MotionDocument, time: number, compositionId?: string, inputs?: EvaluateInputs): Evaluated3DState`: Evaluates all 3D tables at `time` with animated tracks resolved and computes object `worldMatrices`.
- `synthesize3DQuaternions(doc: MotionDocument, props: ResolvedProps): ResolvedProps`: Synthesizes `transform.rotationQuat` from animated Euler tracks in `evaluate()`.

## Decisions Made
1. **Track Path Schema Loosening**: In `src/core/document/references.ts`, clip tracks with `3d:` paths are validated against 3D path syntax (`parse3DPath`) and target entity existence, bypassing the 2D layer property registry check (`checkPath`) without bumping schema version v7.
2. **Quaternion Track Handling**:
   - Explicit `transform.rotationQuat` tracks use spherical linear interpolation (`slerp`) via `quatSlerp` / `interpolateValue("slerp")`.
   - Euler angle tracks (`transform.rotationEuler.{x,y,z}`) interpolate numerically and are converted into unit quaternions via `quatFromEuler("XYZ")` after interpolation.
   - If both Euler and direct quaternion tracks exist, the direct quaternion track wins according to grammar priority.
3. **Parity Diff Structure**: `describe3DDiff` compares numbers against `tolerance = 1e-9`, handles recursive arrays and Float64Array views, and returns clean path identifiers (e.g. `objects/cube/transform/location[0]`, `materials/mat/roughness`, `worldMatrices/cube[12]`).
4. **Scrubbing Determinism**: `evaluate3D` operates purely on immutable clones without maintaining any persistent or hidden module state, guaranteeing identical output regardless of the order in which frames are evaluated.
