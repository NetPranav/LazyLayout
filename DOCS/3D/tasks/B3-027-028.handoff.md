## 2. Public API Added

### Path Engine (`src/core/3d/path/`):
- `signedRingArea(ring: readonly Point2D[]): number`: Signed polygon area via shoelace formula (+ is CCW, - is CW).
- `ringArea(ring: readonly Point2D[]): number`: Absolute area of a polygon ring.
- `ringOrientation(ring: readonly Point2D[]): "ccw" | "cw"`: Winding orientation of a closed ring.
- `closeRing(pts: readonly Point2D[]): Ring`: Closes a polygon ring so first point equals last point.
- `ringSetWinding(rings: readonly Ring[], x: number, y: number): number`: Ray-casting winding number of a multi-ring polygon at continuous coordinate (x, y).
- `normalizeRings(rings: readonly Ring[], rule?: FillRule): NormalizedPolygon[]`: Normalizes rings into `{ outer: Ring; holes: Ring[] }[]` with outers CCW and holes CW.
- `flattenPath(path: BezPath, tolerance?: number, rule?: FillRule): Ring[]`: Adaptively flattens quadratic and cubic curves to max deviation <= tolerance with consistent winding.
- `offsetPolygon(poly: NormalizedPolygon, delta: number, options?: OffsetOptions): NormalizedPolygon[]`: Offsets polygon with round, mitre, or bevel joins.
- `offsetRings(rings: readonly Ring[] | readonly NormalizedPolygon[], delta: number, options?: OffsetOptions): Ring[]`: Offsets a set of rings (+ grows outer / shrinks holes, - shrinks outer / grows holes).
- `booleanRingsPolygons(a, b, op, ruleA?, ruleB?): NormalizedPolygon[]`: Boolean operations returning `{ outer, holes }[]`.
- `booleanRings(a, b, op, ruleA?, ruleB?): Ring[]`: Boolean operations returning flat `Ring[]`.
- `unionRings(a, b, ruleA?, ruleB?): Ring[]`: Union of two ring sets.
- `intersectRings(a, b, ruleA?, ruleB?): Ring[]`: Intersection of two ring sets.
- `differenceRings(a, b, ruleA?, ruleB?): Ring[]`: Difference of two ring sets (a minus b).
- `xorRings(a, b, ruleA?, ruleB?): Ring[]`: Symmetric difference (XOR) of two ring sets.

### Distance Fields & Layer Sources (`src/core/3d/sdf/`):
- `edt1d(f: Float64Array, n: number): Float64Array`: 1D Felzenszwalb-Huttenlocher squared distance transform.
- `edt2d(grid: Float64Array, width: number, height: number): Float64Array`: 2D Felzenszwalb-Huttenlocher EDT on grid.
- `signedDistanceField(rings: readonly Ring[], options: SdfOptions): SdfField`: Generates signed distance field (negative inside) with sub-cell edge correction.
- `sampleSdf(field: Float32Array | SdfField, x: number, y: number, opts?): number`: Bilinear continuous SDF evaluation.
- `sdfToHeight(field: Float32Array | SdfField, options: SdfHeightOptions): Float32Array`: Pillow-profile height map computation ($h = d \sqrt{1 - (1 - u)^2}$) strictly monotone from edge (0) to center (depth).
- `LayerTextureSource`: Clean interface for GPU layer textures and memory ledger tracking.
- `layerOutlineRings(doc: MotionDocument, layerId: string, tolerance?: number): Ring[]`: Extracts and flattens a layer's 2D outline into closed rings.
- `layerSdf(doc: MotionDocument, layerId: string, opts?: LayerSdfOptions): SdfField | null`: Computes SDF for a document layer with bounding box and padding.

## 3. Decisions Made

1. **Subdivision Error Certification**: Implemented de Casteljau adaptive subdivision using exact chord-distance bounds ($\delta = 0.5 \text{dist}(P_1, \text{chord})$ for quadratics; $\max(d_1, d_2)$ for cubics) rather than uniform sampling. Guaranteed maximum geometric error <= requested tolerance.
2. **Offset Architecture**: For positive offsets (dilation), edges are offset into rectangular quads and convex corners into arc fans (round), miter wedges (mitre), or bevel triangles, resolved topologically via `polygonClipping.union`. For negative offsets (erosion), complement dilation inside an expanded bounding box ($B \setminus \text{Dilate}(B \setminus S, d)$) is used to guarantee robust handling of sharp corners, vanishing features, and holes without topological degeneration.
3. **Distance Field Precision**: Discrete pixel grid quantization has ~0.7 px error. Combined the $O(W \times H)$ Felzenszwalb-Huttenlocher distance transform with a spatial bucket segment index for exact continuous edge distance. Bilinear sampling error tested and certified < 0.5 px across 200 random continuous points on 10 diverse shapes.
4. **Inflation Height Formula**: Implemented the circular-arc pillow profile $h = \text{depth} \times \sqrt{1 - (1 - u)^2}$ where $u = d_{\text{in}} / d_{\text{max}}$. Proved and tested strict monotonicity from edge ($h=0$) to center ($h=\text{depth}$).
