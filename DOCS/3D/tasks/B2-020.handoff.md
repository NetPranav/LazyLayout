# Task B2-020 Handoff: 3D Keymaps (Blender & Beginner) & Viewport Core Data (Shading & Overlays)

## Summary of Work
Implemented Phase 3D-020 (Keymaps: Blender and Beginner) alongside the pure data layers of Phase 3D-018 (Shading modes) and Phase 3D-019 (Overlays & stats) for the 3D viewport. The implementation is 100% pure TypeScript, zero DOM/React dependencies, uses strict Zod validation, and conforms strictly to canonical 3D command IDs (`B2-ids.md`).

Key achievements:
1. **Keymaps (`src/core/3d/keymap/`)**:
   - `types.ts`: `KeyBinding`, `KeymapContext`, `Keymap`, and full catalog of all 60 canonical 3D command IDs (`CANONICAL_3D_COMMAND_IDS`).
   - `blender.ts`: Blender keymap implementation covering G/R/S modal transforms, Tab edit toggle, Numpad 1/3/7/5/./0/Home view navigation, Shift+A add menu, X/Delete deletion, H/Alt+H visibility, selection tools, duplication, parenting, Shift+Z wireframe, Alt+Z x-ray, and 3D cursor reset/placement.
   - `beginner.ts`: Editor-native beginner keymap (V move, R rotate, S scale in `object` context avoiding 2D tool collisions), Delete/Backspace, Ctrl+D duplicate, Ctrl+A select all, Escape deselect, Tab, F/Home framing, Z wireframe, Shift+Z x-ray, and a complete `toolbarOnly` catalog for all remaining commands ("beginners never need a key").
   - `conflicts.ts`: Pure conflict detection (`findConflicts`) detecting overlaps (where `global` overlaps all contexts) and prioritized event resolver (`resolve`).
2. **Viewport Core (`src/core/3d/viewport/`)**:
   - `settings.ts`: `ShadingMode`, `ViewportSettings`, defaults, pure `viewportReducer` handling canonical command strings and actions, plus Zod schema and JSON (de)serialization.
   - `stats.ts`: `sceneStats(doc, sceneId)` computing objects, vertices, faces, triangles, and estimated memory from inline meshes and binary pointers. Employs coplanar adjacent triangle clustering (union-find) so a standard cube accurately evaluates to 8 vertices, 6 faces, 12 triangles.
   - `shaders.ts`: GLSL ES 3.00 (`#version 300 es`) shader constants for Solid (3-point studio lighting + curvature cavity term), Wireframe-on-shaded (barycentric), Normal visualization (mapped to RGB), Face orientation (blue front / red back), and Selection outline (inverted hull). Includes `uniformsFor(mode, settings)` returning plain uniform maps.
3. **Tests**:
   - Comprehensive test suites in `src/core/3d/keymap/__tests__/keymap.test.ts` and `src/core/3d/viewport/__tests__/viewport.test.ts` covering conflict freedom, scripted journeys, canonical coverage, reducer/serialization round-trips, cube statistics (8 vertices, 6 faces, 12 triangles), and shader contract validation.

## Decisions Made
1. **Beginner Keymap Context**: Kept unshifted V, R, S inside `context: "object"`, preventing collisions with 2D tools (where V is select, R is rectangle, and K is scale) and global save (`Ctrl+S`). All commands without key bindings in the beginner preset are exposed via `toolbarOnly` so beginners can access 100% of canonical 3D actions via toolbar buttons without keystrokes.
2. **Context Overlap Model**: Defined that `global` overlaps every context (`global`, `object`, `edit`, `modal`), whereas non-global distinct contexts (`object` vs `edit` vs `modal`) do not overlap. This accurately models mode-specific key behaviors without false conflict positives.
3. **Planar Face Clustering**: Triangle meshes in MDM store triangulated indices. To evaluate faces accurately (e.g. 6 faces on a cube with 12 triangles), `countPlanarFaces` groups connected coplanar triangles with identical plane equations via a disjoint-set union-find data structure.
4. **Shader Contracts**: Structured every shader with an explicit `#version 300 es\n` declaration, documented uniforms in JSDoc, and explicit matching `uniform ...` declarations in the GLSL body.
