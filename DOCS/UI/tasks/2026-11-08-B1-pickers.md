## Behaviour (copy values from P)
- **ColorPicker:** floats 8px left of the inspector, all corners rounded, morphs out of the swatch that opened it with Bouncy overshoot. Tabs Solid/Linear/Radial/Conic/Image; gradient stops bar; SB square; hue and opacity sliders; eyedropper loupe; Hex/RGB/HSL/OKLCH fields with scrub labels; Document and Token swatches (token link icon). Controlled: `value`, `onChange(hex)`, `anchorRef`, `open`, `onClose`. Writes the hex so the canvas updates.
- **FontPicker:** 304px, search, All/Sans/Serif/Mono/Display segmented control, groups In this project / System / Library, each name in its own family, live hover preview callback `onPreview(family|null)`, Upload font and Google Fonts footer, edge blur only on the list edges (no bulge), no visible scrollbar. **No weight control.**
- **FramePresetsPanel:** Custom W/H with ratio lock, presets Desktop/Tablet/Phone/Watch/Social/Print/Presentation with proportional glyphs, orientation toggle; `onPick({name,width,height})`. Opens like Insert.
- **OptionsPopover:** 280px, header 36px with title and close, rows cascade in; floats 8px from the inspector exactly like the colour picker, morphs from its trigger (`anchorRef`). Esc, outside click or the trigger closes; opening for another trigger retargets. Fields inside carry a hairline outline. Props: `open`, `title`, `anchorRef`, `onClose`, `children`.
- All: reduced motion = short opacity fade; keyboard focus ring; all 8 themes.
