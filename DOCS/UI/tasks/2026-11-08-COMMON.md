## Rules (short form)
- Tailwind classes use the `ll:` prefix, variant after the prefix (`ll:hover:`). Tokens only: no arbitrary values, no hex, no px/ms literals in TS/TSX/CSS (use tokens or named constants in the lane's own files).
- Radii 4/6/8. No glass, no pills, no `rounded-full`. Icons only through the `Icon` component. No new dependencies. Routes use the shared `labsEnabled`.
- Token names in this repo: `--ll-*` (P's `--text` = `--ll-text` etc.). P's `--lbl-N` = `--ll-label-N`, P's `--syn-*` = `--ll-syn-*`. Add lane tokens only inside your lane block in `tokens.css`/`tailwind.css` (Wave A created them).
- Motion: real springs from `src/editor/motion` (shared preset table, feel Smooth/Lively/Bouncy, Bouncy default). Reduced motion: springs and blur become a short opacity fade. No raw requestAnimationFrame, no setState in useEffect, React never owns classes/styles the motion engine writes.
- Default themes: Warm (light) and Darkroom (dark). All 8 themes must look right (Paper, White, Warm, Lilac, Noir, Dark, Graphite, Darkroom).
- Keep test hooks from `DOCS/UI/handoffs/e2e-testids.md` (`save-status`, Application menu, File / Export project file, Motion tab, `[aria-label="Motion Timeline"]`, Timeline header, and every testid in that file).
- **Engine rule:** bind only through existing stores/commands/compiler/runtime. Never edit `src/core`, `src/compiler`, `src/runtime`, `src/ai`, `src/legacy-editor`, config or `package*.json`. Missing engine piece: write a thin adapter inside your lane, and list it under "Engine changes requested" in your handoff.
- Edit only your lane's paths. Small targeted edits. **Forbidden:** eslint --fix, prettier, any mass rewrite. Keep each file's existing line endings.
- Do not edit PARITY/DECISIONS/INTEGRATION/CHANGELOG: put it in your handoff, the orchestrator merges.
- Components new to `components/` get a demo in `src/editor/design-system/demos/<Lane>Demos.tsx` (all states). Never edit `ComponentDemos.tsx`, `DesignSystemPage.tsx` or `components/index.ts` (B9 wires them; Wave A pre-creates export lines).
