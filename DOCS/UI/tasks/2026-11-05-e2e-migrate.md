## What to do

1. For each spec in your group, run it once and read why it fails. The old editor is `src/legacy-editor` (reference only); the new one is `src/editor` at route `/editor`.
2. Migrate the spec: replace old class selectors with the new hooks (`data-testid`, roles, aria-labels), update flows that changed (File menu is inside the logo menu, the timeline is in Motion mode, and so on). **Keep each test's intent and assertions.** Do not weaken, loosen or delete an assertion to make a test pass.
3. If the new UI genuinely lacks the feature a test covers (for example the legacy dock layout, tear-off panels, old command-bus UI), mark that test `test.fixme("<one-line reason>", ...)`, never delete it, and list it.
4. If a test fails because of a real bug in the app, do not hide it: leave the test strict, mark it `test.fixme` with the bug in the reason, and list it under "App bugs found".
5. Re-run your group until it is as green as honestly possible. Use `--workers=1 --timeout=60000` (the machine has little memory: one browser at a time).

## How to run (important)

Do not use `npm run test:e2e` or `playwright.config.ts` as is (the installed browser is only the `chromium-1248` build; the config's webServer command breaks on Windows). Create `pw-<group>.config.ts` in the repo root with:

```ts
import base from "./playwright.config";
import { defineConfig } from "@playwright/test";
import fs from "node:fs"; import path from "node:path";
const root = path.join(process.env.LOCALAPPDATA!, "ms-playwright");
const dir = fs.readdirSync(root).find((d) => d.startsWith("chromium-1248"))!;
export default defineConfig({ ...base,
  projects: [{ name: "chromium", use: { browserName: "chromium", launchOptions: { executablePath: path.join(root, dir, "chrome-win64", "chrome.exe") } } }],
  webServer: { command: "echo reuse", url: "http://localhost:3000", reuseExistingServer: true, timeout: 30000 },
  reporter: "line" });
```

and run `npx playwright test -c pw-<group>.config.ts tests/e2e/<file>.spec.ts --workers=1 --timeout=60000`. **Delete your config file and any scratch files from the repo root when you finish.** The Next dev server is already running on http://localhost:3000: never start `next dev` or `next build`. Lab routes (`/design-system/...`, `/editor/*-lab`) may 404 if labs are off: check once and report.
