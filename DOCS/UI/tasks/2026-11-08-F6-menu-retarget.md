# Task F6: menus and popovers slide to the next trigger instead of closing and reopening (audit the design file first)

Read `DOCS/UI/tasks/2026-11-08-COMMON.md` first. **Start only after `DOCS/UI/handoffs/2026-11-08-*F5*.md` exists** (F5 owns the same component files until then). User feedback (2026-11-08): when a menu or popover is open and the user opens another one, the open box must slide/morph to the new place (retarget) instead of closing and then opening again from scratch. The worker must first analyse the design file thoroughly, then make the app match it exactly.

## Phase 1: audit (write it down before coding)
Read `DOCS/UI/design/editor-design-mode-blocks-dark.html` and write `DOCS/UI/handoffs/2026-11-08-menu-audit.md`: a table of EVERY menu, dropdown, popover, flyout and panel that opens from a trigger (top-bar File/Edit/View and mode menus, page switcher, Ship popover, theme picker, inspector selects/dropdowns, colour picker, font picker, options popover (`ll-more`: "another section retargets"), Canvas settings `#vpop`, Insert, AI box, frame presets, Spotlight, context menus, timeline menus, layers page selector and row actions, easing popover). For each: what opens it, where it is placed, how it opens (morph from trigger, springs from the shared table, blur, row stagger, icon wiggle, highlight stretch), how it closes, and **what happens when another trigger of the same family is activated while it is open** (grep `placeSub`, `openSub`, `swapSub`, `closeSub`, `retarget`, `swap`, `glide`, `glideW`, `glideH`, `ll-more`, `cpick`, `fpick`, `tbpop`, `llm-pop`): same box slides (position and size spring), content crossfades with blur, no close/reopen flash, and the arrow/anchor changes; also hover-intent behaviour in menu bars (moving across File -> Edit -> View while open swaps the panel in place), Esc/outside-click rules, and one-open-at-a-time rules between different families. Include P line numbers and the exact spring presets/durations.

## Phase 2: make the app match, exactly
Compare with the app in headless Playwright (Warm and Darkroom, 1440) for every row of your table and fix each difference. Required behaviours:
1. A shared retarget mechanism (add it once in `src/editor/components/Popover.tsx`/`Menu.tsx`/`ContextMenu.tsx`/`Select.tsx` or a small shared helper, design system first): if a popover/menu of the same family is already open, opening another reuses the same floating box, springs its position and size to the new anchor (Bouncy, `glideW`/`glideH` from the shared motion table), crossfades the content with blur, and never unmounts/flashes. Applies to: top-bar menus and mode menus (hover swap while open), inspector section options popovers (sliders button of another section), colour picker opened from another swatch, font picker, Insert/AI/frame presets/View options on the toolbar, timeline menus, page selector vs row actions.
2. Different families: opening one closes the other with the P rules.
3. Interruptible: reopening or switching during the spring continues from the current position/velocity (no jumps). Reduced motion: opacity fade only, no slide.
4. Keep focus handling (focus moves into the box, returns to the trigger on close), `aria-expanded`, Esc, outside click, all testids.
5. Motion only through the shared springs (`getMotion`/`panelFx`), no raw requestAnimationFrame, tokens only.
