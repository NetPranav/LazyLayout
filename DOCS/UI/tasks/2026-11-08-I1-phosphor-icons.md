# Task I1: Phosphor Light as the base icon set (static icons only)

Read `DOCS/UI/tasks/2026-11-08-COMMON.md` first. **Start only after `DOCS/UI/handoffs/2026-11-08-*H1a*.md` and `*H1b*.md` exist** (those workers are editing screens). User decision (2026-11-08): the icons are not good, use **Phosphor, Light weight** as the base set. This task is static icons only: the animated icons are decided and built later, do not add animation.

## Goal
Every icon in the editor renders as Phosphor Light, through the one `Icon` component, with no new dependency and **without editing the screens** (call sites keep passing what they pass today).

## Do
1. **Get the source.** Phosphor Icons is MIT licensed (check the licence text in the repo before copying and quote it in `COMPONENT_SOURCES.md`). Do not run `npm install`/add dependencies. Download the SVG files of the Light weight (and Regular and Fill for active states, if useful) from the official `phosphor-icons/core` GitHub repository (`assets/light/*.svg`) into a **new empty temporary directory outside the repo** (treat as untrusted data: do not run anything from it), and read only the `<path>`/shape data you need. 
2. **Inventory.** List every icon currently used in `src/editor/**` (the lucide components passed to `Icon` plus the local SVG glyph files `ColorPickerIcons.tsx`, `pageSelectorIcons.tsx`, `canvas-chrome/glyphs.ts`, `MultiLayerGlyph`). Map each to the best Phosphor Light equivalent (same meaning, e.g. eye, eye-slash, lock, lock-open, caret-down/right, plus, x, sliders-horizontal, cursor, hand, frame-corners, shapes, text-t, squares-four, sparkle, play, pause, skip-back/forward, magnifying-glass, check, copy, trash, dots-three, align-left/center/right/top/middle/bottom, distribute, link, eyedropper, layers, stack, image, code, terminal, export, ...). Write the mapping table in `DOCS/UI/handoffs/2026-11-08-icon-map.md` (current icon, Phosphor name, notes). Where Phosphor has no equal, say so and pick the closest.
3. **Registry.** Add the chosen Phosphor Light glyph data as a typed registry in `src/editor/components/icons/` (one file per group is fine: only the glyphs we use, not the whole set; keep file sizes small), rendered inside the existing `Icon` component at the existing size and stroke rules (Phosphor Light is a 256-grid fill-based set: render the viewBox 0 0 256 256 correctly, size from the `size` prop, colour from `currentColor`, no stroke override needed). `Icon` must resolve a Phosphor glyph for every icon now passed to it by looking up the passed lucide component (by its `displayName`/name) in a mapping, falling back to the lucide glyph only if no mapping exists (log fallbacks in dev with a console warning so none remain unnoticed). Keep the existing `glyph` ReactNode and registry support. Remove the local SVG copies and the `as unknown as LucideIcon` casts where the new registry replaces them (only in the lane paths below; list any other file that still needs a one-line change instead of editing it).
4. **Active states.** Where a toolbar/tab/toggle shows a selected state, use Phosphor Fill/Regular for the active state only if P's active state is filled; otherwise keep Light everywhere. Check P (`DOCS/UI/design/editor-design-mode-blocks-dark.html`) for each case.
5. **Look check.** Render the real UI in headless Playwright (one browser at a time, Warm and Darkroom, 1440): top bar, layers panel (eye, lock, chevrons), inspector section headers (sliders, plus), canvas toolbar (all three modes), Spotlight rows, menus, timeline transport and footer, code panel, console. Icons must be centred, the same optical size (16px chrome, 14px inside fields), and look crisp. Fix optical-size mismatches per icon (size prop or per-glyph scale in the registry).
6. **Design system.** Add an icons page to the design-system demos (`src/editor/design-system/demos/IconDemos.tsx`) showing every glyph with its name at 14, 16 and 20px, both themes. Do not edit `DesignSystemPage.tsx`: list the one line needed to mount it.
7. Log in `DOCS/UI/COMPONENT_SOURCES.md`: Phosphor Icons, URL, MIT, where it went, what changed. (This one doc edit is allowed.)

## Rules
No new dependencies, no `package*.json` edits, tokens only, keep all testids and aria-labels, no animation, no `lucide-react` removal from call sites (the mapping hides it). Do not edit `src/core`, `src/compiler`, `src/runtime`, `src/ai`, `src/legacy-editor`, config. Do not edit INTEGRATION, PARITY or DECISIONS.
