# Wiring Plan: Phases 53–80 (Motion Engine into the New Editor)

This document maps Stage 2 (Phases 53–80) of LazyLayout from the engine implementation (`src/core`) to the new editor UI (`src/editor`, served at `/editor`). It tracks what each phase promises, where its engine code lives, its current reachability in the new editor, and the wiring required to make it functional.

| Phase | What the roadmap promises the user can do | Where the engine code is | Reaches new editor today? | Missing wiring |
|---|---|---|---|---|
| **53 · Animation grammar: close schema gaps** | Lossless schema representation for Exit, Focus, Stagger, LayoutTransition clips; lossless `pointerMove`, `drag`, `time` triggers. Menus offer Exit, Focus, and Layout categories. | `src/core/document/motion.ts`, `migrations/v5-to-v6.ts`, `src/core/kernel/evaluate.ts`, `src/core/animation/clip-adapter.ts` | **Partly** (`src/editor/motion-model/sync.ts`, `src/editor/panels/inspectors/LayerInspector.tsx`) | Two-way binding for all 10 `CLIP_TYPES` and 12 `TRIGGERS` in `LayerInspector.tsx` and `sync.ts`; writing `{ type, trigger }` to document clips via `documentCommands.updateClip` / `addClip`. |
| **54 · Transport & one clock** | Transport bar (play, pause, timecode, loop, fps, shuttle J/K/L) controls the entire studio via a shared store outside React. Frame stepping at 24/30/60 fps. | `src/core/time/transport.ts`, `src/core/time/useTransportTime.ts` | **Yes** (`src/editor/motion-model/store.ts`, `src/editor/panels/timeline/TimelineTransport.tsx`, `src/editor/panels/timeline/TimelinePanel.tsx`, `src/editor/shell/EditorShell.tsx`) | Proved by `src/editor/motion-model/__tests__/oneClock.test.ts` and `tests/e2e/wire-54-transport.spec.ts`. Transport is the one clock; motion model mirrors `transportStore`; `transportCommands` and `transportDriver` registered in shell; UI controls route to `transport.*`. |
| **55 · Frame scheduler** | One `requestAnimationFrame` loop with ordered execution phases (input → evaluate → apply → render → overlay → stats); deterministic mode for test clock and export queue. | `src/core/time/scheduler.ts` | **Yes** (`src/editor/motion-model/store.ts`, `src/editor/stage/Artboard.tsx`, `src/editor/stage/ValueHud.tsx`, `src/editor/stage/MotionPathOverlay.tsx`, `src/editor/stage/OnionSkinOverlay.tsx`, `src/editor/panels/timeline/TimelinePlayhead.tsx`) | Proved by `src/editor/motion-model/__tests__/schedulerPhases.test.ts` and `tests/e2e/wire-55-scheduler.spec.ts`. During playback, transport advances in `evaluate`, Motion store playhead updates in `apply`, stage canvas renders in `render`, and overlays (ValueHud, MotionPathOverlay, OnionSkinOverlay, playhead) update in lockstep in `overlay`. Paused seeking/stepping applies immediately. `window.__LL_SCHEDULER__` test seam enables deterministic virtual stepping. |
| **56 · Move playback onto clock** | Timeline playhead and canvas stay in step; at most 10 React commits a second during playback. | `src/core/time/transport.ts`, `src/core/time/scheduler.ts` | **Yes** (`tests/e2e/wire-56-playback.spec.ts`: 0 timeline and 0 canvas commits over a second of playback; frame-exact needle, clock and canvas) | None. |
| **57 · Engine adapters & kernel on stage** | Pressing play animates the real layers on the canvas, eased exactly as the curves say. | `src/core/engine/stage/StageEngine.ts`, `KernelAdapter.ts`, `StageAdapters.ts` | **Yes** (`src/editor/stage/useCanvasEngine.ts`; `tests/e2e/wire-57-stage-engine.spec.ts`: 10 references x 5 times match the kernel) | Scroll-driven clips (Phase 81, Lane B) are not passed to the engine yet on the new canvas. |
| **58 · CSS / Web Animations adapter** | Simple tweens and loops run on the compositor while playing. | `src/core/engine/stage/WaapiAdapter.ts`, `StageAdapters.ts` | **Yes** (through the engine of Phase 57; `tests/e2e/wire-58-60-engines.spec.ts`) | None. |
| **59 · Scrub vs play** | Scrubbing is the kernel's; playing hands each layer to its adapter, and the hand-over changes nothing. | `src/core/engine/stage/StageAdapters.ts` | **Yes** (`tests/e2e/wire-58-60-engines.spec.ts`: paused after playing matches the kernel at five times) | None. |
| **60 · Parity overlay** | A parity badge (dev builds) turns red when an engine drifts from `evaluate()`. | `src/core/engine/stage/parity.ts` | **Yes** (`ParityBadge` in `TimelineFooter.tsx`; `tests/e2e/wire-58-60-engines.spec.ts`) | None. |
| **61 · Timeline workspace: layout** | An After Effects-style timeline under the canvas. | `src/core/timeline/*` | **Yes** (`tests/e2e/wire-61-timeline.spec.ts`: ten-step journey; work area now saved) | The new timeline trims and moves animations (clips), not composition layer bars. |
| **62 · Twirl-downs & stopwatches** | Twirl a layer down, click a stopwatch to animate any property; U / UU reveal. | `src/core/timeline/model.ts`, `timelineOps.ts` (`setStopwatch`) | **Yes** (`TimelineLayerProperties.tsx`; `tests/e2e/wire-62-stopwatch.spec.ts`) | Keyframes of properties the Motion panel does not model (skew, radius, colours) show as a count, not as diamonds on the lane. |
| **63 · Timeline navigation** | After Effects shortcuts in the timeline. | `src/core/timeline/timelineCommands.ts` | **Yes** (`tests/e2e/wire-63-navigation.spec.ts`; panel keys handed to the commands; one zoom) | None. |
| **64 · Timeline at scale** | Keyframe lanes drawn on a single virtualized HTML5 canvas (not per-keyframe DOM nodes); handles 200 layers × 20 tracks at 60 fps; hitKey detection. | `src/core/timeline/lanes.ts` | **Partly** (`src/core/timeline/lanes.ts`, `src/editor/panels/timeline/TimelineLane.tsx`) | `lanes.ts` contains the optimized canvas rendering engine, but `TimelineLane.tsx` currently renders DOM keyframe elements. |
| **65 · Nested & interaction composition tabs** | Tab strip above timeline (Main, hover/press interaction compositions, precomps); breadcrumbs; double-clicking a precomp bar opens its nested tab. | `src/core/timeline/keyframeOps.ts` (`addPrecomp`, `removeNested`), `src/core/document/compositions.ts` | **No** (`src/editor/panels/timeline/TimelinePanel.tsx`) | `TimelinePanel.tsx` lacks the multi-composition tab bar, breadcrumb navigation, and precomp row rendering. |
| **66 · Keyframing** | Auto-key record mode (changes on canvas or inspector automatically create keyframes at playhead); box select, align, distribute, scale time, copy/paste keys. | `src/core/timeline/keyframeOps.ts`, `src/core/store/useDocumentStore.ts` (`setCommitHook`, `applyAutoKey`) | **Partly** (`src/editor/panels/timeline/TimelineTransport.tsx`, `tests/e2e/auto-key-hud.spec.ts`) | Auto-key toggle is wired in `TimelineTransport`, but box-selection, align, and distribute commands need connection to timeline canvas gestures. |
| **67 · Graph editor & easing** | Value and speed graph editor (Ctrl+Shift+K) with bezier handles and spring previews; preset strip (Snappy, Smooth, Bouncy, Lazy); F9 Easy Ease. | `src/core/timeline/curves.ts`, `src/core/document/motion.ts` | **Partly** (`src/editor/panels/timeline/TimelineCurveGraph.tsx`) | `TimelineCurveGraph.tsx` renders bezier curves, but speed graph mode and spring Bounce/Time controls need full document integration. |
| **68 · Retire legacy animation panels** | Rebuild Content Browser Animation panel on document clips; remove legacy `MotionSequencer` and `AnimationSample` references across all exporters. | `src/core/animation/stackAdapter.ts` | **Partly** (`src/editor/shell/EditorShell.tsx`) | New editor uses `TimelinePanel`, but legacy `MotionSequencer` and `AnimationSample` persist in export pathways and test specs. |
| **69 · Motion paths on canvas** | Spatial motion paths on the canvas: position keyframes render as editable bezier paths; waypoint handles allow bending 2D trajectories. | `src/core/document/motion.ts` (`SpatialTrajectorySchema`, `SpatialWaypointSchema`), `src/core/timeline/keyframeOps.ts` | **Partly** (`src/editor/stage/` overlays, unverified) | Spatial schemas exist in `motion.ts` and `keyframeOps.ts`, but spatial waypoint handle manipulation on the stage canvas is unverified in the new editor. |
| **70 · Auto-key on stage & value HUD** | In record mode, dragging an element on the canvas writes keyframes; live HUD floats next to the element showing x, y, rotation, and opacity. | `src/core/timeline/keyframeOps.ts`, `src/core/editing/autoKeyHook.ts` | **Yes** (`tests/e2e/auto-key-hud.spec.ts`, `src/editor/stage/valueHud/ValueHud.tsx`) | Fully wired and verified in the new editor canvas stage. |
| **71 · Onion skin** | Ghost frames render before and after the playhead at customizable opacity based on `evaluate()`. | `src/core/kernel/evaluate.ts`, `src/core/engine/stage/onionSkin.ts` | **Partly** (`tests/e2e/onion-skin.spec.ts`, unverified) | Onion skin overlay exists in engine tests, but toggle controls are missing from the new editor toolbar/view options. |
| **72 · Anchor points & pins** | 9 preset pins plus arbitrary custom pins; rotation and scaling occur around the anchor; interactive canvas anchor handle. | `src/core/geometry/pins.ts`, `src/core/geometry/anchorTransforms.ts` | **Partly** (`src/editor/stage/AnchorOverlay.tsx`, unverified) | AnchorOverlay exists, but must respect canvas contract (drag only with modifier key); origin inspector sync needs verification. |
| **73 · Parenting & helper layers** | Pick-whip parenting independent of DOM hierarchy; null helper layers (`render.role: helper`) render dashed in Design mode and omit from Preview and export. | `src/core/geometry/parentTransforms.ts`, `src/core/document/editorOnly.ts` | **Partly** (`src/editor/stage/HelperAndParenting.tsx`, unverified) | Helper layer exclusion works in export, but pick-whip parenting UI is missing from the new Layers and Timeline panels. |
| **74 · Blend modes, adjustment layers, masks & mattes** | Per-layer CSS blend modes, backdrop-filter adjustment layers, and SVG/CSS alpha/luma masks. | `src/core/document/properties.ts`, `src/core/render/archetypes/` | **No** (unverified) | No inspector UI controls for blend modes, backdrop filters, or layer mattes exist in `LayerInspector.tsx` or `RightPanelConnected.tsx`. |
| **75 · Effect stack & motion blur** | Keyframeable effect list (blur, glow, drop shadow, displacement); velocity-based motion blur rendering. | `src/core/document/properties.ts` | **No** (unverified) | Inspector lacks effect stack management and keyframeable parameter controls for effects. |
| **76 · Property links & pick-whip** | Connect property values via `Link { target, source, map }`; drag pick-whip between properties in timeline or inspector; cycle detection (`[LINK_CYCLE]`). | `src/core/document/links.ts` (unverified) | **No** (unverified) | Pick-whip gesture and link management UI are absent from the new editor panels. |
| **77 · Expressions** | Small typed expression language (`wiggle`, `time`, `valueAtTime`, arithmetic); AST evaluator without `eval`. | `src/core/expressions/` (unverified) | **No** (unverified) | No expression input fields or expression editor exist on property tracks in the new editor. |
| **78 · States** | Built-in archetype states (idle, hover, pressed, focus, inView) and custom user states; visual state editing on canvas. | `src/core/document/schema.ts` (`StateSchema`), `src/core/store/useDocumentStore.ts` (`addState`) | **Partly** (`src/editor/panels/details/states.tsx`, unverified) | State store commands exist, but Motion workspace lacks state selector tabs and canvas state-override editing. |
| **79 · Transitions & smart animate** | Automatic spring/tween transitions between states with velocity continuity and per-property overrides. | `src/core/document/schema.ts` (`TransitionSchema`), `src/core/kernel/evaluate.ts` | **No** (unverified) | UI for authoring state transitions and tuning transition springs is not built in the new editor. |
| **80 · Animated variants & interactive components** | Component variants automatically animate on switch; interactive instance overrides. | `src/core/components/instances.ts`, `src/core/document/schema.ts` | **No** (unverified) | Component variant animation controls and interactive preview trigger testing are not wired into the new editor. |
