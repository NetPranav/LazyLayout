Right panel concepts

A   Spatial box

Box model with margin, padding and position in one diagram.

B   Instrument

Every value as a slider on a mixing-desk row.

C   Sentence

Properties read as plain sentences you edit in place.

D   State first

Preview each state and change only what differs from default.

E   Tokens first

Pick from the design system instead of typing numbers.

A takes 180px of height, and is the best for layout work.

B reads at a glance, and is less precise for typed values.

C is friendly for beginners, and is slower for experts.

D is the best for interactive states, and has a smaller space for fields.

E keeps designs consistent, and needs a design system set up.
