## Rules
- One 4px grid, solid neutrals, hairline `var(--border)`, soft shadows. Radii are `--r-sm` 4px, `--r-md` 6px and `--r-lg` 8px.
- No glass or blur materials, and no pills.
- Colours: only the theme vars. `--lbl-*` is for timeline tracks only.
- Syntax colouring uses only `--text` (keywords, weight 500), `--text2` (strings and attributes) and `--muted` (comments, italic).
- Fonts: Geist for text, `var(--mono)` for code and numbers. Icons come from the SVG sprite.
- Reuse what already exists: the playful menus (`openMenu`, submenus), the dropdowns, the `.sld` slider, `panelFx`, the mode-switch transitions and the spring engine. Match the quality of Motion mode, including its full-width bottom panel, 40px header, 28px footer and right-panel states.
