# Prototype changelog

What changed in the prototype (`editor-design-mode-blocks-dark.html` unless another file is named). The design session adds an entry for each change. The build session marks an entry `built` once it is committed in `src/editor`. Newest entries are at the top.

| Date | Change | Where in the prototype | Status |
|---|---|---|---|
| 2026-11-04 | **Motion timeline.** One combined timeline replaces the static Motion panel: layer rows (expand, mute, lock, solo, + track) with clips you move and trim, property tracks (Opacity, Position X/Y, Scale, Rotation) with a stopwatch and a value readout, keyframes you add (K or the button), select (click, Shift, marquee), drag, duplicate (Ctrl+D), delete and stretch. Working transport (start, frame step, play/pause, loop Off/Loop/Ping-pong, speed 0.25 to 2x, one `00:01.20` timecode that toggles to frames), draggable playhead and ruler scrub, Ctrl+wheel zoom, work-area handles and markers. The artboard animates from the model and is restored when you leave Motion. The right inspector follows the selection (Layer, Property, At, Value, Easing list with a live curve and x1..y2, clip Delay/Duration, actions) or shows the layer's clip summary. The floating toolbar shows Select, Hand, Add keyframe and Play preview in Motion. Springs: playhead glides, new keys pop, rows grow open, clips squash on release. The Layers badge opens Motion and flashes the layer. **Pro-editor layout pass:** taller timeline (40% of the window) with a spring splitter (double click resets); 40px header (timecode, transport with previous/next keyframe and end, Select and Split tools, snapping, speed, zoom slider and Fit, compact or comfortable tracks); 200px track column with type icons and Effect-Controls rows (live value you can drag, keyframe navigator); multi-clip layers with a Split tool; alternate row tint, hover line with time tooltip, snap flash, work-area bar over the ruler, markers; the right panel is never empty (Composition inspector, layer clip inspector, keyframe inspector). Left `Tracks` list removed (the timeline header column replaces it); Presets placeholder dropped. **Polish and steps 4 to 6 pass:** ruler labels are short (`0s`, `0.5s`, `1s`, frames in frame mode, `1:00` past a minute), never printed if they would clip, hidden under the playhead head and under a marker badge; clip names are a solid chip top left (sticky when the clip starts off screen) and the summary keys are small ticks on the clip's bottom edge; lanes have 8px more inset; track column is 224px; the empty area under the tracks is a calm drop zone ("Drag a layer here to animate it") and dragging a row from the Layers panel adds it as a track (Hero adds a frame layer with Stagger). **Graph view** (Timeline / Graph switch in the header): the selected property's value curve on the same time axis and playhead, a property list on the left, keys as points (drag for time and value, Shift or Ctrl to multi select), bezier handles for the segments of selected keys, vertical range fits the curve and holds still while dragging. **Easing** in the Keyframe inspector has Curve and Spring tabs: Curve is the preset list (now with Anticipate), a draggable-handle editor on the `.kcurve` plot (arrow keys move a focused handle) and x1..y2 fields; Spring has Response (s) and Damping sliders (Nook spring maths, evaluated in real seconds over the segment), the plotted spring with the segment end marked, a settle time note and a Test button that moves a square on that spring. **Layer inspector:** Trigger (On load, On hover, On click, On scroll into view, While scrolling) with Start, End, Scrub, Pin and a Scroll preview slider that drives the playhead; hovering or clicking the element on the artboard plays its clip; Repeat (Once, Number, Forever, Yoyo) and Stagger (frames: delay between children and From Start, Center, End, Edges, Random) both change the preview. **Export** button in the header opens a `.ppop` style panel with CSS, WAAPI, Framer Motion and GSAP tabs, code generated from the model (real keyframes, per segment easing, springs as `linear()` or a spring function), token only syntax colour, Copy with a Copied state, Download (.css or .ts) and a footer with lines, size, dependencies and a reduced motion note. The header `...` menu has Compact tracks (moved from the header), Add marker and Keyboard shortcuts. **Shortcuts:** J and L shuttle (press again for 2x, 4x, 8x), K stops while playing (and still adds a keyframe when stopped), I and O set the work area, `=` and `-` zoom, `\` fits, Shift+Left and Right step 10 frames, U reveals animated properties. `I` no longer opens Insert in Motion | Script `Motion` block before `var B=`; CSS `.tl`, `.tlrow`, `.clip`, `.kfb`, `.tlruler`, `.mtools`; markup `#bottom` (built by `motionShell()`), `#ins-key` (built by `kInspect()`) | not built **Pass 3.** Full-width timeline (Shift+T, default in Motion, remembered), driven by one shared spring panel-transition helper that also animates panel collapse and mode switches (old content slides out with a small blur, new slides in, inspector sections cascade, the mode tab highlight is a spring; reduced motion becomes a 120ms fade). Right-click menus on clips, keyframes, track headers, empty lanes and the ruler, acting on the model. Six muted label colours (--lbl-1..6 and --lbl-n-tint, light and dark sets) used only for the 3px header strip and the clip tint, with a default per layer type; the timeline mirrors the Layers panel and a frame with children is a collapsible group track. New clip look (24px bars, keyframe ticks, selected outline). One slider component for the whole file (stretching thumb, value tag, arrow keys). 28px footer with selection summary, draggable mini-map, zoom, frame rate, snapping and work-area length. Big easing editor in the right panel (240px curve, click to add points, double click to remove, Save as preset, Spring tab, looping preview). Mode menus on the active top-bar tab. |
