# Prototype changelog

What changed in the prototype (`editor-design-mode-blocks-dark.html` unless another file is named). The design session adds an entry for each change. The build session marks an entry `built` once it is committed in `src/editor`. Newest entries are at the top.

| Date | Change | Where in the prototype | Status |
|---|---|---|---|
| 2026-11-04 | **Motion timeline.** One combined timeline replaces the static Motion panel: layer rows (expand, mute, lock, solo, + track) with clips you move and trim, property tracks (Opacity, Position X/Y, Scale, Rotation) with a stopwatch and a value readout, keyframes you add (K or the button), select (click, Shift, marquee), drag, duplicate (Ctrl+D), delete and stretch. Working transport (start, frame step, play/pause, loop Off/Loop/Ping-pong, speed 0.25 to 2x, one `00:01.20` timecode that toggles to frames), draggable playhead and ruler scrub, Ctrl+wheel zoom, work-area handles and markers. The artboard animates from the model and is restored when you leave Motion. The right inspector follows the selection (Layer, Property, At, Value, Easing list with a live curve and x1..y2, clip Delay/Duration, actions) or shows the layer's clip summary. The floating toolbar shows Select, Hand, Add keyframe and Play preview in Motion. Springs: playhead glides, new keys pop, rows grow open, clips squash on release. The Layers badge opens Motion and flashes the layer. **Pro-editor layout pass:** taller timeline (40% of the window) with a spring splitter (double click resets); 40px header (timecode, transport with previous/next keyframe and end, Select and Split tools, snapping, speed, zoom slider and Fit, compact or comfortable tracks); 200px track column with type icons and Effect-Controls rows (live value you can drag, keyframe navigator); multi-clip layers with a Split tool; alternate row tint, hover line with time tooltip, snap flash, work-area bar over the ruler, markers; the right panel is never empty (Composition inspector, layer clip inspector, keyframe inspector). Left `Tracks` list removed (the timeline header column replaces it); Presets, Graph and Export placeholders dropped | Script `Motion` block before `var B=`; CSS `.tl`, `.tlrow`, `.clip`, `.kfb`, `.tlruler`, `.mtools`; markup `#bottom` (built by `motionShell()`), `#ins-key` (built by `kInspect()`) | not built |
| 2026-11-03 | **Liquid glass experiment (copy).** Panels float over a full-window canvas, and every surface (top bar, panels, menus, dropdowns, popovers, toolbar, AI box) is refracting glass, using the technique from Glisse (MIT), rebuilt in plain HTML. There is an On/Off switch in View options. It goes against UI_RULES §1 (no glass), so it is **not approved and must not be built**. Parked by the user for a future plan (see `LATER.md`) | `editor-liquid-glass.html` | parked |
| 2026-11-03 | **Trace logo.** The logo traces its outline while saving (1.6 s), with no visible "Saving"/"Saved" text. An `sr-only` `role=status` reads "Saving", then "Saved". The AI loader uses the same trace (2.4 s). Reduced motion: opacity pulse | CSS `.logo .tro`, `.tfl`, `.saving-on`, keyframes `ll-tro`/`ll-trf`, `.aiload`; markup `#menubtn`, `#saving` | not built (top bar task) |
| 2026-11-03 | **Dropdowns.** The field morphs into the list, with the current row over the field. A chosen value flies in and lands with a pop. The check moves, the chevron nudges and flips. Long lists get the bulge (scale, fade and blur at the edges), endBump, type-ahead, search with FLIP, the odometer roll and the Mixed shimmer. "Dropdown bulge" slider in View options | Script after "===== Dropdowns" | built (menus task, last retry) |
| 2026-11-03 | **Playful menus.** The trigger morphs into the menu, rows pop in with stagger and blur, the icon wiggles, the highlight stretches, and a chosen row pops. One morphing side flyout for File, Edit and View | `placeSub`, `openSub`, `swapSub`, `closeSub`, `popRow`, `mark`, `wiggle`; CSS `.menu`, `.ll-hl`, `#sub` | built (menus task, last retry) |
| 2026-11-03 | **Feel switch.** Smooth, Lively and Bouncy, with Bouncy (playful) the default. Key `ll-feel-v2` | `applyFeel`, `#feelseg` | built |
