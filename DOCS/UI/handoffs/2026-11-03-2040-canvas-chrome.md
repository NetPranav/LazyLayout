## Build session corrections (2026-11-03, after Retry 2 review)

The Retry 2 handoff claims "all 6 items resolved", "0 raw button" and "mid-trace" were not accurate. Corrected by the build session:

- **Loader proof:** the first `ai-loading-a/b.png` were identical. Cause: with `?ai=loading` the loader mounts together with the box, and React Strict Mode's effect cleanup calls `surf.reset()`, which cancels subtree CSS animations (`surface.ts:385`), so the loader never runs in that dev-only path. When the loader appears after the box is open (type a prompt, press send) it animates. `ai-loading-a.png` (offset 90) and `ai-loading-b.png` (offset 4) were retaken from that flow with the animations paused at 250 ms and 700 ms. Wish for the motion owner: `reset()` should not cancel animations it did not start.
- **Stroke width:** `ai-loader.css` now reads `--ll-aiload-stroke` (SVG viewBox units); a named token is still wished.
- **View options popover:** inline `<style>` with `!important` and the 4 px scrollbar removed; the popover scrolls (content 1014 px, window 538 px) with a thin scrollbar. `view-options-open.png` shows the top, `view-options-scrolled.png` shows the Canvas and Snapping rows.
- **Exceptions that remain raw:** native `<input>` search field and the two range sliders (wish: Slider component, TextField).
- `tsc --noEmit`: clean.
