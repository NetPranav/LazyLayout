## App Bugs Found
- None. Failures in legacy tests were due to architectural redesigns:
  - Moving away from legacy iframe stages (`iframe[title="Stage"]`) to direct DOM canvas artboards.
  - Moving away from legacy Simple/Pro form inspectors with `[data-prop-path]` to modern Design/Motion/Code mode tabs.
  - Moving away from legacy modal dialogs (`Fill colour` with Hex/OKLCH tabs) to inline controls.
  - Decoupling of sample canvas elements in `/editor` from project layer tree documents.

## Needs from the App
- **Layer selection sync**: Sample stage elements in `/editor` should synchronize selection state with the Layers panel tree and Document model.
- **Motion Persistence**: The new Motion Sequencer (`useMotionModel`) should synchronize its keyframes and clips with `useProjectStore`'s `document.clips` so timeline edits persist across reloads and save to `.lazy.json`.
- **Status bar Parity Badge**: If engine parity monitoring is intended in the new editor status bar, expose an element or badge for engine parity status.
- **Asset Seam**: Expose `window.__LL_ASSETS__` or equivalent runtime registry if E2E asset verification is required in the new UI.
