## Decisions made
- **Bottom panel height**: Adhered strictly to the prototype token `--ll-size-bottom-code-h` (200px) with hairline border (`ll:border-t ll:border-border`).
- **File tabs in bottom header**: Combined active code file tabs and an embedded Console tab in the 44px bottom toolbar (`.ph` in prototype). This gives instant access to generated component TSX, animation hooks, modular CSS, README, and compiler diagnostics in one unified bottom drawer.
- **Syntax Highlighting without new dependencies**: Implemented a pure, robust regex tokenizer inside `SyntaxHighlighter.tsx` that tokenizes keywords, types, JSX elements, strings, comments, numbers, and operators into spans styled purely via semantic tokens (`ll:text-primary`, `ll:text-secondary`, `ll:text-muted`, `ll:bg-select-bg`).
- **Bidirectional AST synchronization**: Clicking any line in `SyntaxHighlighter` fires `onLineClick` and scans layer names/IDs in `useDocumentStore`, selecting the corresponding element in `useSelectionStore` and focusing it on the canvas.
- **Exporting and Packaging**: Integrated `ZipPacker` for in-browser client-side ZIP packaging of generated files on the "Export" button click, with no server-side dependency.
- **Right-panel `#ins-code`**: Implemented exact prototype controls: Component Name (TextField), Export (Named/Default SegmentedControl), Target (React/HTML/Vue SegmentedControl), Styles (CSS modules/Tailwind/Inline Select), Props list with add/remove inputs, and Dependencies list.
