## What changed
- `src/editor/shell/canvas-chrome/Toolbar.tsx`:
  - Removed chevron indicators from Shape, Easing, and Export buttons; converted all three to standard 40x40 (`var(--ll-size-icon-btn-lg)`) square icon buttons preserving `aria-haspopup="menu"` and `aria-expanded`.
  - Added pointerdown and keydown priming of `snapLeaves()` so button snapshot transitions across all mode switches (Design <-> Motion, Design <-> Code, Motion <-> Code) accurately morph via ghost fade, width spring, and pop-in stagger.
  - Implemented synchronous layout measurement in `useLayoutEffect` to close active popovers and prevent leftover buttons or ghost elements when switching back and forth.
  - Added `id="easingbtn"` and `id="exportbtn"` for accessible identity parity.
  - Removed unused `defaultHost` import (clearing ESLint warning).
- `src/editor/shell/canvas-chrome/Spotlight.tsx`:
  - Implemented dynamic `sizeTo(first: boolean)` measuring results list content directly from DOM and spring-animating `res.style.height` upward from the field up to max 360px (matching Prototype P lines 10222-10231).
  - Wired `useLayoutEffect` to trigger `sizeTo(false)` whenever query, prefix mode, or section items change so the panel follows content height without empty jump or delay.
  - Imported missing `useLayoutEffect` and added `sizeTo` to `runOpen` callback dependency array (resolving React compiler & ESLint errors).
- `src/editor/shell/canvas-chrome/spotlight.css`:
  - Updated `.ll-ftool .ll-dd, .ftool .dd` to 40x40 icon button dimension (`var(--ll-size-icon-btn-lg)`).
  - Removed `.ll-sp-bar:focus-within` and `.sp-bar:focus-within` border stroke / glow (`var(--ll-shadow-spotlight-focus)`), preserving hairline border parity with P.
  - Enforced fixed dimensions on `.ll-ins, .ins` (`width: var(--ll-size-insert-w, 520px) !important; height: var(--ll-size-insert-h, 400px) !important;`).
- `src/editor/shell/canvas-chrome/InsertBox.tsx`:
  - Explicitly initialized surf size `s.size = { w: 520, h: 400 }` on opening.
  - Bound container element inline styling strictly to `var(--ll-size-insert-w, 520px)` and `var(--ll-size-insert-h, 400px)`, preventing container resizing across category tab changes while keeping internal card grids scrollable.
- `src/editor/stage/CanvasCursor.tsx`:
  - Fixed root cause of canvas cursor remaining dormant until clicked: replaced fragile global `[role=menu]:not([data-lv])` check (which permanently matched dormant submenu containers in the DOM) with visible `.ll-menu.ll-open, .menu.ll-open, .tbpop.ll-open`.
  - Added probe of `document.elementFromPoint` in `update()` so that after closing menus or popovers, the target is resolved to the canvas underneath rather than a detached/closed menu DOM element.
  - Extended `inRegion(t)` to properly include `.ll-stagewrap, .stagewrap, .ll-stage-viewport, [data-stage="workspace"], [data-stage="canvas"], [data-stage="artboard"]`.
  - Added `ll-on` class toggling to `#center` and `ll-stage-cursor-active` to `.ll-stagewrap` on `on()` / `off()`.
  - Added immediate reactive subscriptions to `useToolStore` and `MutationObserver` on `[data-mode]` to react immediately to tool/mode switches.
  - Wired delayed updates (100ms, 300ms) on Escape and `ll-menu-close` to reactivate the cursor cleanly even before any mouse movement occurs.
- `src/editor/stage/stage.css`:
  - Added CSS rule ensuring that `.ll-center.ll-on .ll-stagewrap, .ll-center.ll-on .ll-stagewrap *, body .center.ll-on .stagewrap, body .center.ll-on .stagewrap *, .ll-stagewrap.ll-stage-cursor-active` all have `cursor: none !important;` so that system cursors are never visible over the canvas area when `#ll-cur` is active.

## Decisions made
- Kept Shape, Easing, and Export buttons as standard `IconButton` size `lg` (40x40) with `aria-haspopup="menu"` and `aria-expanded` attributes, removing extra chevron glyphs per instruction 2 and Prototype P parity.
- Spotlight height is clamped to `min(360, contentHeight) + 2px` and animated via WAAPI spring, with field remaining at 40px, matching P lines 10222-10231.
- InsertBox is fixed at 520x400 via CSS variables `--ll-size-insert-w` (520px) and `--ll-size-insert-h` (400px), with overflow scrolling internally in `.ll-insr`.
- Kept panels, top bar, and fields using the native system cursor for accessibility and zero input latency.
