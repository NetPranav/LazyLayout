## Decisions made
<!-- Choices you made, also logged in DOCS/UI/DECISIONS.md. Never credit the user unless they said it. "none" if none. -->
- Preserved exact 44px header height (`--ll-size-header-h`) and 32px track row height (`--ll-size-row-h`) to achieve 1:1 concentric horizontal alignment between LeftPanel's `TracksList` and bottom `TimelinePanel`.
- Used FrameScheduler (`render` phase) to paint playhead transform directly via DOM reference to ensure smooth 60fps scrubbing and playback without triggering React component re-renders.
- Styled keyframes as 45-degree rotated solid diamonds (`8px`, `10px` selected) matching prototype `.kf` and `.kf.sel`, avoiding any glass or capsule shapes.
- Toggling the prototype's "Graph" button displays an integrated easing curve graph with cubic bezier curve visualization and presets (Power2, Power4, Elastic, Bounce, Anticipate).
- Maintained full bidirectional transport control (Play, Pause, Stop/Rewind to 0, Step forward, Step back, Loop cycle) directly wired to `@/core/time/transport`.
