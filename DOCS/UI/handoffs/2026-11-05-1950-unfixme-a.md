## App Bugs Found

1. **`Artboard.tsx` (Stage element lock bypass):**
   When a layer is locked in the layers tree (`onToggleLocked` sets `layer.locked = true`), clicking on the element on the canvas stage still selects it. `Artboard.tsx` renders stage elements with pointer-event click handlers without checking `element.locked === true` before delegating to `handleSelect`.
2. **`useEditorActions.ts` (Missing clipboard shortcuts):**
   In `useEditorActions.ts` keyboard handling, `Ctrl+C` and `Ctrl+V` are not mapped in the global keydown listener (only `Ctrl+S`, `Ctrl+A`, `Ctrl+D`, `Ctrl+Z`, `Ctrl+Shift+Z`, `Ctrl+G`, etc. are handled). Consequently, keyboard copy/paste between tabs does not trigger `edit.copy` / `edit.paste`.
3. **`StudioHeader.tsx` / `UnifiedLogoMenu.tsx` (Showcase demo button location):**
   The legacy `Mount Showcase Demo` button was removed from the header toolbar and placed into `UnifiedLogoMenu.tsx` as a menuitem (`#header-toggle-demo-btn`). Any test expecting `getByRole("button", { name: "Mount Showcase Demo" })` times out.

## Needs from the App

1. **Stage lock check:** In `src/editor/stage/Artboard.tsx`, ignore click / pointerdown events when `element.locked === true` so canvas selection matches tree lock state.
2. **Clipboard keybindings:** In `src/editor/shell/useEditorActions.ts`, bind `key === "c"` to `invokeCommand("edit.copy")` and `key === "v"` to `invokeCommand("edit.paste")` under `isCtrl && !isAlt && !isShift`.
3. **Motion model persistence:** Connect `useMotionModel` keyframes and clips to `documentStore.getState().document.clips` so that motion animations persist across page reloads and save into exported `.lazy.json` project files.
