## What changed
- `src/editor/shell/shellFx.ts` (new): `ShellFx` engine. `panelFx` springs for `--lw --rw --bh --fw` on the shared motion engine (`Spring`, `simAdd`, `springAnim`), retargetable mid-flight (position and velocity kept), reduced motion = no springs and a 120ms fade (via `springAnim`). Mode-switch fx: ghost copy of old left, right and bottom content slides out with blur, new content slides in by tab order, inspector `.ll-dsec` cascade. Bottom splitter (drag, double click glides to 40% of window height through the `--mbh` spring).
- `src/editor/shell/EditorShell.tsx`: grid now comes from CSS (data-mode, data-lc, data-rc, data-zen, data-fw) instead of inline styles, so React never owns what the engine writes. A layout effect runs `sync(mode)` after every commit that can change the layout, which covers panel buttons, Ctrl+\, Tab, mode tabs and the timeline full-width button alike. Bottom cell is always mounted (row springs open and closed) and holds the splitter plus `TimelinePanel height="100%"` or `CodePanel`. All props passed to TopBar, LeftPanelConnected, CanvasChrome, RightPanelConnected, project boot, lock, banners are unchanged.
- `src/editor/shell/RightPanelConnected.tsx`: Motion mode mounts `MotionInspector` (L6); Code mode keeps `CodeInspector` (L7).
- `src/editor/shell/useEditorActions.ts`: new option `onBeforeModeChange`; `Shift+T` toggles full width in Motion and Code (`motionActions.setFullWidth`); fixed `toggleBothPanels` (second Ctrl+\ left the right panel closed).
- `src/editor/styles/animations.css` and `tokens.css` (lane L8 blocks): shell grid, panel shadow gradient (6px, 10% / 34% dark), bottom header band (`.ll-ph` mixed 5% toward text), cross-panel focus dim (canvas 0.6 while `.ll-shell-bottom:focus-within`), splitter, ghost.

## Needs from other lanes
- **L7:** `CodePanel` has its own `isFullWidth` toggle that makes the panel `fixed` 75vh. It should use `useMotionModel.fullWidth` / `motionActions.setFullWidth` like the timeline. Its static `#bsplit` is covered by the shell splitter and can be removed.
- **L5:** `TimelinePanel` does not need its own splitter; the shell owns it (`--mbh`). The timeline intro and layer focus dimming (P 5069-5200) are L5's; the screenshot of Motion shows overlapping clip labels in the track area (timeline internals, not shell).
- **L2:** `LeftPanelConnected` can read `var(--bh)` (set by the shell) for the tracks section height.

## Decisions
- Used P's custom property names (`--lw --rw --bh --fw --mbh`), unprefixed, because they are inline-written engine variables and L2 already references `--bh`.
- Splitter minimum is 180px (matches the CSS clamp) instead of P's 160px.
- Motion constants (spring responses, slide distances) are named constants at the top of `shellFx.ts`, since `motion/presets.ts` is read-only.
