## Decisions made
- In `EasingPopover.tsx`, when no keyframe is selected on the timeline, rather than modifying the first non-hero layer, the popover displays a disabled explanation banner and sets the embedded editor to `aria-disabled="true"` with pointer-events disabled, preventing unexpected mutations.
- In `TimelineTransport.tsx`, the Easing button is disabled with title "Select a keyframe to edit easing" when no keyframe is selected, and becomes active/clickable when a keyframe is selected.
- In `timelineOpsAdapter.ts`, removed the silent `catch {}` block and delegated split operations directly to `motionActions.splitAtPlayhead()`. Checked `src/core/timeline/timelineOps.ts`: no split clip op currently exists in core timeline, so the adapter is retained and the engine op is requested below.
- Mapped `--ll-size-timeline-footer-btn` to `--width-timeline-footer-btn` / `--height-timeline-footer-btn` and `--ll-size-popover-min-w` to `--min-width-popover-min` in `tailwind.css`, completely eliminating arbitrary width/height classes in `TimelineFooter.tsx` and `EasingPopover.tsx`.
- Defined `CloseIcon` in `src/editor/panels/timeline/icons.tsx` as a LucideIcon-compatible forwardRef SVG to eliminate direct `lucide-react` imports in screens and comply with UI worker rule 8.
