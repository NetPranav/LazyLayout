## Decisions made
- Used Geist Mono 20px/500 for the timecode readout and 11px mono for the footer summary text, matching prototype lines 464 and 910.
- Modeled hierarchical tracks mirroring the Layers tree (`hero` frame as a group track spanning `headline`, `subtitle`, `button`, `image`).
- Implemented focus dimming: unselected layers transition to 0.45 opacity when any layer is selected.
- Wired all 5 context menus (Keyframe, Clip, Track, Lane, Ruler) to the shared `Menu` component.
- Retained legacy optional props on subcomponents (`TimelineTransport`, `TimelineRuler`, etc.) so existing design system demos and test harnesses continue compiling cleanly.
- Preserved 200px-420px resizer behavior with double-click reset to 264px and localStorage persistence under `ll-tlhw`.
