## Decisions made
- Monochromatic syntax highlighting strictly conforms to PALETTE.md and UI_RULES.md: no rainbow syntax; keywords are regular `--text`, strings are `--muted` with italics, tags/types are `--text` medium, punctuation is `--text-secondary` (`--text2`), and comments are `--muted` italics.
- Sticky scroll scope calculation inspects indentation and AST block boundaries, updating the 24px sticky header (`.cstick`) during vertical scroll.
- Console command line prompt supports history traversal (ArrowUp / ArrowDown) and built-in interactive commands (`help`, `build`, `clear`, `version`, `test`).
- Execution trace player provides interactive step scrubbing, play/pause timing simulation, conditional breakpoints toggle, and live watch expressions.
- OutputConsole bridge directly hosts the Console and Trace views so `/editor/detach/console` and detached popouts render the new native UI without legacy dependencies.
- BlueprintCanvas bridge hosts the full-page Logic and Data "Coming Soon" shells with interactive Back button returning to Design mode, matching prototype line 6882.
