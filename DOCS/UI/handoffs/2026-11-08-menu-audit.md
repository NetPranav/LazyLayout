- **Bouncy** (Default): `shape: [.42, .55]`, `hl: [.26, .6]`, `rows: [.32, .55]`, `stagger: 18`, `rowScale: .9`, `wiggle: 12`, `stretch: .015`, `endBump: 420`, `lock: 350`, `glideW: [.28, .42]`, `glideH: [.3, .38]`, `flip: [.28, .42]`, `flipKick: 140`, `pop: [.26, .38]`

**Key Motion Parameters (P lines 3032–3034):**
- `SP.press`: `[.18, .6]`, `MOT.pressScale`: `0.97`

## 3. Retargeting Rules Across Trigger Families

### Rule 1: Same-Family Retargeting (Reusing Floating Box)
When a trigger activates an overlay while an overlay of the **same family** is already open:
1. **Never unmount or flash**: The floating container remains in DOM and visible.
2. **Spring Position & Size**: The bounding box springs (`left`, `top`, `width`, `height`) from its current geometry to the new target geometry using the shared spring presets (`shape: [.42, .55]` or `glideW: [.28, .42]`, `glideH: [.3, .38]`).
3. **Interruptible Velocity**: If a retarget happens while a previous transition is in flight, the springs inherit existing velocity and position without jumping.
4. **Content Crossfade with Blur**: Outgoing content blurs and fades out (`opacity: 1 -> 0, blur: 0 -> 4px` over 160ms), incoming content crossfades in (`opacity: 0 -> 1, blur: 4px -> 0px`).
5. **Anchor & ARIA Update**: The previous trigger updates `aria-expanded="false"`, the new trigger updates `aria-expanded="true"`. Focus moves into the box (or onto active descendant).

### Rule 2: Inter-Family Exclusion (One-Open-At-A-Time)
Different overlay families are mutually exclusive:
- Opening an **Inspector Options Popover** closes any open **Colour Picker** or **Font Picker** (and vice versa) using the standard leave animation.
- Opening a **Canvas Toolbar Popover** (Insert, AI, View Options) closes top-bar menus and inspector popovers.
- Opening **Spotlight** (Cmd+K) closes all non-modal popovers immediately.
- Opening a **Context Menu** closes other menus and popovers.

### Rule 3: Reduced Motion Compliance
When `prefers-reduced-motion` is active:
- No spatial sliding (`top`, `left`, `translate` do not animate).
- Springs and blurs become a 120ms linear/ease-out opacity fade.
- Retargeting instantly places the box at the new coordinates and crossfades content via 120ms fade.
