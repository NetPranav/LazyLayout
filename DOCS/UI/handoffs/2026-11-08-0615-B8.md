## What changed in Retry 1
1. `tokens.css` B8 block: deleted all unprefixed `.logo`/`.tro`/`.tfl`/`svg.saving-on`/`svg[data-saving]` rules (they duplicated `animations.css`). 2. `--ll-dur-save-cycle` removed (it was unused). `SAVE_DURATION_MS` (3200) is kept for the demo and its comment now says it equals 1.6 s draw + 1.6 s undraw (`--ll-dur-trace`, `animation-direction: alternate` in `animations.css`). Measured in the browser: computed `animation-duration` 1.6s, `alternate`, fill opacity 0, stroke opacity 1, dashoffset 97.4 then 35.7 then 0 across frames.
3. Mode tab fill: already present, no change needed. Measured the `.ll-mhl` tile in the running app: display block, 76x26, background `--ll-control-active` (Warm rgb(227,219,204), Darkroom rgb(52,52,44)), behind the active tab. The earlier screenshots were most likely taken before the spring hook placed it. I did not touch `ModeTabs.tsx`. I could not run `git show HEAD:` for this (the directory is not a git repo from my shell: "Is a git repository: false"), so I did not check what HEAD looked like.
4. 390 wide: root cause was `.ll-top` in unlayered `animations.css` forcing `grid-template-columns: 1fr auto 1fr` (beats Tailwind, mistake 3), plus `1fr` min-content, plus the shell grid being 568 px wide at 390 so the header overflowed. Fix in `TopBar.tsx`: dropped the `ll-top` class, `ll:grid-cols-topbar-fit` (`minmax(0,1fr) auto minmax(0,1fr)`, as P's `.top`), `ll:max-w-screen`, and below `sm` `ll:max-sm:grid-cols-topbar-narrow` (`minmax(0,1fr) auto auto`) with Preview and Ship hidden (`ll:max-sm:hidden`) and smaller right padding. Result at 390: theme icon visible, tabs fully inside the bar. Both new grid entries live in the B8 block of `tailwind.css`.
5. Preview button now stays hoverable when disabled: `aria-disabled` instead of `disabled`, onClick is the `onPreview` prop (undefined = no-op). Extracted as exported `PreviewButton` in `TopBar.tsx` (used by TopBar and the demo). Tooltip uses `side="bottom"` because the default top placement was clipped by the viewport. Tooltip text verified in the DOM ("Preview is not designed yet"). Ship popover "Preview link" item: `TopBar` now passes `onPreview` as-is (the old fallback to a `view.previewMode` menu action is gone); with no handler the item is `aria-disabled`, muted, `ll:opacity-disabled`, with the same reason as title.
6. `ll:opacity-45` replaced with `ll:opacity-disabled` (theme entry `--opacity-disabled` -> `--ll-opacity-disabled`) in the Preview button; also replaced `ll:opacity-40` for the disabled Ship button in `ShipPopover.tsx`. Also removed an arbitrary variant `ll:hover:[&_svg]:opacity-70` in `TopBar.tsx` (`animations.css` already does it).
7. `B8Demos.tsx`: removed the direct `lucide-react` import and the duplicate local button, it now uses the exported `PreviewButton`. Note: `TopBar.tsx` and `ModeTabs.tsx` still import lucide icon components to hand to `Icon` (the shared `Icon` takes a component, there is no icon registry); that is the existing pattern and I did not change it.
