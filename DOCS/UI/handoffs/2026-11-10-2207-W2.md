## Decisions made
- Removed `useEffect` mirroring props into state across all inspector option popovers. In line with React 19 rules, option fields derive values directly from `getValue` / document store during render. Text/hex inputs retain minimal local draft state for transient typing, resetting on blur.
- Removed impure `Date.now()` stop ID generation in `FillOptions.tsx` in favor of sequential index-based ID (`st-${stops.length + 1}`).
- For open lock and text-align icons, drew prototype-native glyphs in `protoGlyphs.ts` (`unlock`, `tal`, `tac`, `tar`, `taj`) matching optical weight of `lock`, `ul`, `ital` instead of falling back to Phosphor.
