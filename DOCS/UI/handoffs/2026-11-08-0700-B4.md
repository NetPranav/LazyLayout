## Decisions
- Cursor hotspot is the origin of `.ll-cp`/`.ll-cv`, so scaling and lean pivot at the pointer tip.
- The cursor is scoped to `.ll-stage-viewport`, so panels, menus and fields keep system cursors.
- Inline SVGs instead of new `Icon` glyphs, to stay inside the lane.
- Coalescing `checkSelection` with `defaultHost.register` ensures DOM measurements happen within the shared motion frame and never stack up during fast pointer selection events.
