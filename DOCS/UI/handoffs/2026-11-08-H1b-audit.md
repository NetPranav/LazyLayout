## 1. Layers Panel Feel & Folding Audit

### Differences Identified:
| Property / Behavior | Prototype (P) | Current App | Difference / Defect |
|---|---|---|---|
| **Fold/Unfold feel** | Chevron springs with `pop` `[0.26, 0.38]`. Rows expand/collapse with spring `rows` `[0.32, 0.55]`, height 0↔32px, stagger 18ms, scale 0.9↔1, blur 3px↔0px. Interruptible. | No fold/unfold animation; rows mount/unmount immediately without spring. | **Missing bouncy fold feel completely.** |
| **Row Height & Indent** | Row height 32px, padding `0 8px 0 calc(12px + lvl*12px)`, gap 4px. | Row height 32px, padding calculated via JS inline style. | Visual match on height, but chevron lacks spring transform. |
| **Chevron** | `.c` rotate 0deg/90deg, 12x12px, animated via `springAnim(c, [{rotate: '0deg'}, {rotate: '90deg'}], pop[0], pop[1])`. | CSS rotation on [data-open] without real spring overshoot. | Does not bounce on open/close. |
| **Selection Band** | `.lyhl.sel` slides between rows with stretching on velocity (`scaleY`) and settles with overshoot on `hl` spring `[0.26, 0.6]`. | Spring is initialized but does not update during group fold/unfold animations. | Needs sync during fold animations. |
| **Panel Collapse / Expand** | Collapses using `panelFx` with `--lw` spring (`shape` `[0.42, 0.55]`) and content blur (`filter: blur(2.5px)` to `blur(0px)`). | Collapses with fixed duration, content blur not synchronized with panel spring. | Needs exact `panelFx` spring feel with active bouncy preset. |
| **Page Change Re-render** | Rows cascade into view: `stagger` 18ms, scale 0.9, blur 4px to 0px, translate `0 6px` to `0 0`. | Page change switches tree without cascade entrance. | Needs bouncy cascade on page change. |

## 2. Fill Colour Picker Box Audit

### Differences Identified:
| Property / Behavior | Prototype (P) | Current App | Difference / Defect |
|---|---|---|---|
| **Trigger mechanism** | Clicking ANY swatch (`.dsw`) OR hex input (`input[data-hex]`) in Fill, Stroke, Theme & Tokens, Page Background opens the picker. | Only clicking the tiny swatch button in Fill / ThemeTokens opens the picker; clicking hex input does nothing. Stroke has no color picker trigger. | **Swatch / hex click broken across Stroke and fields.** |
| **Box position & placement** | Exactly 8px left of right panel (`rightZone.left - 274 - 8px`), clamped inside viewport (`left >= 8px`, `top = clamp(s.top - 12, 8, vh - h - 8)`). Follows swatch when inspector scrolls or resizes. | Position measured before DOM layout (`offsetHeight` is 0 initially); no scroll tracking on inspector. | **Opens at wrong coordinates; does not follow inspector scroll.** |
| **Morph animation** | Morphs out of clicked swatch with `clipPath: inset(top, right, bottom, left round 4px)` to `inset(-48px round 8px)` on Bouncy `shape` `[0.42, 0.55]`. | Inset clipPath fails when height is 0; no overshoot room (clips overshoot). | **Morph animation broken or flashes.** |
| **Retargeting slide** | Clicking from Stroke to Fill or between rows slides/retargets smoothly via `animateRetarget` without unmounting. | Unmounts one `ColorPicker` and mounts another, causing flicker. | **Retarget slide broken.** |
| **Size & styling** | Width 274px, border-radius `var(--r-lg)` (8px), all corners rounded. | Width 274px, but overflow clipping and styling differs from P `.cp*`. | Hairline outline and field heights need exact alignment. |
| **Tabs** | 24px height segmented control with sliding tile (Solid, Linear, Radial, Conic, Image). | SegmentedControl present, but needs exact 24px height and sliding indicator. | Verify 24px height and tile feel. |
| **Fields** | 28px height, hairline outline, prefix inside (`#`, `A`, etc.), 11px mono 400. Live writeback to store. | Live writeback only on commit in some fields. | Needs live writeback on every slider/square drag and input change. |

## Plan of Fixes
1. **Fix Layers Panel Bouncy Feel**:
   - In `LayersTree.tsx`, keep all tree nodes in DOM with `.lcl` class for folded nodes (as P does).
   - Implement `lyFold` and `lyAnim` using `springAnim` with active Bouncy preset (`rows: [0.32, 0.55]`, `stagger: 18`, `rowScale: 0.9`, blur filter).
   - Animate chevrons with `springAnim` on rotation.
   - Implement `cascade` bounce on initial mount and page change.
   - Ensure selection band follows animating rows smoothly.
   - Verify `LeftPanelConnected` and `LeftPanel` collapse/expand with `panelFx` blur feel.
2. **Fix Fill Colour Picker**:
   - Create unified / singleton `ColorPicker` controller in inspector that delegates clicks on any `.dsw` or `.dfield input[data-hex]` (Fill, Stroke, Theme & Tokens, Page background).
   - Fix position calculation: measure after mount, compute 8px left of inspector, clamp inside viewport.
   - Attach scroll listener to inspector container so picker tracks the swatch when scrolled.
   - Implement retarget slide between swatches without unmounting.
   - Ensure morph animation uses Bouncy overshoot and `inset(-48px round 8px)` so it never clips.
   - Match P's exact 24px segmented control mode tabs, 180px SB square, 12px sliders, 28px fields with prefix inside, Document & Token swatches.
3. **Rebuild Section Option Popovers (`ll-more`)**:
   - Rebuild `OptionsPopover.tsx` to match P's `.llm-pop` specification (280px, 36px header, sans 11px/500 muted title, 24px close button, morph from button, scroll tracking).
   - Create dedicated section option components in `src/editor/panels/details/options/`:
     - `StrokeOptions.tsx`
     - `EffectsOptions.tsx`
     - `FillOptions.tsx`
     - `PositionOptions.tsx`
     - `LayoutOptions.tsx`
     - `AppearanceOptions.tsx`
     - `TypographyOptions.tsx`
     - `ThemeTokensOptions.tsx`
     - `index.ts`
   - Use 72px label column (`.dlbl`), 28px fields with hairline border, hairline dividers between groups (`.dmg`).
   - Wire them into `DetailsInspector.tsx`, `StrokeSection.tsx`, `FillSection.tsx`, `EffectsSection.tsx`.
   - Update design system demos (`B1Demos.tsx`, `B2Demos.tsx`, `B3Demos.tsx`) to show all states.
