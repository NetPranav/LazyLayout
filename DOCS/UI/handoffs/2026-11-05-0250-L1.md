Added `aria-pressed="true"` on active tab, 10px chevron caret on active tab, and mode menus morphing on active tab click for Design, Motion, and Code modes (including Workspace layout and Animation submenus). Arrow navigation and hover state tuned to `--bar` background.

Ready state shows "Ready" badge with `var(--ctl)` solid background; issues state shows tabular issue count with `var(--shipbg)` background. Defaults to prototype sample issues (`DEFAULT_SHIP_ISSUES`). Popover contains issue list with 24px "Fix" mini buttons, hairline divider, Preview link, Share, and 32px Publish button.
- `src/editor/components/PageSwitcher.tsx`: Page switcher button with chevron flip, inline renaming on Enter/Escape/blur, surf popover aligned to active row, search box when >12 pages, actions (+ New page, Rename, Duplicate, Delete), roving keyboard navigation.
- `src/editor/components/topbar-constants.ts`: added `DEFAULT_SHIP_ISSUES` matching P lines 1741 & 1831.
- `src/editor/design-system/demos/TopBarDemos.tsx`: created complete design system demos for `TopBarDemo`, `ModeTabsDemo`, `LogoMarkDemo`, `PageSwitcherDemo`, `ShipPopoverDemo`, and `ThemeToggleDemo`.

## Decisions made
- Left-click on `#themebtn` toggles Light (Paper) and Dark (Noir) exactly as P does. Right-click / context menu (`onContextMenu`) opens the 8-theme picker Menu with live swatches (`ThemeSwatch`) across Light (Paper, White, Warm, Lilac) and Dark (Noir, Dark, Graphite, Darkroom).
- Removed `rounded-sm` from the logo button to match P's exact 0px border-radius and grid centering.
- Tested hook `data-testid="save-status"` and `data-state="saved|dirty|saving|error"` placed on logo button. Screen reader status text is visually hidden in `.sr.ll:sr-only`.
- Defaulted `issues` in `ShipPopover` to `DEFAULT_SHIP_ISSUES` (from P lines 1741 & 1831: alt text issue and contrast issue) when not passed, so the default render matches P's "Ship 2" geometry and position down to the subpixel.
- Removed dead `useId` imports and unused local variables `themeBtnId` and `menuBtnId` in favor of semantic `#themebtn` and `#menubtn` IDs from the prototype.
