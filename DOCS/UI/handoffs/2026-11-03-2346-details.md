## What is wired vs what is simulated
- **Wired to real store:**
  - `useSelectionInspector` reads `selectedId`, `selectedIds`, `selectionType` from `useSelectionStore`.
  - Reads layer data dynamically from `useLayers()` (`@/core/store/useDocumentStore`).
  - Writes properties via `setLayerProps(selectedIds, patch)` (`@/core/editing/editOps`), which creates undoable transactions in `documentCommands`.
  - Coordinates (X, Y, Rotation), Dimensions (Width, Height), Opacity, Corner Radius, Typography (fontFamily, fontWeight, fontSize, lineHeight, letterSpacing, textAlign), and Border widths write to canonical layer property dot-paths.
  - Alignment actions in `AlignBar` call `alignLayers(ids, mode)`, `distributeLayers(ids, axis)`, and `tidyLayers(ids)`.
  - Visibility toggles call `toggleHidden(ids)`.
- **Local / Simulated in Lab Workbench:**
  - In `DetailsLabView`, sample mock layers (Headline, Hero Card, Action Button, Multi-selection, Page) allow interactive switching and scrubbing even when no project document is loaded in memory.
  - Repeatable list items (multi-fill, multi-stroke, multi-effect, multi-animation) maintain interactive array state with primary visible entry mirrored to the active layer store props.

## Decisions made
<!-- Choices you made, also logged in DOCS/UI/DECISIONS.md. Never credit the user unless they said it. "none" if none. -->
- **Dual Export Pattern (PascalCase and Section ID lower-case)**: Exported section components both as standard PascalCase (`PositionSection`) and as exact lowercase section IDs (`position`, `layout`, etc.) and a `SECTION_COMPONENTS` record. This allows `RightPanelFrame` builders to map over `designSections` dynamically or import individual sections explicitly.
- **3x3 Alignment Matrix (`AlignmentGrid`)**: Replicated the prototype's spatial 9-dot grid (`.dal`) with full keyboard arrow navigation (Up/Down +/- 3, Left/Right +/- 1) and mapped the 9 states cleanly to standard flexbox/grid `justifyContent` and `alignItems` combinations.
- **Cubic-Bezier Easing Box (`EasingCurveBox`)**: Implemented the exact prototype spec (100x100 SVG curve with baseline, control vectors, and cubic path) coupled with 4 scrubbable `NumberField` controls (`x1`, `y1`, `x2`, `y2`, step 0.01) and preset dropdown (Ease, Ease-in, Ease-out, Ease-in-out, Linear, Custom).
- **Repeatable Row Popover Pattern**: Implemented `.ppop` dialog containers for Fill, Stroke, Effects, Animation, Data, and Logic rows that open via the lead thumbnail button and close cleanly on Escape or backdrop click, avoiding intrusive layout shift.
- **Strict Token & Utility Compliance**: All styles strictly use `ll:` prefixed Tailwind classes and semantic tokens (`--ll-surface-bar`, `--ll-surface-panel`, `--ll-text-primary`, `--ll-text-muted`, `--ll-border-border`). Zero arbitrary hex values or un-prefixed Tailwind classes were written.
