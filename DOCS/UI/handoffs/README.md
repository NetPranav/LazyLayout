# Handoffs

Every Antigravity worker session ends with one handoff file here, so anyone can see what changed and why.

- **Name:** `YYYY-MM-DD-HHMM-<short-name>.md`
- **Start from:** `TEMPLATE.md`
- **Written by:** the worker, at the end of the session.
- **Reviewed by:** Claude (orchestrator), who fills in the sign-off at the bottom.
- One file per session, so entries never conflict. Do not edit another session's handoff.
- **Screenshots:** `DOCS/UI/handoffs/screenshots/<short-name>/`.
- **Old sessions:** the first experiments on the legacy editor are in `DOCS/UI/archive/2026-10-30-legacy-experiments/`.
