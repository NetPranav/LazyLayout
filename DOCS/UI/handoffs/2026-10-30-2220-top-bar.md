## Layout reasoning and choices made

1. **Contextual center section**: Rather than a static device switcher taking up prime center real estate, the middle section adapts to document selection state via `useSelectionStore`. When nothing is selected, users get immediate access to history (Undo/Redo) and viewport targeting (Desktop/Tablet/Mobile). When a layer is selected, the bar instantly surfaces horizontal alignment (Left, Center, Right), vertical alignment (Top, Center, Bottom), distribution & tidy, and layer arrangement (Bring Forward, Send Backward, Grouping).
2. **Unified logo menu (`UnifiedLogoMenu.tsx`)**: Replaces the clutter of 5 horizontal top-level menus (`File`, `Edit`, `View`, `Window`, `Help`) with a single, recognizable entry-point anchored to the LazyLayout logo mark. This creates generous whitespace and visual focus. On desktop, submenus fly out to the right; on mobile screens (390px), the menu transitions to an inline drill-down view with "← Back to Menu" navigation, preventing viewport clipping.
3. **Relocated Showcase Demo toggle**: Moved `#header-toggle-demo-btn` from the top bar into the logo menu with a sample/loaded badge. This frees up the bar for the contextual tools while maintaining full functionality, test ID integrity, and ARIA labels.
4. **Collaborator avatar stack normalization**: Standardized `.studio-header__collab-wrap` using solid neutral ramp tokens and rectangular modest radii (`var(--radius-xs)`). This cures inherited uncompiled Tailwind utilities and aligns the latency badge, user initials avatar, and Share button on the exact single baseline of the 40px header.
5. **Progressive collapsing for responsive viewports**:
   - At 1440px (Desktop): All contextual tools, search text, shortcut badges, and collaborator tools are fully displayed.
   - At 1024px (Tablet): Search text collapses to icon + shortcut, segmented device switcher collapses to icons, collaborator Share text collapses, and secondary arrange buttons hide gracefully without collision.
   - At 390px (Mobile): Top bar collapses to Logo mark + chevron, 3 primary horizontal alignment tools, search icon, and settings icon. No horizontal scroll is ever introduced.
