## Props contract
`Stage` accepts the following props:
- `zoom?: number`: Zoom factor from `CanvasChrome` (default: 0.59). Drives artboard transform scale `(zoom / 0.59) * 0.9`.
- `pan?: { x: number; y: number }`: Pan translation offset from `CanvasChrome` (default: `{ x: 0, y: 0 }`).
- `selectedIds?: string[]`: Controlled selected element IDs. Defaults to `useSelectionStore((s) => s.selectedIds)`.
- `onSelect?: (id: string | null, multi?: boolean) => void`: Callback when element or blank canvas is clicked. Defaults to `useSelectionStore.select`/`toggleSelection`/`clearSelection`.
- `frames?: StageFrameInfo[]`: Canvas frames array (for test injection).
- `elements?: Record<string, StageElement>`: Artboard elements map (for test injection; defaults to `useDocument` layers or prototype defaults).
- `activeTool?: CanvasTool`: Active canvas tool from chrome ("select", "hand", "frame", etc.).
- `snapObjects?: boolean`: Whether element-to-element edge snapping is active (default: true).
- `snapGuides?: boolean`: Whether center/ruler guide snapping is active and guide lines displayed (default: true).
- `smartGuides?: boolean`: Whether smart alignment guides are drawn during drag (default: true).
- `snapThreshold?: number`: Snap threshold in screen px (default: 6px).
- `preset?: StagePreset`: Active size preset ("1440", "768", "375").
- `onPresetChange?: (preset: StagePreset) => void`: Preset change callback.
- `title?: string`: Artboard title (default: "LazyLayout").
- `empty?: boolean`: Forces empty state rendering.
- `onAddFrame?`, `onInsert?`, `onAskAi?`: Empty state button action callbacks.
- `mode?: "design" | "motion" | "code"`: Editor mode (adjusts artboard vertical alignment: 52% in design mode, 50% in motion/code modes per prototype).

## Decisions made
<!-- Choices you made, also logged in DOCS/UI/DECISIONS.md. Never credit the user unless they said it. "none" if none. -->
- **8 Resize Handles vs Prototype 4 Corners**: Prototype CSS `.selbox s` defined 4 corner points, but task explicitly required "8 resize handles". Implemented `nw`, `n`, `ne`, `e`, `se`, `s`, `sw`, `w` handles on the bounding box with custom directional resize cursors and ratio/symmetric center sizing.
- **Real Snapping Logic Reuse**: Reused existing mathematical functions `snapMove`, `snapEdges`, and `distanceMarks` from `@/core/geometry/snap`. Snapping threshold dynamically scales with canvas zoom (`threshold / zoom`) to maintain consistent screen-pixel feel.
- **Canvas Size Button (`#albl`) using `Menu` component**: Replaced prototype's raw DOM dropdown with `Menu` and `MenuItem` from `@/editor/components/Menu`, supporting keyboard navigation, semantic tokens, and active checkmarks for Desktop (1440), Tablet (768), and Mobile (375).
- **Zero magic px literals**: Extracted all pixel constants, offsets, and thresholds into `src/editor/stage/constants.ts` (`STAGE_CONSTANTS`).
- **Transaction-safe drag/resize**: Opened transaction via `documentCommands.begin(...)` on pointer down, updated coordinates via `documentCommands.updateProps(...)` during movement, and committed on pointer up (`txRef.current?.commit()`) with cancellation on Escape (`txRef.current?.cancel()`).
