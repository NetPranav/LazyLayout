## Decisions made
- Toolbar center placement: Located within `#center` with `left: 50%; transform: translateX(-50%)`, resting at `bottom: 16px` across Design, Motion (sits 16px directly above bottom panel/timeline), and Code (sits 16px directly above bottom panel/editor) modes.
- Narrow canvas lift: Lifts to `bottom: 72px` above zoom bar when `(cw + bw) / 2 > cw - zw - 32` evaluates true (verified at 1024 and 390 viewports matching P).
- Spotlight morph architecture: `#tools` is the single morphing element that expands into the 560px search field via `.sp-on` / `.sp-f` classes, eliminating the double-toolbar bug and matching prototype P lines 10023-10398.
- Motion springs: Uses shared Bouncy spring presets (`preset.shape`, `preset.pop`, `preset.hl`, `preset.rows`) from `src/editor/motion/feel.ts` and `ease.ts`.
