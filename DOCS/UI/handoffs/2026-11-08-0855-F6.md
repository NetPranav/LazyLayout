## Decisions made
- Logged in `DOCS/UI/DECISIONS.md`:
  - Menu & Popover Retargeting Engine: Implemented shared retarget coordinator in `src/editor/components/retarget.ts` with active overlay registry, same-family handoff detection via `getFamilyHandoff`, inter-family exclusion, and spring-assisted morphing (`glideW`/`glideH` spring presets) with 160ms 4px blur crossfade matching P lines 3196–3308, 4064–4092, and 2433–2436.
  - Continuous Spring Velocity & Momentum: In `Menu.tsx`, in-place anchor changes adjust spring offsets (`s.Y.x += oldTop - newTop; s.G.x += oldLeft - newLeft; s.Y.to = 0; s.G.to = 0; s.shapeTo(...)`) inheriting velocity without unmounting or tearing; row stagger staggers child items in the glide direction.
  - Pickers & Popovers: ColorPicker, FontPicker, OptionsPopover, and Select retain or hand off surface rect across trigger switches; FillSection and PageSection share single active ColorPicker instance so clicking between swatches glides smoothly.
  - Reduced-motion: Gracefully degrades retargeting to 120ms opacity crossfade without spatial translation or dimension morph.
