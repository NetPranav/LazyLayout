## What changed
- `src/editor/shell/useEditorActions.ts`: Created unified hook mapping every menu id to real engine commands, stores, or documented no-ops; installed global & editing commands on mount; bound keyboard layer for prototype shortcuts (V, H, F, R, O, L, Shift+L, Y, Shift+Y, T, I, `/`, Shift+R, Ctrl+\, Tab, Ctrl+Z, Ctrl+Shift+Z, Ctrl+S, Ctrl+A, Ctrl+D, Ctrl+G, Ctrl+Shift+G, Ctrl+Alt+G, Del, Backspace, Ctrl+0, Ctrl++, Ctrl+-, Shift+1, Shift+2, Ctrl+K, F11, F1, Escape), ignored while typing in text inputs (`isTextEditingTarget`).
- `src/editor/shell/EditorShell.tsx`: Wired `useEditorActions` to connect `TopBar`, `CanvasChrome`, `PageSwitcher`, and left/right panels. Connected `PageSwitcher` to real document layers via `useDocument` and `listFrames`, passing frame selection (`focusFrame`) and creation (`addFrame`). Implemented prototype Zen mode (`Tab`), hiding top and side chrome and rendering the prototype hint overlay ("Press Tab to show the interface").
- `src/editor/components/TopBar.tsx`: Added `showRulers`, `isZen`, `onPreview`, and `onShare` to `TopBarProps`. Wired `showRulers` and `isZen` to checkmark indicators on `view.rulers` and `view.hideInterface`. Wired `view.options` to call `onMenuAction("view.options")`. Passed `onPreview` and `onShare` to `ShipPopover`.
- `src/editor/shell/canvas-chrome/CanvasChrome.tsx`: Added `topAnchorRef` to anchor `ViewOptionsPopover` directly under the top bar (at the top edge of the canvas) and passed `triggerRef={topAnchorRef}` to `ViewOptionsPopover`.

## Decisions made
- Used `isTextEditingTarget` from `@/core/commands/normalize` to ensure single-key shortcuts (V, H, F, R, O, L, T, I, `/`, Y, etc.) and editing keys (Backspace, Delete, Tab) are ignored while typing in `<input>`, `<textarea>`, and `contentEditable` elements, maintaining full typing usability across forms and fields.
- Implemented Zen mode (`Tab` or `view.hideInterface`) following the prototype CSS grid collapse (`0 minmax(0, 1fr) 0`) and rendered the hint banner `Press Tab to show the interface` at the top center.
- Wired `view.options` to trigger the `ViewOptionsPopover` in `CanvasChrome`, anchored via `topAnchorRef` under the top bar.
- Wired `PageSwitcher` to document frames through `useDocument((doc) => doc.layers)` and `listFrames`, with fallback to default pages if the document has no frames yet.
- Mapped align menu items (`align.center` -> `align.hcenter`, `align.middle` -> `align.vcenter`, `align.distributeH` -> `distribute.horizontal`, `align.distributeV` -> `distribute.vertical`) to matching core commands in `src/core/editing/editCommands.ts`.
- Documented tool panel actions (`window.outputLog`, `window.executionTrace`, `window.undoHistory`, `window.versionHistory`, `window.referenceViewer`, `window.plugins`, `window.deployment`, `window.logic`, `window.data`) as custom event dispatchers (`antigravity:open_tool`) to allow extensible panel tabs without hardcoding arbitrary mock HTML.
