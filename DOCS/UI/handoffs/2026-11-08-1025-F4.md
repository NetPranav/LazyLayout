## Decisions made
- **Direct GPU-driven Dragging vs React Loop:** Direct DOM updates (`root.style.setProperty("--lw", ...)` and `aria-valuenow`) run in `pointermove` to guarantee zero latency and prevent `EditorShell` component tree re-renders per pixel. React state `onWidthChange` commits on `pointerup` and keyboard navigation.
- **Spring and Blur Feel on Release:** Drag follows the pointer 1:1; on release, `settle()` kicks off the shared motion table spring (preset Bouncy `[0.4, 0.6]`) with pointer velocity handoff and triggers a `blur(2.5px)` to `blur(0px)` settle on the panel body (`.ll-zbody`), perfectly matching P's collapse/expand feel.
- **Reduced Motion:** If `prefersReducedMotion()` is active, springs and blurs are disabled; widths jump immediately with zero blur or animation.
- **Section Headers Far-Right Sliders:** `onAdd` (+) precedes `hasMore` (Sliders) in `RightPanelSection.tsx` so the Sliders button stays permanently anchored at the far right.
