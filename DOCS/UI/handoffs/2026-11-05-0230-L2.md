## Decisions made
- In Design and Motion modes, `#pagebtn` PageSwitcher is rendered leading in the 44px zone header, and `#lhead` text is visually hidden (kept in DOM with `ll:hidden` for accessible tree querying), matching prototype line 1327 where `#lhead` has class `lh hide`.
- When in Code mode, `#pagebtn` is absent and `#lhead` displays "Files".
- In Motion mode, the Left panel displays `LayersTree` (mirroring the timeline layer order as in P line 4874) and hides the motion badge (`.mb`) per P line 818 (`.app:not([data-mode=design]) .mb { display: none }`). The timeline tracks list is rendered by Lane L5 in the bottom workstation, not in the Left Panel.
- Positioned `.act` (hover-only Eye and Lock icons) before `.mb` (Motion badge) in the row DOM, ensuring the motion badge always rests consistently at `x: 215` (right end) matching prototype lines 4786-4790.
- Implemented drag-to-reorder and drag-to-nest using declarative pointer capture and DOM position calculations, highlighting with `.ldb` (before line), `.lda` (after line), and `.ldi` (inside nest highlight). Dropping into a non-frame layer triggers the floating status toast `#lmsg` ("Only frames can hold layers").
- Wired the layer row context menu with complete submenus: Arrange (Bring forward, Send backward, Bring to front, Send to back), Align (6 alignment options + horizontal/vertical distribution), Group, Frame selection, Tidy up, Layer (Ungroup, Rename, Hide, Lock, Label colour with 6 swatches + type default, Select all, Show all, Unlock all), and More (Copy as code, Add animation).
- Code mode file tree includes sticky `.fsbar` category selector (`All`, `Pages`, `Components`, `Styles`, `Config`), modified indicator dots (`.mdot`), extension-based file icons, and file context menu (`Open`, `Open to the side`, `Copy path`, `Download`, `Reveal layer`).
