## 5. E2E Sample of Main's Specs on `/editor/legacy`

- **Sample tested:** `tests/e2e/breakpoints.spec.ts` (Phase 43, 5 tests, 1 worker).
- **Result:** 0 passed, 5 timed out on `waiting for getByRole('button', { name: 'Mount Showcase Demo' })`.
- **Root cause:** In `origin/main:src/editor/shell/StudioHeader.tsx`, the `Mount Showcase Demo` button was directly on the top-level header (`#header-toggle-demo-btn`). In the branch's `src/legacy-editor/shell/StudioHeader.tsx`, it uses `UnifiedLogoMenu`, which moved that button inside the closed dropdown menu. Consequently, `ready(page)` in the e2e tests times out waiting for the top-level button.
- **What was not run:** The other ~29 legacy e2e specs (phases 39 to 52: `pen`, `auto-layout`, `tokens`, `components`, etc.) were not run in full to avoid 45s timeout loops per test, as all of them share the identical `ready(page)` call to `Mount Showcase Demo`.
