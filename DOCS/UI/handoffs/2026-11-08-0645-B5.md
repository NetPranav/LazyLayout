## What changed in this retry
1. `Toolbar.tsx` and `B5Demos.tsx`: `ll:bottom-[72px]` replaced by `ll:bottom-toolbar-lift`. The theme key was `--bottom-toolbar-lift`, which Tailwind 4 does not map to `bottom-*`, so the class would not generate. Renamed it to `--spacing-toolbar-lift` in the `B5 chrome` block of `tailwind.css`. After that the toolbar at 390 wide sits 72px above the bottom, over the zoom bar (screenshot below).
2. `Spotlight.tsx` pages: removed the invented `Home/Pricing/About/Blank` list and the fake `setActivePage("page_home")`. Pages come only from `useProjectStore.pages`; with no pages the "No results" empty state shows.
3. `Spotlight.tsx` commands: removed every guessed id and all `||` chains (`view.zoomFit`, `canvas.zoomToFit`, `view.zoom100`, `view.zoomSelection`, ...). Real registry commands still run through `runCommand(cmd.id)` (ids come from `getAllCommands`). The three UI zoom rows now call new optional props `onZoomFit`, `onZoom100`, `onZoomSelection` (wired in `CanvasChrome.tsx` to `handleZoomFit` / `handleZoom100` / `handleZoomSelection`) and are disabled with a reason when a prop is missing. Layer rows call `onZoomSelection?.()` only. Added a disabled "Split at playhead" row ("No engine command for split"). Dedupe of the P rows against registry rows is now case-insensitive (it showed "Zoom to Selection" twice before).
4. `spotlight.css`: the real cause of the missing icon-to-label gap was `--ll-spacing-2-5` / `--ll-spacing-1-5`, which do not exist, so those declarations were dropped. Added lane tokens (`--ll-b5-space-0-75/1-5/2-5`, field height, glyph sizes, keycap height, input size, highlight durations and ease, disabled opacity, focus shadow) in the `B5 chrome` block of `tokens.css` and used them. All px/ms literals are gone from `spotlight.css` (grep checked). Group headers are now uppercase mono with the micro tracking token. Meta is right-aligned. Disabled rows show "Not available" (reason in the `title`). Key combos render as ONE `<kbd>` ("Shift 1"). Non-shortcut commands show a "Command" meta like P. The field bar gets a focus ring through `.ll-sp-bar:focus-within`. Recent rows come from the existing recent list (visible in the empty-state screenshot). Added `@media (prefers-reduced-motion: reduce)`: the highlight only fades (opacity) and row blur is forced off. `handleScroll` already returns early on reduced motion, so JS blur is gated too. The 50ms run delay is now the named constant `SPOTLIGHT_RUN_DELAY_MS`.
5. Lucide: `Spotlight.tsx` no longer imports `lucide-react`. New `canvas-chrome/glyphs.ts` is the single lane file naming glyphs; rows render through `Icon`. This moves the import rather than removing it, because `Icon` takes a Lucide component and the repo has no glyph registry.
6. Frame presets: `CanvasChrome.tsx` imports `FramePresetsPanel` from `@/editor/components/FramePresetsPanel` and renders it; the Frame tool opens it (screenshot below).
