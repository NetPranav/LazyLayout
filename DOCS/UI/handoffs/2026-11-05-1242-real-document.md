## What changed

- `src/editor/shell/prototypeDocument.ts` (created): Implemented `isUntouchedSeed(layers)` and `getPrototypeSeedLayers()` defining the prototype's 16 real layers (Hero container, Headline, Subtitle, Get started button, Hero image, Features, Footer, and Other elements group with Email input, Newsletter toggle, Section divider, Page background, Menu icon, Star shape, Visitors counter, 3D model) with exact prototype coordinates and properties. Added `seedPrototypeDocument()` executing in a single `documentCommands.insertLayers` transaction.
- `src/editor/shell/EditorShell.tsx`: Subscribed on mount to `documentStore`; if the project is brand new and untouched (`isUntouchedSeed`), automatically seeds the 16 prototype layers through real engine commands.
- `src/editor/panels/layers/buildLayerTree.ts`: Unwrapped `elem_canvas_root` / `el_root_container` so that top-level sections (Hero, Features, Footer, Other elements) are the direct top-level roots rendered in the tree, matching painter's order and design-system demo.
- `src/editor/panels/layers/useLeftPanelData.ts`: Deleted `SAMPLE_LAYERS`, `isDefaultUnpositioned`, and `showSample` stopgaps. The panel now unconditionally builds from `buildLayerTree(layers, motionMap, rootFilterId)`. Replaced fallback `["headline"]` selection with live `selectedIds`.
- `src/editor/panels/details/hooks/useSelectionInspector.ts`: Completely removed `PROTOTYPE_ELEMENTS`, `mockOverrides`, `updateMockLayerProps`, and `subscribeOverrides`. Mapped `selectedLayers` directly from `layers[id]`. Reads live properties via `properties?.[propKey]` and dispatches property updates directly through `setLayerProps`. Updated `isFrame` to recognize container / frame archetypes.
- `src/editor/stage/Stage.tsx`: Removed `SAMPLE_STAGE_ELEMENTS` stopgap and `updateMockLayerProps`. Elements are derived directly from `useDocument((d) => d.layers)` for all non-root and non-catalog layers. Removed forced `select("headline")` on mount, preserving 59% initial camera zoom.
- `src/editor/stage/Artboard.tsx`: Updated selection matching to recognize `canv={subtitle:'headline'}` parity and eliminated duplicate fallback strings for text layers.
- `src/editor/stage/TransformOverlay.tsx`: Added `subtitle` to `headline` canvas element mapping for selection bounding box and hover outline.
- `src/editor/stage/useStageTransform.ts`: Removed `updateMockLayerProps` imports and calls; drag and nudge persist directly via `documentCommands.updateProps`.
- `src/editor/panels/code-view/useCodeModels.ts`: Mapped canonical properties (`typography.fontSize`, `typography.fontWeight`, `appearance.radius`, `appearance.opacity`, `appearance.background.color`, `content.text`, `content.label`) so code generator reflects live document layers.
- `src/editor/panels/code-view/codeGenerator.ts`: Updated `DEFAULT_TYPE.headline` to 30px / 600 weight, `DEFAULT_TYPE.subtitle` to 13px / 400 weight, and `DEFAULT_TXT.subtitle` to match prototype.
- `src/editor/motion-model/model.ts`: Updated `defaultComposition` to dynamically resolve layer IDs from `documentStore` (by name/archetype for Headline, Subtitle, Button, Image), and updated `layerName(id)` and `layerType(id)` to read live names and archetypes from `documentStore`.
- `src/editor/shell/canvas-chrome/insertCommands.ts`: Set explicit default geometry (`frame.x: 50, frame.y: 50, frame.width, frame.height`) on newly inserted catalog items so they immediately render on stage and in tree.
- `src/editor/shell/left-panel/LayersTree.tsx`: Added `data-depth={node.level}` testing hook to row buttons.
- `src/editor/components/TopBar.tsx`: Added `data-status={resolvedState}` alongside `data-state={resolvedState}` to `[data-testid="save-status"]`.
