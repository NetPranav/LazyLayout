## What changed
- `src/editor/styles/tokens.css` & `src/editor/styles/tailwind.css`: Added lane tokens block `/* === lane: F8 sweep === */` defining `--ll-context-seed-size: 10px` and `--ll-context-seed-radius: 5px` strictly matching P line 4039.
- `src/editor/components/retarget.ts`:
  - Added `"context-menu"` to `OverlayFamily`.
  - Excluded context menus from same-family retargeting handoff (`getFamilyHandoff` returns `null` for `"context-menu"`; `unregisterOverlay` does not record history for context menus).
  - Enforced immediate closure (`close(true)`) of any existing overlays whenever a context menu is registered, guaranteeing no doubled or stuck overlays.
- `src/editor/components/Menu.tsx`:
  - Context menus (`variant === "context"` or `position` supplied) bypassed from `isAnchorSwitch` and retargeting morphs.
  - Context menus now execute fresh pop-in from seed `{ w: 10, h: 10, r: 5 }` with spring `enterRows` row stagger matching P lines 4033–4041.
  - Repeated right-clicks at new coordinates call `s.reset()`, cancel pending submenus, clamp coordinates to viewport `[pad, innerWidth - menuW - pad]`, `[pad, innerHeight - menuH - pad]`, and pop in fresh at the new position without gliding.
  - Added window listeners for `scroll` (capture), `resize`, `blur`, and outside `contextmenu` to dismiss open menus cleanly.
  - Dispatched `ll-menu-open` and `ll-menu-close` events to synchronize overlay lifecycle with custom cursor.
- `src/editor/stage/stage.css`:
  - Removed `transition: opacity var(--ll-dur-cursor-fade) linear;` on `#ll-cur` to eliminate double cursor lag when handing off between custom cursor and system cursor.
- `src/editor/stage/CanvasCursor.tsx`:
  - Wired `ll-menu-open` and `ll-menu-close` listeners: cursor hides when menu opens and wakes up when menu closes.
  - Reset `held = false` on `ll-menu-close`, on Esc `keydown`, on `endDrag` (pointerup/pointercancel), and on window `focus`.
  - Updated `update()` to only suppress cursor if an active, non-exiting menu is open (`.menu.ll-open, .menu.open, [role=menu]:not([data-lv])`).
  - Updated `apply(kd, a)`: when returning from hidden (`!shown`), calls `setKind(kd, a, true)` to trigger the 4px blur and scale crossfade animation matching prototype P.
- `DOCS/UI/DECISIONS.md`: Logged worker-attributed architectural decisions for context menu isolation and cursor transitions.

## Decisions made
- Logged in `DOCS/UI/DECISIONS.md`:
  - **Context Menus Isolation:** Context menus isolated from F6 retargeting coordinator; opening or changing position closes prior instance immediately, clamps strictly to viewport, and pops in fresh from pointer seed `{ w: 10, h: 10, r: 5 }` with spring row stagger matching P lines 4033–4041.
  - **Canvas Cursor Handoff:** Removed container CSS opacity transition from `#ll-cur` in `stage.css` eliminating double cursor lag; wired `ll-menu-open`/`close` events to synchronize cursor hide/show without stuck states after Esc, item click, right-click-drag, or window blur; `setKind` fades in with `blur(4px)` and `scale(0.85)` when returning from hidden.
