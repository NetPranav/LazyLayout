## Optical size rule (Position fix)

Phosphor glyphs sit inside more padding than lucide and their Light stroke (12/256 of the box) is thinner than lucide at 1.5/24. Each glyph carries `s`, computed once in a measurement script as (content extent of the lucide glyph it replaced, stroke included) / (content extent of the Phosphor glyph), never below 1, floored at 1.06, capped at 1.2 and never past 98% of the box. `PhosphorIcon` crops the viewBox by 1/s around the centre, so the `size` prop keeps its meaning and no call site changes. Median plain ratio over all 153 pairs was 1.06, align glyphs 1.17.

Measured rendered glyph extents in Position (px, at the same size prop):

| Glyph (size) | old lucide | Phosphor trial | Phosphor now |
|---|---|---|---|
| Align left/right/top/bottom (16) | 14.3 | 12.25 | 14.33 |
| Align centre H/V (16) | 14.3 | 12.75 | 14.28 |
| Rotation arrow (14) | 11.4 | 11.15 | 11.82 |
| Offset arrows (12) | 7.8 | 8.8 | 8.8 (s = 1, already larger) |

## Prototype icon set (supersedes Phosphor as the primary set)

The user prefers the prototype icons (`DOCS/UI/design/editor-design-mode-blocks-dark.html`, inline sprite, 156 symbols). `Icon` now resolves: prototype glyph (`icons/protoMap.ts` LUCIDE_TO_PROTO) -> Phosphor glyph (`phosphorMap.ts`, optical scale kept) -> lucide with a dev `console.warn`.

- `icons/protoGlyphs.ts`: all 156 symbols, generated by a script from the sprite (nodes as `[tag, attrs, children?]`, no HTML strings).
- `icons/ProtoIcon.tsx`: viewBox 0 0 24 24, fill none, stroke currentColor, 1.5, round caps and joins (the prototype's `svg` rule). No optical scale; the stroke scales with the box as in the prototype.
- Result: 131 of the 166 mapped lucide names use a prototype glyph, 35 fall back to Phosphor, 0 reach lucide.
- `PhosphorIcon` (used directly by TextFormatBar, the Position section and the align bar) redirects names in `PHOSPHOR_TO_PROTO` (align set, offset arrows to the side arrows, rotation to `rot`, italic/underline/strike/link) to the prototype twin, so those call sites are unchanged. `PhosphorMotionIcon` keeps its `ll-pi` wrapper, so the hover motions (rotate 45deg, nudge, spread, lift) apply unchanged (measured: rotation matrix 45deg, left nudge -2px). `PhosphorGlyph` is the raw Phosphor renderer used for fallbacks.
- Frame tool: the prototype's `frame` (hash-style) replaces the Phosphor frame-corners the user chose earlier, because the prototype set was requested wholesale.
- Direction chevron up is `chevd` rotated 180deg (CSS `rotate`, so it does not fight the hover scale).

Notable choices: Box/Square/RectangleHorizontal -> `box`, Layers -> `stack`, Rows2/PanelsTopLeft -> `layouts`, Columns3 -> `panels`, Pen/PenTool -> `tb-pen`, Timer -> `stopw`, Download -> `exp`, Terminal -> `prompt`, Hexagon -> `poly`, FileCode -> `ftsx`, Scan -> `selall`, SquareRoundCorner -> `radius`, Spline -> `graph`, Move horizontal/vertical -> `autow`/`autoh`.
