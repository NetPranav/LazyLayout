## Decisions made
- SegmentedControl Compact Variant: Added `compact` size with 24px height (`ll:h-6`), 2px padding (`ll:p-0.5`), `ll:rounded-xs` sliding marker, and `ll:text-micro` font to match prototype `.cp-tabs`, `.fp-seg`, and the top-bar mode switch design language.
- Select Floating-Surface Variant: Added `variant="floating"` to provide a clean hairline border (`ll:border ll:border-solid ll:border-border ll:hover:border-muted ll:bg-surface-bar` and `ll:border-primary` when open) without raised bevels or native drop shadows.
- Scoped Base Reset in `@layer base`: Positioned base reset inside `@layer base` so Tailwind utilities (`ll:*`) take precedence while ensuring portaled controls (which mount under `document.body` outside `.ll-editor-root`) and in-tree controls are stripped of native browser styles (`appearance: auto`, `background: ButtonFace`, `border: outset`).
- Type Safety: Added clean generic parameter support to `SegmentedControl` so callers (`ColorMode`, `FontCategory`, `TargetOption`) have strict type safety on change events.
