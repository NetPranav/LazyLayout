## Decisions made
- Semantic color tokens (`--ll-surface-*`, `--ll-text-*`, `--ll-control-primary-*`) replace numbered neutrals; dark theme is default on `:root` and `[data-theme="dark"]`, light on `[data-theme="light"]`.
- Soft shadow token (`--ll-shadow-soft`) adopts stronger black alpha in dark (`rgba(0,0,0,0.5)` / `0.3`) and subtle alpha in light (`rgba(0,0,0,0.08)` / `0.04`).
- Theme choice stored in `localStorage` under `lazy-layout-theme` and initialized via inline script in `layout.tsx` to eliminate theme flash; default dark when nothing is stored.
- Added `ThemeToggle` component (ghost icon button with Lucide Sun/Moon and "Switch theme" tooltip) in TopBar and DesignSystemPage.
- Hover and active states map to `surface-panel` on raised surfaces and `surface-bar` on panel surfaces for cross-theme contrast.
- Colors page shows dual-theme comparison columns (Dark vs Light) for all 11 semantic roles, real workspace frame preview in active theme, and WCAG AAA/AA surface text contrast ratios.
