### Root Causes & Fixes Applied

1. **Missing Top-Level Header Triggers & Showcase Mount Button:**
   - **Diagnosis:** On `origin/main`, `StudioHeader` exposed top-level menu triggers (`File`, `Edit`, `View`, `Window`, `Help`) and `#header-toggle-demo-btn` ("Mount Showcase Demo" / "Clear showcase demo"). In the redesign branch, `StudioHeader` was refactored into `UnifiedLogoMenu`, moving the demo mount button and submenus inside a closed logo popup. When moved to `src/legacy-editor`, legacy specs timed out waiting for `getByRole('button', { name: 'Mount Showcase Demo' })` and top-level menu buttons.
   - **Fix:** Created `src/app/editor/legacy/LegacyStudioHeader.tsx` restoring `origin/main`'s classic header layout with the full desktop menu bar, device selectors, project save indicators, and the top-level `#header-toggle-demo-btn`. Injected it via `<EditorShell headerSlot={<LegacyStudioHeader />} />` in `src/app/editor/legacy/page.tsx`.

2. **Dropdown Menu Z-Index Layering:**
   - **Diagnosis:** Dropdown menus on `/editor/legacy` were intercepted by `.canvas-frame__surface` because `--z-dropdown` (60) and `--z-header` (45) were undefined without legacy tokens.
   - **Fix:** Added `import "@/legacy-editor/styles/globals.css";` to `src/app/editor/legacy/page.tsx`, properly scoping legacy z-index tokens and layout variables.

3. **Helper Default Target URL:**
   - **Diagnosis:** `openEditor(page, url = "/editor")` in `tests/e2e/support/editor.ts` was pointing callers to `/editor` (the new UI) rather than `/editor/legacy`. Specs written for `main` were failing on `/editor` and had spurious `test.fixme` additions applied during earlier redesign sweeps.
   - **Fix:** Changed default in `tests/e2e/support/editor.ts` to `export async function openEditor(page: Page, url = LEGACY_EDITOR_URL)`.

4. **Spurious `test.fixme` Reversals:**
   - Restored specs that had been marked with `test.fixme("New editor lacks...")` (`editing.spec.ts`, `selection.spec.ts`, `snapping.spec.ts`, `stopwatch.spec.ts`, `tools.spec.ts`, `viewport-camera.spec.ts`) so they target the legacy editor cleanly without weakened assertions.

5. **Dynamic Frame Hydration Guard in Spec Helpers:**
   - Guarded `measure` helpers in `tests/e2e/grid-constraints.spec.ts` and `tests/e2e/auto-layout.spec.ts` against transient null returns during dynamic iframe mounting, and guarded edge resize polling in `tests/e2e/breakpoint-canvas.spec.ts`.
